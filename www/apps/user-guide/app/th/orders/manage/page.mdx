# {metadata.title}

ในคู่มือนี้ คุณจะได้เรียนรู้วิธีการค้นหาหน้ารายละเอียดของคำสั่งซื้อ ข้อมูลที่คุณสามารถพบได้ในหน้ารายละเอียดคำสั่งซื้อ และวิธีการจัดการรายละเอียดของคำสั่งซื้อ ซึ่งรายละเอียดของคำสั่งซื้อนี้รวมถึงข้อมูลทั่วไป เช่น ข้อมูลลูกค้า หรือรายละเอียดที่อยู่

## เปิดหน้ารายละเอียดคำสั่งซื้อ

ขั้นตอนการเปิดรายละเอียดของคำสั่งซื้อ:

1. ไปที่หน้า **Orders** จากแถบข้าง (sidebar)
2. เลือกรายการสั่งซื้อรายการใดรายการหนึ่งเพื่อเปิดหน้ารายละเอียดคำสั่งซื้อ

![หน้ารายละเอียดคำสั่งซื้อ](https://res.cloudinary.com/dza7lstvk/image/upload/v1739543439/User%20Guide/Screenshot_2025-02-14_at_4.30.14_PM_nirqsy.png)

### ส่วนสรุปคำสั่งซื้อ (Order Summary)

ส่วน Summary ประกอบด้วยข้อมูลสรุปของสินค้าที่ลูกค้าซื้อ รวมถึงยอดรวมต่างๆ เช่น ภาษี การจัดส่ง และอื่นๆ คุณสามารถใช้ส่วนนี้เพื่อดูภาพรวมของคำสั่งซื้อได้อย่างรวดเร็ว [สร้างรายการคืนสินค้า](../returns/page.mdx) [สร้างรายการแลกเปลี่ยนสินค้า](../exchanges/page.mdx) หรือจัดการรายละเอียดของคำสั่งซื้อตามที่อธิบายไว้ในคู่มือนี้

![สรุปคำสั่งซื้อ](https://res.cloudinary.com/dza7lstvk/image/upload/v1739543620/User%20Guide/Screenshot_2025-02-14_at_4.33.05_PM_ockept.png)

### ส่วนข้อมูลลูกค้า (Customer)

ส่วน Customer จะแสดงรายละเอียดของลูกค้า รวมถึงข้อมูลติดต่อและที่อยู่จัดส่งสินค้า คุณสามารถใช้ส่วนนี้เพื่อดูและแก้ไขรายละเอียดของลูกค้าที่เกี่ยวข้องกับคำสั่งซื้อตามที่อธิบายไว้ในคู่มือนี้

![ส่วนข้อมูลลูกค้า](https://res.cloudinary.com/dza7lstvk/image/upload/v1739543745/User%20Guide/Screenshot_2025-02-14_at_4.35.27_PM_b4vav0.png)

### ส่วนกิจกรรม (Activity)

ส่วน Activity ของหน้ารายละเอียดคำสั่งซื้อจะแสดงข้อมูลสรุปของการเปลี่ยนแปลงที่เกิดขึ้นกับคำสั่งซื้อ ซึ่งรวมถึงการเรียกเก็บเงินที่ชำระแล้ว สินค้าที่คืน สินค้าที่จัดส่ง และอื่นๆ คุณสามารถใช้ส่วนนี้เพื่อดูประวัติของคำสั่งซื้อและการดำเนินการต่างๆ ได้อย่างรวดเร็ว

![ส่วนประวัติกิจกรรม](https://res.cloudinary.com/dza7lstvk/image/upload/v1739543897/User%20Guide/Screenshot_2025-02-14_at_4.37.58_PM_dcl0lw.png)

### ส่วนการชำระเงิน (Payments)

ส่วน Payment ของหน้ารายละเอียดคำสั่งซื้อประกอบด้วยรายละเอียดที่เกี่ยวข้องกับการชำระเงินของคำสั่งซื้อ โดยจะแสดงประวัติการเปลี่ยนแปลงสถานะการชำระเงินทั้งหมด คุณสามารถใช้ส่วนนี้เพื่อดูและ[จัดการการชำระเงิน](../payments/page.mdx)ที่เกี่ยวข้องกับคำสั่งซื้อ

![ส่วนการชำระเงิน](https://res.cloudinary.com/dza7lstvk/image/upload/v1739544008/User%20Guide/Screenshot_2025-02-14_at_4.39.51_PM_vufzzu.png)

### ส่วนสินค้าที่ยังไม่ได้ดำเนินการจัดส่ง (Unfulfilled Items)

ส่วน Unfulfilled Items ของหน้ารายละเอียดคำสั่งซื้อจะแสดงรายละเอียดของสินค้าที่ยังไม่ได้จัดส่ง คุณสามารถใช้ส่วนนี้เพื่อดูรายการสินค้าที่จำเป็นต้องจัดส่งและ[สร้างการจัดส่งสินค้าเหล่านั้น](../fulfillments/page.mdx)

![ส่วนสินค้าที่ยังไม่ได้จัดส่ง](https://res.cloudinary.com/dza7lstvk/image/upload/v1739544116/User%20Guide/Screenshot_2025-02-14_at_4.40.44_PM_vjrput.png)

### ส่วนการจัดส่งสินค้า (Fulfillment)

สำหรับการจัดส่งทุกรายการที่คุณสร้างขึ้น ส่วนการจัดส่งใหม่จะถูกเพิ่มเข้ามาพร้อมกับระบุหมายเลขการจัดส่งในส่วนหัว โดยส่วนนี้จะประกอบด้วยรายละเอียดการจัดส่งสินค้า คุณสามารถใช้ส่วนนี้เพื่อดูและ[จัดการการจัดส่งสินค้า](../fulfillments/page.mdx)

![ส่วนการจัดส่งสินค้า](https://res.cloudinary.com/dza7lstvk/image/upload/v1739544250/User%20Guide/Screenshot_2025-02-14_at_4.43.21_PM_lcm50k.png)

### ส่วนข้อมูล JSON

ส่วน JSON มีประโยชน์สำหรับนักพัฒนาในการดูข้อมูลดิบของคำสั่งซื้อในรูปแบบโครงสร้าง JSON นักพัฒนาสามารถใช้ส่วนนี้เพื่อวิเคราะห์แก้ไขปัญหาต่างๆ ที่เกี่ยวข้องกับคำสั่งซื้อได้

หากต้องการดูโครงสร้าง JSON ให้คลิกที่ไอคอน <InlineIcon Icon={ArrowUpRightOnBox} alt="ขยาย" />

## จัดสรรสินค้าในคำสั่งซื้อด้วยตนเอง

หาก Medusa จัดการสินค้าคงคลังของสินค้าที่สั่งซื้อ ระบบจะสำรองหรือจัดสรรสินค้าตามจำนวนที่สั่งซื้อจากคลังสินค้า เพื่อให้มั่นใจว่าจำนวนสินค้าที่พร้อมจำหน่ายของสินค้าชิ้นนั้นจะลดลงตามจำนวนที่สั่งซื้อไป

Medusa จะจัดสรรจำนวนสินค้าคงคลังตามที่สั่งซื้อจากสถานที่จัดเก็บสินค้า (stock location) ของตัวเลือกการจัดส่งที่เลือกในคำสั่งซื้อ ตัวอย่างเช่น หากลูกค้าเลือกตัวเลือกการจัดส่งที่ใช้คลังสินค้าในสหรัฐอเมริกา Medusa จะจัดสรรจำนวนสินค้าคงคลังตามที่สั่งซื้อจากสถานที่จัดเก็บสินค้าแห่งนั้น

อย่างไรก็ตาม ในบางกรณีคุณอาจจำเป็นต้องจัดสรรสินค้าด้วยตนเอง เช่น หากคุณ[แก้ไขคำสั่งซื้อ](../edit/page.mdx) หรือหากคุณเปลี่ยนการตั้งค่าการจัดการสินค้าคงคลังของตัวเลือกย่อยของสินค้านั้น คุณจะพบป้ายสถานะ "Not allocated" ปรากฏอยู่ข้างชื่อสินค้าในส่วน Summary

![ป้ายสถานะไม่ได้จัดสรรสินค้า](https://res.cloudinary.com/dza7lstvk/image/upload/v1739546156/User%20Guide/Screenshot_2025-02-14_at_5.14.59_PM_fgc2d2.png)

ขั้นตอนการจัดสรรสินค้าเหล่านี้ด้วยตนเอง:

1. ไปที่ส่วน Summary ในหน้ารายละเอียดของคำสั่งซื้อ
2. หากมีสินค้าหนึ่งรายการหรือมากกว่าที่ยังไม่ได้รับการจัดสรร คุณจะพบปุ่ม "Allocate items" อยู่ที่ด้านล่างของส่วนดังกล่าว ให้คลิกที่ปุ่มนั้น
3. ในแบบฟอร์มที่เปิดขึ้น:
  1. สำหรับช่อง Location ให้เลือกสถานที่จัดเก็บสินค้าที่ต้องการจัดสรรสินค้าออกมา
  2. ในส่วน Items to Allocate ให้ป้อนจำนวนสินค้าที่ต้องการจัดสรรสำหรับสินค้าแต่ละรายการ
4. เมื่อเสร็จแล้ว ให้คลิกปุ่ม "Allocate Items"

![แบบฟอร์มจัดสรรสินค้า](https://res.cloudinary.com/dza7lstvk/image/upload/v1739545718/User%20Guide/Screenshot_2025-02-14_at_5.07.46_PM_mzi0bg.png)

## แก้ไขที่อยู่จัดส่ง

ขั้นตอนการแก้ไขที่อยู่จัดส่งที่ใช้สำหรับคำสั่งซื้อ:

1. เปิดหน้ารายละเอียดคำสั่งซื้อ
2. คลิกที่ไอคอน <InlineIcon Icon={EllipsisHorizontal} alt="สามจุด" /> ในแถบส่วนหัวของส่วน Customer
3. คลิกเลือก "Shipping address" (ที่อยู่จัดส่ง) จากเมนูดรอปดาวน์
4. ในหน้าต่างด้านข้างที่เปิดขึ้น ให้แก้ไขรายละเอียดที่อยู่
5. เมื่อเสร็จแล้ว ให้คลิกปุ่ม Save

![แบบฟอร์มแก้ไขที่อยู่จัดส่ง](https://res.cloudinary.com/dza7lstvk/image/upload/v1739546317/User%20Guide/Screenshot_2025-02-14_at_5.18.13_PM_zfi5ly.png)

## แก้ไขที่อยู่อีเมล

คุณสามารถแก้ไขที่อยู่อีเมลของคำสั่งซื้อเพื่อส่งการแจ้งเตือนการอัปเดตคำสั่งซื้อไปยังอีเมลใหม่ได้ การดำเนินการนี้จะไม่ส่งผลต่อการอัปเดตที่อยู่อีเมลของลูกค้าที่เชื่อมโยงอยู่ หรือการโอนย้ายคำสั่งซื้อนี้ไปยังลูกค้ารายใหม่ หากต้องการโอนย้ายคำสั่งซื้อไปยังลูกค้ารายใหม่ โปรดดูที่ส่วน [โอนสิทธิ์ความเป็นเจ้าของของลูกค้า](#โอนสิทธิ์ความเป็นเจ้าของของลูกค้า)

ขั้นตอนการแก้ไขที่อยู่อีเมลที่เชื่อมโยงกับคำสั่งซื้อ:

1. เปิดหน้ารายละเอียดคำสั่งซื้อ
2. คลิกที่ไอคอน <InlineIcon Icon={EllipsisHorizontal} alt="สามจุด" /> ในแถบส่วนหัวของส่วน Customer
3. คลิกเลือก "Email" (อีเมล) จากเมนูดรอปดาวน์
4. ในหน้าต่างด้านข้างที่เปิดขึ้น ให้แก้ไขที่อยู่อีเมล
5. เมื่อเสร็จแล้ว ให้คลิกปุ่ม Save

![แบบฟอร์มแก้ไขที่อยู่อีเมล](https://res.cloudinary.com/dza7lstvk/image/upload/v1739546558/User%20Guide/Screenshot_2025-02-14_at_5.22.06_PM_fmrnc6.png)

## โอนสิทธิ์ความเป็นเจ้าของของลูกค้า

คุณสามารถโอนสิทธิ์ความเป็นเจ้าของของคำสั่งซื้อไปยังลูกค้าคนอื่นที่ลงทะเบียนแล้วได้ การดำเนินการนี้จะเปลี่ยนลูกค้าที่เชื่อมโยงกับคำสั่งซื้อ และส่งการแจ้งเตือนการอัปเดตคำสั่งซื้อไปยังลูกค้าคนใหม่

<Note>

คุณไม่สามารถโอนสิทธิ์ความเป็นเจ้าของไปยังลูกค้าทั่วไป (guest) ได้ ซึ่งรวมถึงลูกค้าที่คุณสร้างขึ้นผ่านหน้าแดชบอร์ดผู้ดูแลระบบ (admin dashboard) ด้วย

</Note>

เมื่อคุณโอนสิทธิ์ความเป็นเจ้าของของคำสั่งซื้อ ลูกค้าเดิมจะได้รับการแจ้งเตือน เช่น อีเมล เพื่อขออนุมัติการโอนย้ายดังกล่าว คำสั่งซื้อจะถูกโอนไปยังลูกค้าคนใหม่ก็ต่อเมื่อลูกค้าเดิมอนุมัติการโอนย้ายนี้แล้วเท่านั้น

ขั้นตอนการโอนสิทธิ์ความเป็นเจ้าของของคำสั่งซื้อไปยังลูกค้าคนอื่น:

1. เปิดหน้ารายละเอียดคำสั่งซื้อ
2. คลิกที่ไอคอน <InlineIcon Icon={EllipsisHorizontal} alt="สามจุด" /> ในแถบส่วนหัวของส่วน Customer
3. คลิกเลือก "Transfer ownership" (โอนสิทธิ์ความเป็นเจ้าของ) จากเมนูดรอปดาวน์
4. ในหน้าต่างด้านข้างที่เปิดขึ้น ให้เลือกลูกค้าใหม่จากเมนูดรอปดาวน์ภายใต้ส่วน "New owner"
5. เมื่อเสร็จแล้ว ให้คลิกปุ่ม Save

ลูกค้าเดิมจะได้รับการแจ้งเตือนเพื่อขออนุมัติการโอนย้ายสิทธิ์ดังกล่าว

<Note>

หากไม่มีการแจ้งเตือนส่งไป โปรดติดต่อทีมเทคนิคของคุณเพื่อตรวจสอบแก้ไขข้อผิดพลาดใน[บริการแจ้งเตือนที่เชื่อมโยงระบบ (integrated notification service)](!resources!/infrastructure-modules/notification)

</Note>

![แบบฟอร์มโอนสิทธิ์ความเป็นเจ้าของ](https://res.cloudinary.com/dza7lstvk/image/upload/v1739546904/User%20Guide/Screenshot_2025-02-14_at_5.28.12_PM_brwpek.png)

## ยกเลิกคำสั่งซื้อ

คุณสามารถยกเลิกคำสั่งซื้อได้หากยังไม่มีสินค้าใดที่ได้รับการดำเนินการจัดส่ง การยกเลิกคำสั่งซื้อจะส่งผลดังนี้:

- เปลี่ยนสถานะของคำสั่งซื้อเป็นยกเลิก (canceled)
- คืนเงินสำหรับรายการชำระเงินที่เรียกเก็บไปแล้ว
- ยกเลิกรายการชำระเงินใดๆ ที่ได้รับการอนุมัติ (authorized) ไว้
- แจ้งเตือนลูกค้าเกี่ยวกับการยกเลิกคำสั่งซื้อ

<Note type="warning">

การยกเลิกคำสั่งซื้อไม่สามารถย้อนคืนได้

</Note>

ขั้นตอนการยกเลิกคำสั่งซื้อ:

1. เปิดหน้ารายละเอียดคำสั่งซื้อ
2. ในส่วนแรกที่แสดงหมายเลขคำสั่งซื้อ ให้คลิกที่ไอคอน <InlineIcon Icon={EllipsisHorizontal} alt="สามจุด" /> ที่อยู่ถัดจากหมายเลขนั้น
3. คลิกเลือก Cancel (ยกเลิก) จากเมนูดรอปดาวน์
4. ยืนยันการยกเลิกคำสั่งซื้อโดยคลิกปุ่ม “Continue” ในกล่องป๊อปอัป

หากคำสั่งซื้อได้รับการชำระเงินหรือจัดส่งแล้ว คุณจะได้รับข้อความแจ้งเตือนข้อผิดพลาดเพื่อป้องกันไม่ให้คุณยกเลิกคำสั่งซื้อ มิฉะนั้น คำสั่งซื้อจะถูกยกเลิกสำเร็จ
