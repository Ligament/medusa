# {metadata.title}

<Note title="ข้อกำหนดเบื้องต้น">

หากคุณกำลังใช้งานเวอร์ชันก่อน v2.10.0 คุณต้อง[ติดตั้งปลั๊กอิน Draft Orders ด้วยตนเอง](!resources!/commerce-modules/order/draft-orders) โดยทีมงานฝ่ายเทคนิคของคุณควรเป็นผู้ดำเนินการติดตั้งปลั๊กอินดังกล่าว

</Note>

ส่วนคำสั่งซื้อร่าง (Draft Orders) ใน Medusa Admin ช่วยให้คุณสามารถสร้างและจัดการคำสั่งซื้อร่างในนามของลูกค้าได้

คำสั่งซื้อร่างมีประโยชน์สำหรับการจัดการในกรณีของการสนับสนุนลูกค้า หรือเมื่อลูกค้าทำการสั่งซื้อแบบออฟไลน์ เช่น ทางโทรศัพท์หรือภายในร้านค้า

คุณสามารถดูรายการคำสั่งซื้อร่างที่มีในร้านค้าของคุณได้โดยคลิกที่ Orders -> Drafts จากเมนูด้านข้าง

![รายการคำสั่งซื้อร่าง](https://res.cloudinary.com/dza7lstvk/image/upload/v1756190283/User%20Guide/CleanShot_2025-08-26_at_09.32.13_2x_tmueho.png)

ในรายการนี้ คุณจะเห็นรายละเอียดของคำสั่งซื้อร่าง เช่น ID, วันที่, ลูกค้า, ช่องทางการขาย และภูมิภาค นอกจากนี้คุณยังสามารถค้นหา กรอง และจัดเรียงรายการเพื่อหาคำสั่งซื้อร่างที่เฉพาะเจาะจงตามที่คุณต้องการได้

<Note title="เคล็ดลับ">

คุณสามารถดูเคล็ดลับสำหรับการใช้งานรายการต่างๆ อย่างมีประสิทธิภาพได้ใน[คู่มือนี้](../../tips/lists/page.mdx)

</Note>
