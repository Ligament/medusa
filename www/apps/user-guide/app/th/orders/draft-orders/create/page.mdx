# {metadata.title}

ในคู่มือนี้ คุณจะได้เรียนรู้วิธีสร้างคำสั่งซื้อร่างใน Medusa Admin

<Note title="ข้อกำหนดเบื้องต้น">

หากคุณกำลังใช้งานเวอร์ชันก่อน v2.10.0 คุณต้อง[ติดตั้งปลั๊กอิน Draft Orders ด้วยตนเอง](!resources!/commerce-modules/order/draft-orders) โดยทีมงานฝ่ายเทคนิคของคุณควรเป็นผู้ดำเนินการติดตั้งปลั๊กอินดังกล่าว

</Note>

## เมื่อใดที่ควรสร้างคำสั่งซื้อร่าง

คุณควรสร้างคำสั่งซื้อร่างในสถานการณ์ต่อไปนี้:

- เมื่อจัดการกับคำขอช่วยเหลือจากลูกค้าที่ต้องมีการสร้างคำสั่งซื้อในนามของลูกค้า
- เมื่อดำเนินการกับคำสั่งซื้อที่ทำผ่านช่องทางออฟไลน์ เช่น ทางโทรศัพท์หรือหน้าร้าน
- เมื่อลูกค้าต้องการสั่งซื้อสินค้าแต่จำเป็นต้องยืนยันรายละเอียดในภายหลัง

คุณสามารถสร้างคำสั่งซื้อร่างและแปลงเป็นคำสั่งซื้อปกติได้เมื่อพร้อมสำหรับการดำเนินการ

---

## สร้างคำสั่งซื้อร่าง

วิธีการสร้างคำสั่งซื้อร่าง:

1. ไปที่ Orders -> Drafts
2. คลิกปุ่ม Create ในส่วนหัวของส่วนหลัก
3. ในฟอร์มที่เปิดขึ้น ให้กรอกข้อมูลต่อไปนี้:
    - **Region**: เลือกภูมิภาคสำหรับคำสั่งซื้อร่าง ซึ่งจะเป็นตัวกำหนดสกุลเงินและกฎภาษีที่นำมาใช้กับคำสั่งซื้อ
    - **Sales Channel**: เลือกช่องทางการขายสำหรับคำสั่งซื้อร่าง ซึ่งเป็นการกำหนดว่าคำสั่งซื้อนี้ถูกสร้างขึ้นที่ใด ส่งผลต่อรายการสินค้าคงคลังที่พร้อมจำหน่าย และกำหนดว่าตัวเลือกการจัดส่งใดที่สามารถใช้ได้กับคำสั่งซื้อนี้
    - **Customer** (ไม่บังคับ): เลือกลูกค้าที่มีอยู่แล้วในระบบซึ่งเป็นเจ้าของคำสั่งซื้อร่างนี้ คุณยังสามารถระบุลูกค้าในภายหลังหรือข้ามการระบุลูกค้าได้เลย
    - **Email**: กำหนดที่อยู่อีเมลของลูกค้า ลูกค้าอาจได้รับข้อมูลอัปเดตคำสั่งซื้อผ่านอีเมลนี้
    - **Shipping Address**: กรอกรายละเอียดที่อยู่จัดส่งสำหรับคำสั่งซื้อร่าง หรือเลือกที่อยู่ที่มีอยู่แล้วหากมีการระบุลูกค้าไว้
    - **Billing Address**: กำหนดให้ที่อยู่เรียกเก็บเงินเป็นที่อยู่เดียวกันกับที่อยู่จัดส่ง หรือกรอกที่อยู่เรียกเก็บเงินอื่นที่แตกต่างออกไป
4. เมื่อเสร็จแล้ว ให้คลิกปุ่ม Save

คำสั่งซื้อร่างจะถูกสร้างขึ้น และระบบจะนำคุณไปยังหน้ารายละเอียดของคำสั่งซื้อร่างดังกล่าว

## ขั้นตอนถัดไป: จัดการสินค้าและวิธีการจัดส่ง

หลังจากสร้างคำสั่งซื้อร่างแล้ว คุณสามารถเพิ่มสินค้าไปยังคำสั่งซื้อและจัดการวิธีการจัดส่งได้

ศึกษาวิธีการดำเนินการดังกล่าวได้ในคู่มือ [จัดการรายละเอียดคำสั่งซื้อร่าง](../manage/page.mdx)
