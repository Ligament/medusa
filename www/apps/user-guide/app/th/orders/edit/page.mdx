# {metadata.title}

ในคู่มือนี้ คุณจะได้เรียนรู้วิธีแก้ไขรายการสินค้าในคำสั่งซื้อ ซึ่งรวมถึงการเพิ่ม การอัปเดต หรือการลบรายการสินค้า

## วิธีการทำงานของการแก้ไขคำสั่งซื้อ

ด้วยการใช้งาน Medusa Admin คุณสามารถแก้ไขคำสั่งซื้อเพื่อ:

- เพิ่มสินค้าใหม่เข้าไปในคำสั่งซื้อ
- แก้ไขจำนวนสินค้าที่มีอยู่แล้วในคำสั่งซื้อ
- ลบสินค้าออกจากคำสั่งซื้อ

![ส่วนคำขอแก้ไขคำสั่งซื้อ](https://res.cloudinary.com/dza7lstvk/image/upload/v1739787160/User%20Guide/Screenshot_2025-02-17_at_12.09.50_PM_bap56a.png)

เมื่อคุณส่งคำขอแก้ไขคำสั่งซื้อ การเปลี่ยนแปลงจะยังไม่ถูกบันทึกในคำสั่งซื้อจนกว่าการแก้ไขดังกล่าวจะได้รับการยืนยัน โดยมีสองวิธีในการยืนยันคำขอแก้ไขคำสั่งซื้อ:

1. ลูกค้าตรวจสอบการแก้ไขคำสั่งซื้อ หากพวกเขายอมรับการแก้ไขและจำเป็นต้องมีการชำระเงินเพิ่มเติม พวกเขาจะต้องอนุมัติการชำระเงินนั้น ทั้งนี้ลูกค้าสามารถปฏิเสธการแก้ไขคำสั่งซื้อได้เช่นกัน
2. หรือคุณทำการบังคับยืนยัน (Force-confirm) การแก้ไขคำสั่งซื้อ จากนั้นคุณจึงจะจัดการกับยอดค้างชำระต่าง ๆ

---

## ส่งคำขอแก้ไขคำสั่งซื้อ

คุณสามารถส่งคำขอแก้ไขคำสั่งซื้อได้ทีละหนึ่งรายการเท่านั้น หากคุณต้องการทำการเปลี่ยนแปลงเพิ่มเติม คุณต้องยกเลิกการแก้ไขคำสั่งซื้อปัจจุบันแล้วส่งคำขอใหม่ หรือบังคับยืนยันการแก้ไขคำสั่งซื้อปัจจุบัน

ในการส่งคำขอแก้ไขคำสั่งซื้อ:

1. เปิดหน้าประวัติคำสั่งซื้อ (Order details)
2. ในส่วนสรุป (Summary) คลิกที่ไอคอน <InlineIcon Icon={EllipsisHorizontal} alt="สามจุด" />
3. เลือก "Edit Order" (แก้ไขคำสั่งซื้อ) จากเมนูดรอปดาวน์
4. ในฟอร์มที่เปิดขึ้น:
    1. วิธีการเพิ่มสินค้า:
        1. คลิกที่ปุ่ม "Add items" (เพิ่มสินค้า)
        2. ในรายการที่เปิดขึ้น ให้คลิกเลือกช่องทำเครื่องหมาย (Checkbox) ถัดจากสินค้าที่คุณต้องการเพิ่ม
        3. เมื่อเสร็จแล้ว ให้คลิกปุ่ม "Save" (บันทึก) สินค้าจะถูกเพิ่มในส่วนของ "Items" (สินค้า) พร้อมป้ายกำกับ (Badge) "New" (ใหม่) นอกจากนี้คุณยังสามารถอัปเดตจำนวนสินค้าได้อีกด้วย
    2. วิธีการอัปเดตจำนวนสินค้า:
        1. ค้นหาสินค้าภายใต้ส่วน "Items"
        2. เปลี่ยนค่าในช่องป้อนข้อมูล "qty" (จำนวน) ซึ่งจะเป็นการเพิ่มป้ายกำกับ "Modified" (แก้ไขแล้ว) ให้กับสินค้านั้น
    3. วิธีการทำซ้ำสินค้า:
        1. ค้นหาสินค้าภายใต้ส่วน "Items"
        2. คลิกที่ไอคอน <InlineIcon Icon={EllipsisHorizontal} alt="สามจุด" />
        3. เลือก "Duplicate" (ทำซ้ำ) จากเมนูดรอปดาวน์ สินค้าใหม่ที่มีรายละเอียดเดียวกันจะถูกเพิ่มในส่วนของ "Items" พร้อมป้ายกำกับ "New"
    4. วิธีการลบสินค้า:
        1. ค้นหาสินค้าภายใต้ส่วน "Items"
        2. คลิกที่ไอคอน <InlineIcon Icon={EllipsisHorizontal} alt="สามจุด" />
        3. เลือก "Remove" (ลบออก) จากเมนูดรอปดาวน์
            - หากคุณลบสินค้าที่เพิ่งเพิ่มเข้ามาใหม่ สินค้านั้นจะถูกลบออกจากรายการทันที หากเป็นสินค้าเดิม สินค้าจะมีป้ายกำกับ "Removed" (ถูกลบออก) และคุณจะไม่สามารถแก้ไขจำนวนสินค้าได้
            - หากต้องการยกเลิกการลบสินค้าในคำสั่งซื้อ ให้คลิกไอคอน <InlineIcon Icon={EllipsisHorizontal} alt="สามจุด" /> ถัดจากสินค้านั้น แล้วเลือก "Undo" (เลิกทำ) จากเมนูดรอปดาวน์
    5. ป้อนหมายเหตุเพิ่มเติมในช่อง Note (หมายเหตุ) เพื่อให้ลูกค้าเห็นได้ (ไม่บังคับ)
    6. หากคุณต้องการส่งการแจ้งเตือนไปยังลูกค้าเกี่ยวกับการแก้ไขคำสั่งซื้อ ให้เปิดใช้งานปุ่มสลับ "Send notifications" (ส่งการแจ้งเตือน)
5. เมื่อเสร็จแล้ว ให้คลิกปุ่ม "Confirm Edit" (ยืนยันการแก้ไข)
6. ยืนยันการส่งคำขอแก้ไขคำสั่งซื้อโดยการคลิกปุ่ม "Continue" (ดำเนินการต่อ) ในป๊อปอัป

![ฟอร์มแก้ไขคำสั่งซื้อ](https://res.cloudinary.com/dza7lstvk/image/upload/v1739792815/User%20Guide/Screenshot_2025-02-17_at_1.46.35_PM_quugt5.png)

เมื่อส่งคำขอแล้ว ส่วนใหม่ที่ชื่อ "Order edit requested" (ส่งคำขอแก้ไขคำสั่งซื้อแล้ว) จะแสดงขึ้นที่ด้านบนของหน้ารายละเอียดคำสั่งซื้อพร้อมข้อมูลรายละเอียดของการแก้ไข

## บังคับยืนยันการแก้ไขคำสั่งซื้อ

ดังที่ได้กล่าวไว้ในตอนต้นของคู่มือนี้ ลูกค้าจะต้องเป็นผู้ยืนยันการแก้ไขคำสั่งซื้อเพื่อให้ระบบบันทึกการเปลี่ยนแปลงลงในคำสั่งซื้อ อย่างไรก็ตาม คุณสามารถทำการบังคับยืนยัน (Force-confirm) การแก้ไขคำสั่งซื้อได้ หากคุณต้องการให้การเปลี่ยนแปลงมีผลทันที หรือหากลูกค้ามอบหมายให้คุณดำเนินการแทน

<Note type="warning">

การบังคับยืนยันการแก้ไขคำสั่งซื้อจะทำการเปลี่ยนแปลงคำสั่งซื้อที่ไม่สามารถย้อนกลับได้

</Note>

ในการบังคับยืนยันการแก้ไขคำสั่งซื้อ:

1. เปิดหน้ารายละเอียดคำสั่งซื้อ
2. คลิกปุ่ม "Force confirm" (บังคับยืนยัน) ที่อยู่ด้านล่างของส่วน "Order edit requested"

การดำเนินการนี้จะปรับใช้การเปลี่ยนแปลงกับการแก้ไขคำสั่งซื้อ หากจำเป็นต้องมีการชำระเงินเพิ่มเติม คุณจะต้องทำเครื่องหมายคำสั่งซื้อว่าชำระเงินแล้ว หรือแชร์ลิงก์การชำระเงินด้วยตนเอง

### การจัดสรรสินค้าใหม่

สำหรับสินค้าใหม่ คุณอาจเห็นปุ่ม "Allocate Items" (จัดสรรสินค้า) ซึ่งระบุว่าคุณจำเป็นต้องจัดสรรสินค้าเหล่านั้นด้วยตนเองจากคลังสินค้า โปรดดูรายละเอียดเพิ่มเติมที่[คู่มือนี้](../manage/page.mdx#allocate-order-items-manually)

### การจัดการยอดค้างชำระหลังการแก้ไขคำสั่งซื้อ

หลังจากได้รับการยืนยันการแก้ไขคำสั่งซื้อแล้ว คุณสามารถตรวจสอบว่ามียอดค้างชำระใด ๆ (ที่จะต้องเรียกเก็บเพิ่มเติมจากลูกค้าหรือคืนเงิน) ได้ในส่วนสรุป (Summary)

ในการจัดการยอดค้างชำระโดยการคืนเงินหรือการเรียกเก็บเงิน โปรดดูรายละเอียดที่[คู่มือการชำระเงิน](../payments/page.mdx#handling-outstanding-amounts)

### การดำเนินการส่งสินค้าใหม่

หากการแก้ไขคำสั่งซื้อมีการเพิ่มสินค้าใหม่เข้าไปในคำสั่งซื้อ สินค้าเหล่านั้นจะแสดงในส่วน "Unfulfilled Items" (สินค้าที่ยังไม่ได้ดำเนินการจัดส่ง) หลังจากยืนยันการแก้ไขคำสั่งซื้อแล้ว คุณสามารถดำเนินการจัดส่งสินค้าเหล่านั้นตามที่อธิบายไว้ใน[คู่มือนี้](../fulfillments/page.mdx)

## ยกเลิกคำขอแก้ไขคำสั่งซื้อ

หากคำขอแก้ไขคำสั่งซื้อยังไม่ได้รับการยืนยัน คุณสามารถยกเลิกคำขอดังกล่าวได้

ในการยกเลิกคำขอแก้ไขคำสั่งซื้อ:

1. เปิดหน้ารายละเอียดคำสั่งซื้อ
2. คลิกปุ่ม "Cancel" (ยกเลิก) ที่อยู่ด้านล่างของส่วน "Order edit requested"

การแก้ไขคำสั่งซื้อจะถูกยกเลิกและการเปลี่ยนแปลงจะไม่ถูกบันทึกลงในคำสั่งซื้อ นอกจากนี้ลูกค้าจะไม่สามารถกดยืนยันการแก้ไขคำสั่งซื้อดังกล่าวได้อีกต่อไป
