# {metadata.title}

ยินดีต้อนรับสู่คู่มือการใช้งาน Medusa Admin คู่มือนี้มีวัตถุประสงค์เพื่อช่วยให้ผู้ดูแลระบบและผู้ค้าเรียนรู้วิธีการใช้งาน Medusa Admin เพื่อดำเนินงานการค้าและจัดการร้านค้าของพวกเขา

![ภาพรวม Medusa Admin](https://res.cloudinary.com/dza7lstvk/image/upload/v1739530936/User%20Guide/Screenshot_2025-02-14_at_1.01.35_PM_ecyltl.png)

## คู่มือนี้เหมาะสำหรับใคร?

คู่มือนี้เหมาะสำหรับผู้ใช้งาน Medusa Admin ที่ต้องการทำความเข้าใจและจัดการร้านค้าอย่างมีประสิทธิภาพ โดยคุณไม่จำเป็นต้องมีความรู้ทางเทคนิคใดๆ ก็สามารถทำตามคู่มือนี้ได้

คุณสามารถศึกษาคู่มือนี้ได้เช่นกันหากคุณต้องการเรียนรู้เกี่ยวกับคุณลักษณะการทำงานต่างๆ ของ Medusa

<Note>

สำหรับผู้ใช้งานทางเทคนิคหรือนักพัฒนา สามารถเรียนรู้วิธีการสร้างและปรับแต่ง Medusa ได้ในส่วน [เริ่มต้นใช้งาน](!docs!/learn) ของเอกสารประกอบ

</Note>

## เข้าใช้งาน Medusa Admin

ในการเข้าใช้งานแดชบอร์ด Medusa Admin ของร้านค้าอีคอมเมิร์ซของคุณ ให้เปิด URL ของระบบในเครื่องของคุณ (`localhost:9000/app`) หรือเว็บไซต์ที่ได้ติดตั้งไว้ จากนั้นระบบจะขอให้คุณเข้าสู่ระบบ

![หน้าเข้าสู่ระบบ](https://res.cloudinary.com/dza7lstvk/image/upload/v1739526611/User%20Guide/Screenshot_2025-02-14_at_11.45.35_AM_j1gepy.png)

คุณต้องใช้อีเมลและรหัสผ่านของคุณในการเข้าสู่ระบบ หากคุณไม่แน่ใจว่าอีเมลและรหัสผ่านของคุณคืออะไร โปรดติดต่อทีมงานฝ่ายเทคนิคที่ทำการติดตั้งและตั้งค่าแอปพลิเคชัน Medusa ของคุณ

<Note title="คำแนะนำทางเทคนิค">

ดูรายละเอียดที่ [Medusa CLI](!resources!/medusa-cli#user) เพื่อเรียนรู้วิธีการสร้างผู้ใช้งานใหม่

</Note>

## แนะนำส่วนต่างๆ ของ Medusa Admin

หลังจากที่คุณเข้าสู่ระบบ Medusa Admin แล้ว คุณจะเห็นแถบเมนูด้านข้างสำหรับนำทางพร้อมแถบค้นหาที่ด้านบน, ไอคอนการแจ้งเตือน <InlineIcon Icon={BellAlert} alt="bell" /> ที่ส่วนหัว และพื้นที่เนื้อหาหลักตรงกลาง

### เมนูด้านข้าง (Sidebar Menu)

เมนูด้านข้างประกอบด้วยการนำทางหลักของ Medusa Admin คุณสามารถใช้เพื่อสลับไปมาระหว่างส่วนจัดการต่างๆ เช่น หน้าสินค้า (Products) หรือหน้าคำสั่งซื้อ (Orders)

![เมนูด้านข้าง](https://res.cloudinary.com/dza7lstvk/image/upload/v1739529281/User%20Guide/Screenshot_2025-02-14_at_12.34.22_PM_oeyaol.png)

คุณสามารถซ่อนแถบเมนูด้านข้างได้โดยคลิกไอคอน <InlineIcon Icon={SidebarLeft} alt="sidebar" /> ที่ด้านบนถัดจากแถบข้าง และคลิกอีกครั้งเพื่อแสดงแถบเมนูด้านข้าง

### คีย์ลัดแถบข้าง (Sidebar Shortcuts)

รายการแถบข้างต่างๆ มีคีย์ลัดสำหรับเข้าใช้งาน ตัวอย่างเช่น หน้าสินค้ามีคีย์ลัดโดยกดปุ่ม <Kbd>G</Kbd> แล้วตามด้วย <Kbd>P</Kbd> หากต้องการดูคีย์ลัดของรายการใด ให้วางเมาส์เหนือรายการนั้นสักครู่ แล้วกล่องคำแนะนำจะปรากฏขึ้นพร้อมกับคีย์ลัด

![คีย์ลัดแถบข้าง](https://res.cloudinary.com/dza7lstvk/image/upload/v1739530172/User%20Guide/Screenshot_2025-02-14_at_12.48.19_PM_moyjtv.png)

คุณยังสามารถดูคีย์ลัดทั้งหมดได้โดยคลิกที่โปรไฟล์ของคุณที่ด้านล่างของแถบข้างแล้วเลือก "คีย์ลัด" (Shortcuts)

### การตั้งค่าและการดำเนินการด่วน (Settings and Quick Actions)

ที่ด้านล่างของแถบข้าง คุณจะพบเมนูการตั้งค่า (Settings) ซึ่งจะนำคุณไปยังการตั้งค่าเพิ่มเติมสำหรับร้านค้าของคุณ เช่น การจัดการภูมิภาคและการตั้งค่าช่องทางการขาย นอกจากนี้คุณยังสามารถเห็นภาพโปรไฟล์และชื่อของคุณได้ที่นี่

![การตั้งค่าและโปรไฟล์](https://res.cloudinary.com/dza7lstvk/image/upload/v1739530277/User%20Guide/Screenshot_2025-02-14_at_12.51.06_PM_lq0ehf.png)

เมื่อคลิกที่รูปโปรไฟล์และชื่อของคุณ คุณจะเห็นการดำเนินการด่วน เช่น การเข้าถึงการตั้งค่าโปรไฟล์ การดูคีย์ลัด หรือการเปลี่ยนธีมของระบบผู้ดูแลระบบ

![การดำเนินการด่วนสำหรับโปรไฟล์](https://res.cloudinary.com/dza7lstvk/image/upload/v1739530277/User%20Guide/Screenshot_2025-02-14_at_12.50.50_PM_qqmw54.png)

### แถบค้นหา (Search Bar)

ที่ด้านบนสุดของแถบข้าง คุณจะพบส่วนการค้นหาที่สามารถคลิกเพื่อเปิดหน้าต่างค้นหาได้ หรือคุณสามารถเปิดหน้าต่างค้นหาได้โดยใช้คีย์ลัดบนคีย์บอร์ดดังนี้:

- Windows และ Linux: <Kbd>CTRL</Kbd> + <Kbd>K</Kbd>
- Mac OS: <Kbd>⌘</Kbd> + <Kbd>K</Kbd>

![หน้าต่างค้นหา](https://res.cloudinary.com/dza7lstvk/image/upload/v1739529553/User%20Guide/Screenshot_2025-02-14_at_12.36.53_PM_vps6cm.png)

คุณสามารถคลิกเลือกผลลัพธ์ด้วยเมาส์ หรือใช้ปุ่มลูกศรขึ้นและลงบนคีย์บอร์ดเพื่อนำทางระหว่างผลลัพธ์ แล้วเลือกผลลัพธ์ที่ต้องการโดยกดปุ่ม <Kbd>Enter</Kbd>

### การตรวจสอบการแจ้งเตือน (Check Notifications)

ที่ด้านขวาบนของแถบส่วนหัว คุณจะพบไอคอน <InlineIcon Icon={BellAlert} alt="Bell" /> เมื่อคลิกไอคอนนี้จะเปิดหน้าต่างด้านข้างเพื่อดูการแจ้งเตือนต่างๆ ของคุณ เช่น การแจ้งเตือนเมื่อการส่งออกรายการสินค้าเสร็จสมบูรณ์

![หน้าต่างการแจ้งเตือน](https://res.cloudinary.com/dza7lstvk/image/upload/v1739529955/User%20Guide/Screenshot_2025-02-14_at_12.45.44_PM_ljdvof.png)

### การเปลี่ยนภาษา (Change Language)

Medusa Admin รองรับการใช้งานหลายภาษา โดยมีภาษาอังกฤษเป็นภาษาเริ่มต้น สามารถตรวจสอบภาษาที่พร้อมใช้งานในคู่มือ [ภาษาของระบบ](./tips/languages/page.mdx)

ศึกษาวิธีการเปลี่ยนภาษาได้ในคู่มือ [การจัดการตั้งค่าโปรไฟล์](./settings/profile/page.mdx#change-admin-language)

### การเปลี่ยนธีมของระบบผู้ดูแลระบบ (Change Admin Theme)

Medusa Admin มาพร้อมกับธีมสว่าง (Light) และธีมมืด (Dark) คุณสามารถเปลี่ยนธีมได้โดยคลิกที่โปรไฟล์ของคุณที่ด้านล่างสุดของแถบข้าง → ธีม (Theme) → เลือก สว่าง (Light), มืด (Dark) หรือ ระบบ (System) ซึ่งจะอ้างอิงตามธีมของระบบปฏิบัติการหรือเบราว์เซอร์ของคุณ

![ธีมมืด](https://res.cloudinary.com/dza7lstvk/image/upload/v1739530936/User%20Guide/Screenshot_2025-02-14_at_1.01.56_PM_fdcgmz.png)
