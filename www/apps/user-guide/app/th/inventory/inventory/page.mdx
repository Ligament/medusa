# {metadata.title}

ในคู่มือนี้ คุณจะได้เรียนรู้วิธีจัดการรายการสินค้าคงคลัง (Inventory Items) ใน Medusa Admin

<Note>

คู่มือนี้ครอบคลุมการจัดการรายการสินค้าคงคลังในส่วน Inventory ของ Medusa Admin คุณยังสามารถจัดการคลังสินค้าของตัวเลือกสินค้า (Variants) ของผลิตภัณฑ์ได้จาก [หน้ารายละเอียดผลิตภัณฑ์](../../products/variants/page.mdx#manage-product-variant-inventory)

</Note>

## สร้างรายการสินค้าคงคลัง

หากต้องการสร้างรายการสินค้าคงคลัง:

1. ไปที่หน้า **Inventory** (สินค้าคงคลัง) จากเมนูด้านข้าง
2. คลิกปุ่ม **Create** (สร้าง) ที่ส่วนหัวข้อหลัก
3. แบบฟอร์มที่เปิดขึ้นจะมีสองขั้นตอน:
    1. ขั้นตอน Details (รายละเอียด):
        - กรอกชื่อสินค้าคงคลังและรหัส SKU ในช่องที่เกี่ยวข้อง
        - กรอกรายละเอียดเพิ่มเติม (ระบุหรือไม่ก็ได้)
        - หากสินค้าคงคลังนี้ไม่จำเป็นต้องจัดส่งเมื่อมีการซื้อตัวเลือกสินค้า ให้ปิดตัวเลือก "Requires shipping" (ต้องมีการจัดส่ง) ตัวอย่างเช่น กรณีที่สินค้าคงคลังนี้เป็นผลิตภัณฑ์ดิจิทัล
        - ระบุคุณสมบัติทางกายภาพและศุลกากรของสินค้าคงคลังได้เพิ่มเติม เช่น ความกว้าง ความยาว ความสูง น้ำหนัก รหัส MID รหัส HS ประเทศต้นกำเนิด และวัสดุ (ระบุหรือไม่ก็ได้)
        - เมื่อดำเนินการเสร็จแล้ว ให้คลิกปุ่ม **Next** (ถัดไป)
    2. ขั้นตอน Availability (การมีสินค้าพร้อมจำหน่าย) โดยใช้ [เครื่องมือแก้ไขข้อมูลจำนวนมาก (Bulk Editor)](../../tips/bulk-editor/page.mdx):
        - หากร้านค้าของคุณมีการสร้างคลังสินค้า (Locations) ไว้แล้ว ซึ่งคุณสามารถตั้งค่าได้ในส่วน [Settings](../../settings/locations-and-shipping/locations/page.mdx) คุณสามารถกำหนดจำนวนสินค้าคงคลังสำหรับแต่ละคลังสินค้าได้
4. เมื่อดำเนินการเสร็จเรียบร้อยแล้ว ให้คลิกปุ่ม **Save** (บันทึก)

1. ไปที่หน้า **Inventory** (สินค้าคงคลัง) จากเมนูด้านข้าง
2. คลิกที่รายการสินค้าคงคลังที่คุณต้องการดู

## แก้ไขรายละเอียดสินค้าคงคลัง

หากต้องการแก้ไขรายละเอียดทั่วไปของสินค้าคงคลัง:

1. ไปที่หน้ารายละเอียดของสินค้าคงคลัง
2. คลิกไอคอน <InlineIcon Icon={EllipsisHorizontal} alt="three-dots" /> ที่หัวข้อส่วนแรก
3. เลือก **Edit** (แก้ไข) จากเมนูแบบดึงลง
4. ในหน้าต่างด้านข้างที่เปิดขึ้น คุณสามารถแก้ไขชื่อสินค้าและรหัส SKU ได้
5. เมื่อดำเนินการเสร็จเรียบร้อยแล้ว ให้คลิกปุ่ม **Save** (บันทึก)

## แก้ไขคุณลักษณะสินค้าคงคลัง

หากต้องการแก้ไขคุณลักษณะ (Attributes) ของสินค้าคงคลัง เช่น ความสูงและน้ำหนัก:

1. ไปที่หน้ารายละเอียดของสินค้าคงคลัง
2. คลิกไอคอน <InlineIcon Icon={EllipsisHorizontal} alt="three-dots" /> ที่ส่วนหัวข้อ "Attributes" (คุณลักษณะ)
3. เลือก **Edit** (แก้ไข) จากเมนูแบบดึงลง
4. ในหน้าต่างด้านข้างที่เปิดขึ้น คุณสามารถแก้ไขค่าความสูง ความกว้าง ความยาว น้ำหนัก รหัส MID รหัส HS และประเทศต้นกำเนิดของสินค้าได้
5. เมื่อดำเนินการเสร็จเรียบร้อยแล้ว ให้คลิกปุ่ม **Save** (บันทึก)

## แก้ไขข้อมูลเมตาของสินค้าคงคลัง

ข้อมูลเมตา (Metadata) คือข้อมูลที่กำหนดเองซึ่งสามารถเชื่อมโยงกับสินค้าคงคลังในรูปแบบคู่คีย์-ค่า (Key-Value) โดยทั่วไปนักพัฒนาจะใช้ในส่วนนี้สำหรับการเชื่อมต่อข้อมูลแบบกำหนดเอง หรือสำหรับจัดเก็บข้อมูลเพิ่มเติมเกี่ยวกับสินค้าคงคลัง

หากต้องการแก้ไขข้อมูลเมตาของสินค้าคงคลัง:

1. ไปที่หน้ารายละเอียดของสินค้าคงคลัง
2. คลิกไอคอน <InlineIcon Icon={ArrowUpRightOnBox} alt="arrow" /> ในส่วน "Metadata" (ข้อมูลเมตา)
3. ในหน้าต่างด้านข้างที่เปิดขึ้น:
    - จัดการคู่คีย์-ค่าในตาราง
    - หากต้องการเพิ่มแถวคู่คีย์-ค่าใหม่ก่อนหน้าหรือถัดจากแถวที่มีอยู่:
        - วางเมาส์เหนือแถวที่ต้องการแล้วคลิกไอคอน <InlineIcon Icon={EllipsisVertical} alt="three-dots" /> ที่ท้ายแถว
        - เลือก "Insert row above" (แทรกแถวด้านบน) หรือ "Insert row below" (แทรกแถวด้านล่าง) จากเมนูดึงลง
    - หากต้องการลบแถวคู่คีย์-ค่าออก:
        - วางเมาส์เหนือแถวที่ต้องการแล้วคลิกไอคอน <InlineIcon Icon={EllipsisVertical} alt="three-dots" /> ที่ท้ายแถว
        - เลือก "Delete row" (ลบแถว) จากเมนูแบบดึงลง
4. เมื่อดำเนินการเสร็จเรียบร้อยแล้ว ให้คลิกปุ่ม **Save** (บันทึก)

## จัดการสถานะพร้อมจำหน่ายของสินค้าคงคลัง

คุณสามารถจัดการได้ว่าสินค้าคงคลังนี้จะพร้อมจำหน่ายที่คลังสินค้า (Locations) ใดบ้าง, กำหนดจำนวนสินค้าที่มีในแต่ละคลังสินค้า รวมถึงจัดการการจองสินค้า

### จัดการคลังสินค้าที่พร้อมจำหน่าย

หากต้องการจัดการคลังสินค้าที่สินค้าคงคลังนี้พร้อมจำหน่าย:

1. ไปที่หน้ารายละเอียดของสินค้าคงคลัง
2. คลิกปุ่ม **Manage locations** (จัดการคลังสินค้า) ที่ส่วนหัวข้อ "Locations" (คลังสินค้า)
3. ในหน้าต่างด้านข้างที่เปิดขึ้น คุณสามารถทำเครื่องหมายเลือกหรือยกเลิกการเลือกคลังสินค้าที่ต้องการให้สินค้านี้มีอยู่ได้
4. เมื่อดำเนินการเสร็จเรียบร้อยแล้ว ให้คลิกปุ่ม **Save** (บันทึก)

![ฟอร์มจัดการคลังสินค้า](https://res.cloudinary.com/dza7lstvk/image/upload/v1739883050/User%20Guide/Screenshot_2025-02-18_at_2.50.41_PM_zxtz8k.png)

### จัดการจำนวนสินค้าพร้อมจำหน่าย

หากต้องการจัดการจำนวนสินค้าในคลัง (In-stock Quantity) ของคลังสินค้าที่เลือก:

1. ไปที่หน้ารายละเอียดของสินค้าคงคลัง
2. ในส่วน "Locations" (คลังสินค้า) ให้ค้นหาคลังสินค้าที่คุณต้องการแก้ไขจำนวนสินค้าในคลัง จากนั้นคลิกไอคอน <InlineIcon Icon={EllipsisHorizontal} alt="three-dots" /> ที่ท้ายแถว
3. เลือก **Edit** (แก้ไข) จากเมนูแบบดึงลง
4. ในหน้าต่างด้านข้างที่เปิดขึ้น คุณสามารถกรอกตัวเลขแก้ไขจำนวนสินค้าในคลังสินค้าดังกล่าวได้
5. เมื่อดำเนินการเสร็จเรียบร้อยแล้ว ให้คลิกปุ่ม **Save** (บันทึก)

![ฟอร์มจัดการจำนวนสินค้าคงคลัง](https://res.cloudinary.com/dza7lstvk/image/upload/v1739883219/User%20Guide/Screenshot_2025-02-18_at_2.52.33_PM_jvax7o.png)

### จัดการรายการจองของสินค้าคงคลัง

สินค้าคงคลังอาจมีรายการจองเกิดขึ้นเมื่อตัวเลือกสินค้า (Variant) ที่เกี่ยวข้องได้รับการซื้อแต่ยังไม่ถูกจัดส่ง การจองสินค้าจะช่วยให้มั่นใจได้ว่ามีสินค้าในปริมาณที่กำหนดพร้อมส่งเมื่อคำสั่งซื้อได้รับการประมวลผล

คุณสามารถจัดการการจองสินค้าทั้งหมดได้จาก [หน้าการจองสินค้า](../reservations/page.mdx) หรือจัดการเฉพาะรายการการจองของสินค้าคงคลังชิ้นนี้โดยตรงผ่านทางหน้ารายละเอียดของสินค้านั้นเอง

### สร้างการจองสินค้า

หากต้องการสร้างการจองสำหรับสินค้าคงคลังนี้:

1. ไปที่หน้ารายละเอียดของสินค้าคงคลัง
2. ในส่วน "Reservations" (การจองสินค้า) ให้คลิกปุ่ม **Create** (สร้าง)
3. ในแบบฟอร์มที่เปิดขึ้น:
    - ในช่อง Location (คลังสินค้า) ให้เลือกสถานที่ที่ต้องการจองสินค้า
    - เมื่อเลือกคลังสินค้าแล้ว ให้ระบุจำนวนที่ต้องการจองในช่อง Quantity (จำนวน)
        - ตารางเหนือช่องข้อมูลจะแสดงจำนวนสินค้าคงเหลือที่พร้อมจำหน่ายในคลังสินค้าที่เลือก เมื่อมีการแก้ไขค่าจำนวน ตัวเลขในตารางจะอัปเดตเพื่อแสดงความพร้อมจำหน่ายใหม่ทันที
    - ระบุรายละเอียดของการจองได้เพิ่มเติมในช่องคำอธิบาย (ระบุหรือไม่ก็ได้)
4. เมื่อดำเนินการเสร็จเรียบร้อยแล้ว ให้คลิกปุ่ม **Create** (สร้าง)

![ฟอร์มสร้างการจองสินค้าคงคลัง](https://res.cloudinary.com/dza7lstvk/image/upload/v1739884917/User%20Guide/Screenshot_2025-02-18_at_2.58.41_PM_d8tgpb.png)

หากต้องการแก้ไขรายละเอียดการจองสำหรับสินค้าคงคลังนี้:

2. ในส่วน "Reservations" (การจองสินค้า) ให้ค้นหาการจองที่คุณต้องการแก้ไข จากนั้นคลิกไอคอน <InlineIcon Icon={EllipsisHorizontal} alt="three-dots" /> ที่ท้ายแถว
3. เลือก **Edit** (แก้ไข) จากเมนูแบบดึงลง
4. ในหน้าต่างด้านข้างที่เปิดขึ้น คุณสามารถแก้ไขคลังสินค้า จำนวนการจอง และคำอธิบายได้
5. เมื่อดำเนินการเสร็จเรียบร้อยแล้ว ให้คลิกปุ่ม **Save** (บันทึก)

![ฟอร์มแก้ไขการจองสินค้าคงคลัง](https://res.cloudinary.com/dza7lstvk/image/upload/v1739884918/User%20Guide/Screenshot_2025-02-18_at_3.21.36_PM_vjp0eo.png)

### ลบการจองสินค้า

<Note type="warning">

การลบรายการจองสินค้าจะไม่สามารถย้อนกลับหรือกู้คืนได้ หากคุณลบรายการจองสินค้าที่สร้างขึ้นสำหรับคำสั่งซื้อ คุณอาจจำเป็นต้อง [จัดสรรสินค้าในคำสั่งซื้อนั้นใหม่อีกครั้ง](../../orders/manage/page.mdx#allocate-order-items-manually)

</Note>

หากต้องการลบการจองสำหรับสินค้าคงคลังนี้:

1. ไปที่หน้ารายละเอียดของสินค้าคงคลัง
2. ในส่วน "Reservations" (การจองสินค้า) ให้ค้นหาการจองที่คุณต้องการลบ จากนั้นคลิกไอคอน <InlineIcon Icon={EllipsisHorizontal} alt="three-dots" /> ที่ท้ายแถว
3. เลือก **Delete** (ลบ) จากเมนูแบบดึงลง
4. ยืนยันการลบรายการโดยคลิกปุ่ม **Delete** (ลบ) ในป๊อปอัปแจ้งเตือน

## ลบสินค้าคงคลัง

<Note type="warning">

การลบรายการสินค้าคงคลังเป็นแบบถาวรและไม่สามารถย้อนกลับได้ ซึ่งการดำเนินการนี้อาจส่งผลกระทบต่อข้อมูลคลังสินค้าของตัวเลือกสินค้า (Variants) ที่เกี่ยวข้องได้

</Note>

หากต้องการลบสินค้าคงคลัง:

1. ไปที่หน้า **Inventory** (สินค้าคงคลัง) จากเมนูด้านข้าง
2. ค้นหารายการสินค้าคงคลังที่ต้องการลบ จากนั้นคลิกไอคอน <InlineIcon Icon={EllipsisHorizontal} alt="three-dots" /> ในแถวของรายการนั้น
3. เลือก **Delete** (ลบ) จากเมนูแบบดึงลง
4. ยืนยันการลบโดยคลิกปุ่ม **Delete** (ลบ) ในป๊อปอัปแจ้งเตือน
