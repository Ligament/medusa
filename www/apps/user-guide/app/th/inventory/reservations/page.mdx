# {metadata.title}

ในคู่มือนี้ คุณจะได้เรียนรู้วิธีจัดการการจองสินค้า (Reservations) ในร้านค้าของคุณ

## การจองสินค้าคืออะไร?

การจองสินค้าคือการระบุจำนวนสินค้าคงคลังที่ถูกสำรองไว้ ระบบ Medusa จะทำการสร้างการจองสินค้าโดยอัตโนมัติสำหรับสินค้าคงคลังเมื่อมีคำสั่งซื้อตัวเลือกสินค้า (Variant) นั้นๆ ซึ่งจะช่วยให้มั่นใจได้ว่าสินค้าชิ้นดังกล่าวจะไม่ถูกขายให้กับลูกค้ารายอื่นในขณะที่คำสั่งซื้อกำลังอยู่ในระหว่างการประมวลผล และเมื่อดำเนินการจัดส่งสินค้าในคำสั่งซื้อเรียบร้อยแล้ว รายการการจองสินค้าจะถูกลบออกไป

คุณสามารถสร้างการจองสินค้าด้วยตนเองได้ด้วยเช่นกัน ตัวอย่างเช่น การจองจำนวนสินค้าคงคลังสำหรับช่องทางการขายออฟไลน์ หรือการจองสำหรับลูกค้าที่ติดต่อขอจองสินค้าไว้

### ดูการจองสินค้า

หากต้องการดูรายการจองสินค้า ให้ไปที่ **Inventory** (สินค้าคงคลัง) จากแถบเมนูด้านข้าง จากนั้นคลิกเมนูย่อย **Reservations** (การจองสินค้า) ที่แสดงในแถบข้าง

ในรายการ คุณจะเห็นรายละเอียดของการจองสินค้า เช่น รหัส SKU และจำนวนสินค้าที่จองไว้ คุณยังสามารถค้นหา กรอง และจัดเรียงรายการการจองสินค้าเพื่อหารายการที่ต้องการได้อย่างรวดเร็ว

## สร้างการจองสินค้า

หากต้องการสร้างการจองสินค้าด้วยตนเอง:

1. ไปที่ **Inventory** (สินค้าคงคลัง) > **Reservations** (การจองสินค้า)
2. คลิกปุ่ม **Create** (สร้าง) ที่ส่วนหัวข้อหลัก
3. ในแบบฟอร์มที่เปิดขึ้น:
    - ในช่อง "Item to reserve" (สินค้าที่จะจอง) ให้กรอกหรือเลือก SKU ของสินค้าที่ต้องการสร้างการจอง
    - ในช่อง "Location" (คลังสินค้า) ให้เลือกสถานที่ที่ต้องการสร้างการจองสินค้า
    - ระบุจำนวนที่จะจองในช่อง "Quantity" (จำนวน)
        - ตารางเหนือช่องข้อมูลจะแสดงจำนวนสินค้าที่พร้อมใช้งานในคลังสินค้าที่เลือก เมื่อคุณปรับเปลี่ยนค่าในช่องจำนวน ข้อมูลสินค้าพร้อมใช้งานในตารางจะอัปเดตตามการเปลี่ยนแปลงโดยอัตโนมัติ
    - คุณสามารถกรอกรายละเอียดเพิ่มเติมในช่อง Description (คำอธิบาย) (ระบุหรือไม่ก็ได้)
4. เมื่อดำเนินการเสร็จเรียบร้อยแล้ว ให้คลิกปุ่ม **Create** (สร้าง)

## ดูรายละเอียดการจองสินค้า

หากต้องการดูรายละเอียดของการจองสินค้า:

1. ไปที่ **Inventory** (สินค้าคงคลัง) > **Reservations** (การจองสินค้า)
2. คลิกการจองสินค้าที่คุณต้องการดู

หน้ารายละเอียดของการจองสินค้าจะเปิดขึ้น

## แก้ไขการจองสินค้า

หากต้องการแก้ไขการจองสินค้า:

1. ไปที่ **Inventory** (สินค้าคงคลัง) > **Reservations** (การจองสินค้า)
2. ค้นหารายการจองสินค้าที่ต้องการแก้ไข จากนั้นคลิกไอคอน <InlineIcon Icon={EllipsisHorizontal} alt="three-dots" /> ในแถวของรายการนั้น
3. เลือก **Edit** (แก้ไข) จากเมนูแบบดึงลง
4. ในหน้าต่างด้านข้างที่เปิดขึ้น คุณสามารถแก้ไขคลังสินค้า จำนวนการจอง และคำอธิบายได้
5. เมื่อดำเนินการเสร็จเรียบร้อยแล้ว ให้คลิกปุ่ม **Save** (บันทึก)

![ฟอร์มแก้ไขการจองสินค้า](https://res.cloudinary.com/dza7lstvk/image/upload/v1739884918/User%20Guide/Screenshot_2025-02-18_at_3.21.36_PM_vjp0eo.png)

## แก้ไขข้อมูลเมตาของการจองสินค้า

ข้อมูลเมตา (Metadata) คือข้อมูลที่กำหนดเองซึ่งสามารถเชื่อมโยงกับการจองสินค้าในรูปแบบคู่คีย์-ค่า (Key-Value) โดยทั่วไปนักพัฒนาจะใช้ในส่วนนี้สำหรับการเชื่อมต่อข้อมูลแบบกำหนดเอง หรือสำหรับจัดเก็บข้อมูลเพิ่มเติมเกี่ยวกับการจองสินค้า

หากต้องการแก้ไขข้อมูลเมตาของการจองสินค้า:

1. ไปที่หน้ารายละเอียดการจองสินค้า
2. คลิกไอคอน <InlineIcon Icon={ArrowUpRightOnBox} alt="arrow" /> ในส่วน "Metadata" (ข้อมูลเมตา)
3. ในหน้าต่างด้านข้างที่เปิดขึ้น:
    - จัดการคู่คีย์-ค่าในตาราง
    - หากต้องการเพิ่มแถวคู่คีย์-ค่าใหม่ก่อนหน้าหรือถัดจากแถวที่มีอยู่:
        - วางเมาส์เหนือแถวที่ต้องการแล้วคลิกไอคอน <InlineIcon Icon={EllipsisVertical} alt="three-dots" /> ที่ท้ายแถว
        - เลือก "Insert row above" (แทรกแถวด้านบน) หรือ "Insert row below" (แทรกแถวด้านล่าง) จากเมนูดึงลง
    - หากต้องการลบแถวคู่คีย์-ค่าออก:
        - วางเมาส์เหนือแถวที่ต้องการแล้วคลิกไอคอน <InlineIcon Icon={EllipsisVertical} alt="three-dots" /> ที่ท้ายแถว
        - เลือก "Delete row" (ลบแถว) จากเมนูแบบดึงลง
4. เมื่อดำเนินการเสร็จเรียบร้อยแล้ว ให้คลิกปุ่ม **Save** (บันทึก)

## ลบการจองสินค้า

<Note type="warning">

การลบรายการจองสินค้าจะไม่สามารถย้อนกลับหรือกู้คืนได้ หากคุณลบการจองสินค้าที่สร้างขึ้นสำหรับคำสั่งซื้อ คุณอาจจำเป็นต้อง [จัดสรรสินค้าในคำสั่งซื้อนั้นใหม่อีกครั้ง](../../orders/manage/page.mdx#allocate-order-items-manually)

</Note>

หากต้องการลบการจองสินค้า:

1. ไปที่ **Inventory** (สินค้าคงคลัง) > **Reservations** (การจองสินค้า)
2. ค้นหารายการจองสินค้าที่ต้องการลบ จากนั้นคลิกไอคอน <InlineIcon Icon={EllipsisHorizontal} alt="three-dots" /> ในแถวของรายการนั้น
3. เลือก **Delete** (ลบ) จากเมนูแบบดึงลง
4. ยืนยันการลบการจองสินค้าโดยคลิกปุ่ม **Delete** (ลบ) ในป๊อปอัปแจ้งเตือน
