# {metadata.title}

ส่วนงานสินค้าคงคลัง (Inventory) ช่วยให้คุณสามารถจัดการรายการสินค้าคงคลัง, กำหนดจำนวนสินค้าคงเหลือในคลังสินค้าต่างๆ และจัดการรายการจองสินค้าได้

เมื่อเปิดใช้ตัวเลือก "Manage Inventory" (จัดการสินค้าคงคลัง) สำหรับตัวเลือกสินค้า (Product Variant) ระบบจะสร้างรายการสินค้าคงคลังขึ้นมาเพื่อใช้จัดการจำนวนสินค้าของตัวเลือกนั้น คุณสามารถสร้างรายการสินค้าคงคลังไว้ล่วงหน้าแล้วค่อยนำมาเชื่อมโยงกับตัวเลือกสินค้าในภายหลังได้ ซึ่งจะมีประโยชน์อย่างมากสำหรับสินค้าแบบ [ประกอบหลายชิ้น (Multi-part)](../products/create/multi-part/page.mdx) และสินค้าแบบ [ชุดเซ็ต (Bundled)](../products/create/bundle/page.mdx)

คุณสามารถดูรายการสินค้าคงคลังทั้งหมดในร้านค้าอีคอมเมิร์ซของคุณได้โดยคลิกที่ **Inventory** จากเมนูด้านข้าง

ในรายการนี้ คุณจะเห็นรายละเอียดของคลังสินค้า เช่น ชื่อรายการสินค้า รหัส SKU และจำนวนสินค้าคงคลังที่มีอยู่จริงในระบบ คุณยังสามารถค้นหา กรอง และจัดเรียงสินค้าคงคลังเพื่อหารายการที่ต้องการได้อย่างรวดเร็ว

</Note>
