# {metadata.title}

ในคู่มือนี้ คุณจะได้เรียนรู้วิธีดูและจัดการแคมเปญ

## แคมเปญคืออะไร?

แคมเปญคือกลุ่มของโปรโมชันที่เกี่ยวข้องกับเป้าหมายทางการตลาดหรือยอดขายที่เฉพาะเจาะจง แคมเปญยังช่วยให้คุณควบคุมการใช้งานโปรโมชันได้อย่างละเอียด โดยสามารถตั้งค่าวันที่เริ่มต้นและสิ้นสุด รวมถึงการใช้จ่ายงบประมาณแคมเปญ ซึ่งเมื่อใช้งานเกินขีดจำกัดแล้ว โปรโมชันทั้งหมดในแคมเปญจะไม่สามารถใช้ได้อีกต่อไป

---

## ดูแคมเปญ

หากต้องการดูแคมเปญทั้งหมดในร้านค้าของคุณ ให้ไปที่ **Promotions** (โปรโมชัน) > **Campaigns** (แคมเปญ) จากเมนูด้านข้าง

ในรายการนี้ คุณจะเห็นรายละเอียดของแคมเปญ เช่น ชื่อ คำอธิบาย และตัวระบุแคมเปญ คุณยังสามารถค้นหา กรอง และจัดเรียงแคมเปญเพื่อหารายการที่ต้องการได้อย่างรวดเร็ว

<Note title="คำแนะนำ">

ศึกษาวิธีการใช้งานรายการต่างๆ อย่างมีประสิทธิภาพได้ใน [คู่มือนี้](../../tips/lists/page.mdx)

</Note>

## สร้างแคมเปญ

หากต้องการสร้างแคมเปญ:

1. ไปที่ **Promotions** (โปรโมชัน) > **Campaigns** (แคมเปญ) จากเมนูด้านข้าง
2. คลิกปุ่ม **Create** (สร้าง) ที่ส่วนหัวข้อหลัก
3. ในแบบฟอร์มที่เปิดขึ้น:
    - กรอกชื่อแคมเปญและตัวระบุแคมเปญในช่องที่กำหนด
    - ใส่คำอธิบายในช่อง Description (คำอธิบาย) (ระบุหรือไม่ก็ได้)
    - กำหนดวันที่เริ่มต้นในช่อง "Start date" (วันที่เริ่มต้น) (ระบุหรือไม่ก็ได้) โดยโปรโมชันในแคมเปญนี้จะสามารถใช้ได้หลังจากวันที่นี้เท่านั้น
    - กำหนดวันที่สิ้นสุดในช่อง "End date" (วันที่สิ้นสุด) (ระบุหรือไม่ก็ได้) โดยโปรโมชันในแคมเปญนี้จะหมดอายุหลังจากวันที่นี้
    - คุณสามารถกำหนดประเภทของงบประมาณแคมเปญได้ดังนี้:
        - **Usage:** จำนวนครั้งสูงสุดที่โปรโมชันในแคมเปญสามารถนำมาใช้งานได้ เมื่อจำนวนการใช้งานเกินขีดจำกัด แคมเปญและโปรโมชันภายในจะหมดอายุการใช้งาน
        - **Spend:** จำนวนเงินรวมสูงสุดที่จะให้ส่วนลดผ่านโปรโมชันต่างๆ ในแคมเปญ เมื่อจำนวนเงินส่วนลดรวมเกินขีดจำกัด แคมเปญและโปรโมชันภายในจะหมดอายุการใช้งาน ทั้งนี้ ตัวเลือกนี้จะไม่สามารถใช้งานได้กับโปรโมชันประเภท "ซื้อ X แถม Y" หรือ "จัดส่งฟรี"
    - หากคุณเลือกประเภท **Spend** ให้เลือกสกุลเงินของงบประมาณในช่อง "Currency"
        - ในภายหลังเมื่อคุณจะเพิ่มโปรโมชันเข้าไปในแคมเปญ โปรโมชันแบบกำหนดจำนวนส่วนลดคงที่จะสามารถเพิ่มเข้าแคมเปญได้ก็ต่อเมื่อมีสกุลเงินตรงกับสกุลเงินงบประมาณของแคมเปญเท่านั้น
    - ในช่อง **Limit** คุณสามารถระบุจำนวนจำกัดของงบประมาณแคมเปญตามประเภทที่คุณเลือกไว้:
        - หากเลือก **Usage** ให้กรอกจำนวนครั้งสูงสุดที่โปรโมชันต่างๆ ในแคมเปญสามารถใช้ได้
        - หากเลือก **Spend** ให้กรอกจำนวนเงินรวมสูงสุดที่จะเป็นส่วนลดผ่านโปรโมชันในแคมเปญ
    - หากคุณเลือกประเภท **Usage** คุณสามารถเลือกจำกัดการใช้งานต่อคนในช่อง **Limit usage per** ได้เพิ่มเติม (ระบุหรือไม่ก็ได้):
        - หากคุณไม่ได้ระบุเงื่อนไข ขีดจำกัดจะมีผลทั่วทั้งระบบ (Global) ตัวอย่างเช่น หากจำกัดไว้ที่ 5 ครั้ง โปรโมชันในแคมเปญนี้จะถูกใช้งานรวมกันได้ทั้งหมดเพียง 5 ครั้งสำหรับทุกคน
        - หากเลือก "Customer" (ลูกค้า) ขีดจำกัดจะมีผลต่อลูกค้าแต่ละรายโดยอิงจากตัวระบุเฉพาะของลูกค้าแต่ละคน ตัวอย่างเช่น หากตั้งจำกัดไว้ที่ 5 ครั้ง ลูกค้าแต่ละคนจะใช้โปรโมชันในแคมเปญนี้ได้คนละ 5 ครั้ง
        - หากเลือก "Customer Email" (อีเมลลูกค้า) ขีดจำกัดจะมีผลต่อลูกค้าแต่ละรายโดยอิงจากที่อยู่อีเมลของพวกเขา ตัวอย่างเช่น หากตั้งจำกัดไว้ที่ 5 ครั้ง ลูกค้าแต่ละอีเมลจะใช้โปรโมชันในแคมเปญนี้ได้คนละ 5 ครั้ง
4. เมื่อดำเนินการเสร็จเรียบร้อยแล้ว ให้คลิกปุ่ม **Create** (สร้าง)

<Note>

ช่องข้อมูล **Limit usage per** รองรับตั้งแต่เวอร์ชัน [Medusa Admin v2.11.0](https://github.com/medusajs/medusa/releases/tag/v2.11.0) หากคุณไม่พบตัวเลือกนี้ โปรดแจ้งให้ทีมงานฝ่ายเทคนิคดำเนินการ [อัปเกรดแอปพลิเคชัน Medusa ของคุณ](!docs!/learn/update)

</Note>

## แก้ไขรายละเอียดแคมเปญ

หากต้องการแก้ไขรายละเอียดของแคมเปญ:

1. ไปที่หน้ารายละเอียดของแคมเปญ
2. คลิกไอคอน <InlineIcon Icon={EllipsisHorizontal} alt="three-dots" /> ที่ส่วนหัวข้อแรก
3. เลือก **Edit** (แก้ไข) จากเมนูแบบดึงลง
4. ในหน้าต่างด้านข้างที่เปิดขึ้น คุณสามารถแก้ไขชื่อแคมเปญ คำอธิบาย ตัวระบุแคมเปญ รวมถึงวันที่เริ่มต้นและสิ้นสุดได้
5. เมื่อดำเนินการเสร็จเรียบร้อยแล้ว ให้คลิกปุ่ม **Save** (บันทึก)

![แก้ไขรายละเอียดแคมเปญ](https://res.cloudinary.com/dza7lstvk/image/upload/v1739954855/User%20Guide/Screenshot_2025-02-19_at_10.47.24_AM_c81zgf.png)

## แก้ไขขีดจำกัดงบประมาณแคมเปญ

หากต้องการแก้ไขปริมาณการใช้งานงบประมาณหรือขีดจำกัดการใช้จ่ายของแคมเปญ:

1. ไปที่หน้ารายละเอียดของแคมเปญ
2. คลิกไอคอน <InlineIcon Icon={EllipsisHorizontal} alt="three-dots" /> ที่ส่วนหัวข้อ "Budget Limit" (ขีดจำกัดงบประมาณ)
3. เลือก **Edit** (แก้ไข) จากเมนูแบบดึงลง
4. ในหน้าต่างด้านข้างที่เปิดขึ้น คุณสามารถแก้ไขขีดจำกัดงบประมาณได้
5. เมื่อดำเนินการเสร็จเรียบร้อยแล้ว ให้คลิกปุ่ม **Save** (บันทึก)

![แก้ไขขีดจำกัดงบประมาณแคมเปญ](https://res.cloudinary.com/dza7lstvk/image/upload/v1739955041/User%20Guide/Screenshot_2025-02-19_at_10.50.32_AM_wsvwko.png)

## ข้อมูลในแคมเปญที่ไม่สามารถแก้ไขได้

หลังจากสร้างแคมเปญเรียบร้อยแล้ว คุณจะไม่สามารถแก้ไขข้อมูลต่อไปนี้ได้:

1. ประเภทงบประมาณแคมเปญ (Usage หรือ Spend)
2. สกุลเงินของงบประมาณแคมเปญ (หากงบประมาณเป็นประเภท Spend)
3. เงื่อนไข "จำกัดการใช้งานต่อ" (Limit usage per) ของงบประมาณ (Customer หรือ Customer Email)

หากคุณจำเป็นต้องเปลี่ยนข้อมูลเหล่านี้ ให้ปฏิบัติตามวิธีดังนี้:

1. [ลบแคมเปญ](#ลบแคมเปญ)
2. กำหนดให้แคมเปญหมดอายุโดย [ตั้งวันที่สิ้นสุดให้เป็นอดีต](#แก้ไขรายละเอียดแคมเปญ)

จากนั้น ให้สร้างแคมเปญใหม่ที่มีข้อมูลที่ถูกต้อง แล้ว [เพิ่มโปรโมชันเข้าไปยังแคมเปญดังกล่าว](#จัดการโปรโมชันของแคมเปญ)

## จัดการโปรโมชันของแคมเปญ

คุณสามารถจัดการได้ว่าจะมีโปรโมชันใดอยู่ในแคมเปญบ้างจากหน้ารายละเอียดของแคมเปญ

### เพิ่มโปรโมชันเข้าแคมเปญ

<Note title="คำแนะนำ">

คุณจะเพิ่มเข้าแคมเปญได้เฉพาะโปรโมชันที่ยังไม่ได้ขึ้นอยู่กับแคมเปญอื่นเท่านั้น

</Note>

1. ไปที่หน้ารายละเอียดของแคมเปญ
2. คลิกปุ่ม **Add** (เพิ่ม) ที่ส่วนหัวข้อของส่วน "Promotions"
3. ในรายการที่เปิดขึ้น ให้ทำเครื่องหมายเลือกโปรโมชันที่ต้องการเพิ่มเข้าในแคมเปญ
4. เมื่อดำเนินการเสร็จเรียบร้อยแล้ว ให้คลิกปุ่ม **Save** (บันทึก)

![เพิ่มโปรโมชันเข้าแคมเปญ](https://res.cloudinary.com/dza7lstvk/image/upload/v1739954374/User%20Guide/Screenshot_2025-02-19_at_10.39.17_AM_gvzsjj.png)

### ลบโปรโมชันออกจากแคมเปญ

หากต้องการลบโปรโมชันออกจากแคมเปญ:

1. ไปที่หน้ารายละเอียดของแคมเปญ
2. ในส่วน "Promotions" ให้ทำเครื่องหมายเลือกโปรโมชันที่คุณต้องการลบออกจากแคมเปญ
3. เมื่อเสร็จแล้ว ให้กดปุ่ม <Kbd>R</Kbd> บนคีย์บอร์ด หรือคลิกปุ่ม **Remove** (ลบออก) ที่กึ่งกลางด้านล่างของหน้า
4. ยืนยันการลบโปรโมชันออกจากแคมเปญโดยคลิกปุ่ม **Continue** (ดำเนินการต่อ) ในป๊อปอัปแจ้งเตือน

![ลบโปรโมชันออกจากแคมเปญ](https://res.cloudinary.com/dza7lstvk/image/upload/v1739954706/User%20Guide/Screenshot_2025-02-19_at_10.42.49_AM_zk8mcr.png)

## ลบแคมเปญ

<Note type="warning">

การลบแคมเปญไม่สามารถเรียกคืนข้อมูลได้ และการลบแคมเปญจะไม่ส่งผลให้โปรโมชันภายในแคมเปญนั้นถูกลบไปด้วย

</Note>

หากต้องการลบแคมเปญ:

1. ไปที่หน้ารายละเอียดของแคมเปญ
2. คลิกไอคอน <InlineIcon Icon={EllipsisHorizontal} alt="three-dots" /> ที่ส่วนหัวข้อแรก
3. เลือก **Delete** (ลบ) จากเมนูแบบดึงลง
4. ยืนยันการลบแคมเปญโดยคลิกปุ่ม **Delete** (ลบ) ในป๊อปอัปแจ้งเตือน
