# {metadata.title}

ส่วนลูกค้า (Customers) ช่วยให้คุณสามารถจัดการลูกค้าและกลุ่มลูกค้าในร้านค้าอีคอมเมิร์ซของคุณได้

คุณสามารถจัดการได้ทั้งลูกค้าที่ลงทะเบียนในร้านค้าของคุณและลูกค้าทั่วไป (guest) ที่ทำการสั่งซื้อ นอกจากนี้คุณยังสามารถแบ่งกลุ่มลูกค้าเหล่านี้ออกเป็นกลุ่มเพื่อเสนอ[โปรโมชัน](../promotions/page.mdx)และ[รายการราคา](../price-lists/page.mdx) ที่เฉพาะเจาะจงได้

คุณสามารถดูรายการลูกค้าในร้านค้าของคุณได้โดยคลิกที่ Customers จากเมนูแถบข้าง (sidebar)

ในรายการนี้ คุณจะเห็นรายละเอียดของลูกค้า เช่น อีเมล ชื่อ และประเภทบัญชี นอกจากนี้คุณยังสามารถค้นหา กรอง และจัดเรียงลูกค้าเพื่อค้นหาลูกค้าที่ต้องการได้

<Note title="เคล็ดลับ">

ค้นหาเคล็ดลับในการใช้งานรายการอย่างมีประสิทธิภาพใน[คู่มือนี้](../tips/lists/page.mdx)

</Note>
