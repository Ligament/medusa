# {metadata.title}

ในคู่มือนี้ คุณจะได้เรียนรู้วิธีสร้างและจัดการกลุ่มลูกค้า

## แบ่งกลุ่มลูกค้าด้วยกลุ่มลูกค้า

กลุ่มลูกค้าเป็นวิธีการแบ่งกลุ่มลูกค้าของคุณตามเกณฑ์ที่กำหนด คุณสามารถใช้กลุ่มลูกค้าเพื่อใช้โปรโมชันหรือเสนอราคาที่แตกต่างกันได้

ตัวอย่างเช่น คุณสามารถสร้างกลุ่มลูกค้า VIP และมอบส่วนลด 10% สำหรับสินค้าทั้งหมดได้ นอกจากนี้คุณยังสามารถสร้างกลุ่มลูกค้าค้าส่งและเสนอสินค้าในราคาพิเศษสำหรับการสั่งซื้อจำนวนมากได้

### ดูรายการกลุ่มลูกค้า

หากต้องการดูกลุ่มลูกค้าทั้งหมด ให้ไปที่หน้า Customers → Customer Groups จากที่นี่ คุณสามารถดูรายการ กรอง และค้นหาผ่านกลุ่มลูกค้าทั้งหมดได้

![Customer Groups List](https://res.cloudinary.com/dza7lstvk/image/upload/v1739888390/User%20Guide/Screenshot_2025-02-18_at_4.19.35_PM_rhhfpx.png)

## สร้างกลุ่มลูกค้า

หากต้องการสร้างกลุ่มลูกค้า:

1. ไปที่หน้า Customers → Customer Groups
2. คลิกปุ่ม Create
3. ในฟอร์มที่เปิดขึ้น ให้กรอกชื่อของกลุ่มลูกค้า
4. คลิกปุ่ม Create

![Create customer group form](https://res.cloudinary.com/dza7lstvk/image/upload/v1739888496/User%20Guide/Screenshot_2025-02-18_at_4.21.18_PM_xzuzxp.png)

## ดูรายละเอียดกลุ่มลูกค้า

หากต้องการดูรายละเอียดของกลุ่มลูกค้า:

1. ไปที่หน้า Customers → Customer Groups
2. คลิกกลุ่มที่คุณต้องการดู

หน้าจอนี้จะเปิดหน้ารายละเอียดของกลุ่มลูกค้าขึ้นมา

![Customer group details page](https://res.cloudinary.com/dza7lstvk/image/upload/v1739888618/User%20Guide/Screenshot_2025-02-18_at_4.23.15_PM_g6mzpc.png)

## แก้ไขกลุ่มลูกค้า

หากต้องการแก้ไขกลุ่มลูกค้า:

1. ไปที่หน้ารายละเอียดของกลุ่มลูกค้า
2. คลิกไอคอน <InlineIcon Icon={EllipsisHorizontal} alt="สามจุด" /> ในหัวข้อของส่วนแรก
3. คลิก Edit ในเมนูแบบดรอปดาวน์
4. ในหน้าต่างด้านข้างที่เปิดขึ้น คุณสามารถแก้ไขชื่อของกลุ่มลูกค้าได้
5. เมื่อเสร็จแล้ว ให้คลิกปุ่ม Save

![Edit Customer Group](https://res.cloudinary.com/dza7lstvk/image/upload/v1739888705/User%20Guide/Screenshot_2025-02-18_at_4.24.50_PM_qex5xs.png)

## จัดการลูกค้าในกลุ่ม

กลุ่มลูกค้าสามารถมีลูกค้าได้หลายคน คุณสามารถเพิ่มหรือลบลูกค้าออกจากกลุ่มลูกค้าได้

### เพิ่มลูกค้าเข้ากลุ่ม

หากต้องการเพิ่มลูกค้าเข้ากลุ่มลูกค้า:

1. ไปที่หน้ารายละเอียดของกลุ่มลูกค้า
2. ในส่วน Customers ให้คลิกปุ่ม Add ในหัวข้อของส่วนนี้
3. เลือกลูกค้าที่คุณต้องการเพิ่มเข้ากลุ่ม
4. เมื่อเสร็จแล้ว ให้คลิกปุ่ม Save

![Add Customers to Group](https://res.cloudinary.com/dza7lstvk/image/upload/v1739888804/User%20Guide/Screenshot_2025-02-18_at_4.26.31_PM_oxfcva.png)

### ลบลูกค้าออกจากกลุ่ม

หากต้องการลบลูกค้าออกจากกลุ่มลูกค้า:

1. ไปที่หน้ารายละเอียดของกลุ่มลูกค้า
2. ในส่วน Customers ให้เลือกลูกค้าที่คุณต้องการลบออกจากกลุ่ม
3. เมื่อเสร็จแล้ว ให้กดปุ่ม <Kbd>R</Kbd> หรือคลิก Remove ที่กึ่งกลางด้านล่างของหน้าจอ
4. ยืนยันการลบลูกค้าโดยคลิกปุ่ม Continue ในป๊อปอัป

![Remove customers from group](https://res.cloudinary.com/dza7lstvk/image/upload/v1739888876/User%20Guide/Screenshot_2025-02-18_at_4.27.42_PM_tghdqi.png)

## แก้ไขเมทาดาตาของกลุ่มลูกค้า

เมทาดาตา (Metadata) คือข้อมูลที่กำหนดเองซึ่งสามารถเชื่อมโยงกับกลุ่มลูกค้าในรูปแบบคู่คีย์-ค่า (key-value pairs) โดยปกติแล้วนักพัฒนาจะใช้วิธีนี้สำหรับการรวมระบบที่กำหนดเองหรือเพื่อจัดเก็บข้อมูลเพิ่มเติมเกี่ยวกับกลุ่มลูกค้า

หากต้องการแก้ไขเมทาดาตาของกลุ่มลูกค้า:

1. ไปที่หน้ารายละเอียดของกลุ่มลูกค้า
2. คลิกไอคอน <InlineIcon Icon={ArrowUpRightOnBox} alt="ลูกศร" /> ในส่วน "Metadata"
3. ในหน้าต่างด้านข้างที่เปิดขึ้น:
    - จัดการคู่คีย์-ค่าในตาราง
    - หากต้องการเพิ่มแถวใหม่ของคู่คีย์-ค่า ก่อนหรือหลังแถวใดแถวหนึ่ง:
        - เลื่อนเมาส์ไปวางเหนือแถวดังกล่าวแล้วคลิกไอคอน <InlineIcon Icon={EllipsisVertical} alt="สามจุด" /> ที่ส่วนท้ายของแถว
        - เลือก "Insert row above" หรือ "Insert row below" จากเมนูแบบดรอปดาวน์
    - หากต้องการลบแถวของคู่คีย์-ค่า:
        - เลื่อนเมาส์ไปวางเหนือแถวดังกล่าวแล้วคลิกไอคอน <InlineIcon Icon={EllipsisVertical} alt="สามจุด" /> ที่ส่วนท้าย of แถว
        - เลือก "Delete row" จากเมนูแบบดรอปดาวน์
4. เมื่อเสร็จแล้ว ให้คลิกปุ่ม Save

## ลบกลุ่มลูกค้า

<Note type="warning">

การลบกลุ่มลูกค้าไม่สามารถย้อนกลับได้ การดำเนินการนี้ไม่ได้เป็นการลบลูกค้าที่อยู่ในกลุ่มดังกล่าว

</Note>

หากต้องการลบกลุ่มลูกค้า:

1. ไปที่หน้ารายละเอียดของกลุ่มลูกค้า
2. คลิกไอคอน <InlineIcon Icon={EllipsisHorizontal} alt="สามจุด" /> ในหัวข้อของส่วนแรก
3. เลือก Delete จากเมนูแบบดรอปดาวน์
4. ยืนยันการลบกลุ่มลูกค้าโดยคลิกปุ่ม Delete ในป๊อปอัป
