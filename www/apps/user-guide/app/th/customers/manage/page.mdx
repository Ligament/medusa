ในคู่มือนี้ คุณจะได้เรียนรู้วิธีสร้างและจัดการลูกค้าพร้อมทั้งรายละเอียดของลูกค้า

## สร้างลูกค้า

คุณสามารถสร้างลูกค้าผ่าน Medusa Admin ได้ ซึ่งมีประโยชน์ในกรณีที่ลูกค้าทำรายการสั่งซื้อแบบออฟไลน์ โดยลูกค้ารายนี้จะมีสถานะเป็นลูกค้าทั่วไป (guest) หากต้องการลงทะเบียน ลูกค้าจะต้องลงทะเบียนผ่านทางหน้าร้าน (storefront)

ขั้นตอนการสร้างลูกค้าจาก Medusa Admin:

1. ไปที่หน้า Customers
2. คลิกปุ่ม Create ในหัวข้อของส่วนหลัก
3. ในฟอร์มที่เปิดขึ้น ให้กรอกอีเมลของลูกค้า และสามารถเลือกกรอกชื่อ นามสกุล ชื่อบริษัท และเบอร์โทรศัพท์เพิ่มเติมได้
4. เมื่อเสร็จแล้ว ให้คลิกปุ่ม Create

## แก้ไขรายละเอียดของลูกค้า

<Note>

คุณไม่สามารถแก้ไขรหัสผ่านของลูกค้าจาก Medusa Admin ได้ ลูกค้าจะต้องรีเซ็ตรหัสผ่านผ่านทางหน้าร้าน (storefront) ด้วยตัวเอง

</Note>

ขั้นตอนการแก้ไขรายละเอียดของลูกค้า:

1. ไปที่หน้ารายละเอียดของลูกค้า
2. คลิกไอคอน <InlineIcon Icon={EllipsisHorizontal} alt="สามจุด" /> ในส่วนแรก
3. เลือก Edit จากเมนูแบบดรอปดาวน์
4. ในหน้าต่างด้านข้างที่เปิดขึ้น คุณสามารถแก้ไขอีเมล ชื่อ นามสกุล ชื่อบริษัท และเบอร์โทรศัพท์ของลูกค้าได้
5. เมื่อเสร็จแล้ว ให้คลิกปุ่ม Save

## ดูรายการสั่งซื้อของลูกค้า

คุณสามารถดูรายการสั่งซื้อของลูกค้าได้ในส่วน Orders บนหน้ารายละเอียดของพวกเขา และสามารถดูรายละเอียดของการสั่งซื้อแต่ละรายการได้โดยคลิกที่รายการสั่งซื้อนั้น ๆ

### โอนย้ายการสั่งซื้อไปยังลูกค้าคนอื่น

คุณสามารถโอนย้ายการสั่งซื้อไปยังลูกค้าคนอื่นได้ เช่น กรณีที่ลูกค้าทั่วไปได้ทำการลงทะเบียนในภายหลัง หรือลูกค้าสร้างการสั่งซื้อแบบออฟไลน์

เมื่อคุณโอนย้ายความเป็นเจ้าของรายการสั่งซื้อ ลูกค้าเดิมจะได้รับข้อความแจ้งเตือน เช่น อีเมล เพื่อขออนุมัติการโอนย้าย รายการสั่งซื้อจะถูกโอนไปยังลูกค้าคนใหม่หลังจากที่ลูกค้าเดิมอนุมัติการโอนย้ายแล้วเท่านั้น

<Note>

คุณไม่สามารถโอนย้ายความเป็นเจ้าของรายการสั่งซื้อไปยังลูกค้าทั่วไป (guest) ได้ ซึ่งรวมถึงลูกค้าที่คุณสร้างผ่านแผงควบคุมหลัก (admin dashboard) ด้วย

</Note>

ขั้นตอนการโอนย้ายความเป็นเจ้าของรายการสั่งซื้อของลูกค้าไปยังผู้อื่น:

1. ไปที่หน้ารายละเอียดของลูกค้า
2. ในส่วน Orders ให้คลิกไอคอน <InlineIcon Icon={EllipsisHorizontal} alt="สามจุด" /> ในแถวของรายการสั่งซื้อนั้น
3. เลือก Transfer ownership จากเมนูแบบดรอปดาวน์
4. ในหน้าต่างด้านข้างที่เปิดขึ้น ให้เลือกลูกค้าที่คุณต้องการโอนย้ายการสั่งซื้อไปให้ในฟิลด์ "New owner"
5. เมื่อเสร็จแล้ว ให้คลิกปุ่ม Save

จากนั้น ลูกค้าเดิมจะได้รับข้อความแจ้งเตือนเพื่อขออนุมัติการโอนย้าย

<Note>

หากไม่มีการส่งข้อความแจ้งเตือน ให้ตรวจสอบกับทีมเทคนิคของคุณเพื่อดีบัก[บริการแจ้งเตือนที่เชื่อมต่ออยู่](!resources!/infrastructure-modules/notification)

</Note>

## จัดการกลุ่มลูกค้าของลูกค้า

คุณสามารถเพิ่มลูกค้าเข้าสู่กลุ่มลูกค้าได้หลายกลุ่ม ช่วยให้คุณสามารถเสนอโปรโมชันหรือราคาที่แตกต่างกันตามกลุ่มที่พวกเขาอยู่ได้

### เพิ่มลูกค้าเข้ากลุ่ม

ขั้นตอนการเพิ่มลูกค้าเข้ากลุ่มลูกค้า:

1. ไปที่หน้ารายละเอียดของลูกค้า
2. ในส่วน "Customer Groups" ให้คลิกปุ่ม "Add"
3. ในรายการที่เปิดขึ้น ให้ทำเครื่องหมายเลือกกลุ่มที่คุณต้องการเพิ่มลูกค้าคนนี้เข้าไป
4. เมื่อเสร็จแล้ว ให้คลิกปุ่ม Save

![Add groups form](https://res.cloudinary.com/dza7lstvk/image/upload/v1739888065/User%20Guide/Screenshot_2025-02-18_at_4.14.13_PM_jntqs2.png)

### ลบลูกค้าออกจากกลุ่ม

ขั้นตอนการลบลูกค้าออกจากกลุ่มลูกค้า:

1. ไปที่หน้ารายละเอียดของลูกค้า
2. ในส่วน "Customer Groups" ให้ทำเครื่องหมายเลือกกลุ่มที่คุณต้องการลบลูกค้าออกจากกลุ่ม
3. เมื่อเสร็จแล้ว ให้กดปุ่ม <Kbd>R</Kbd> หรือคลิก "Remove" ที่กึ่งกลางด้านล่างของหน้าจอ
4. ยืนยันการลบออกจากกลุ่มโดยคลิกปุ่ม "Remove" ในป๊อปอัป

![Remove customer from groups](https://res.cloudinary.com/dza7lstvk/image/upload/v1739888155/User%20Guide/Screenshot_2025-02-18_at_4.15.44_PM_ieqngf.png)

## แก้ไขเมทาดาตาของลูกค้า

เมทาดาตา (Metadata) คือข้อมูลที่กำหนดเองซึ่งสามารถเชื่อมโยงกับลูกค้าในรูปแบบคู่คีย์-ค่า (key-value pairs) โดยปกติแล้วนักพัฒนาจะใช้วิธีนี้สำหรับการรวมระบบที่กำหนดเองหรือเพื่อจัดเก็บข้อมูลเพิ่มเติมเกี่ยวกับลูกค้า

ขั้นตอนการแก้ไขเมทาดาตาของลูกค้า:

1. ไปที่หน้ารายละเอียดของลูกค้า
2. คลิกไอคอน <InlineIcon Icon={ArrowUpRightOnBox} alt="ลูกศร" /> ในส่วน "Metadata"
3. ในหน้าต่างด้านข้างที่เปิดขึ้น:
    - จัดการคู่คีย์-ค่าในตาราง
    - หากต้องการเพิ่มแถวใหม่ของคู่คีย์-ค่า ก่อนหรือหลังแถวใดแถวหนึ่ง:
        - เลื่อนเมาส์ไปวางเหนือแถวดังกล่าวแล้วคลิกไอคอน <InlineIcon Icon={EllipsisVertical} alt="สามจุด" /> ที่ส่วนท้ายของแถว
        - เลือก "Insert row above" หรือ "Insert row below" จากเมนูแบบดรอปดาวน์
    - หากต้องการลบแถวของคู่คีย์-ค่า:
        - เลื่อนเมาส์ไปวางเหนือแถวดังกล่าวแล้วคลิกไอคอน <InlineIcon Icon={EllipsisVertical} alt="สามจุด" /> ที่ส่วนท้ายของแถว
        - เลือก "Delete row" จากเมนูแบบดรอปดาวน์
4. เมื่อเสร็จแล้ว ให้คลิกปุ่ม Save

## จัดการที่อยู่ของลูกค้า

คุณสามารถดูและจัดการที่อยู่ของลูกค้าได้จากส่วน "Addresses" บนหน้ารายละเอียดของพวกเขา สิ่งนี้มีประโยชน์เมื่อคุณต้องการแก้ไขที่อยู่จัดส่งหรือที่อยู่สำหรับเรียกเก็บเงินของลูกค้าในรายการสั่งซื้อ

<Note>

ส่วนที่อยู่และฟีเจอร์การจัดการที่อยู่จะพร้อมใช้งานเฉพาะหลังจากโซนการแทรกนี้เปิดใช้งานตั้งแต่ [Medusa v2.7.0](https://github.com/medusajs/medusa/releases/tag/v2.7.0) เป็นต้นไป

</Note>

### เพิ่มที่อยู่ลูกค้า

ขั้นตอนการเพิ่มที่อยู่ให้กับลูกค้า:

1. ไปที่หน้ารายละเอียดของลูกค้า
2. คลิกที่ปุ่ม "Add" ในหัวข้อของส่วน "Addresses"
3. ในฟอร์มที่เปิดขึ้น ให้กรอกรายละเอียดที่อยู่ ได้แก่ ชื่อเจ้าของที่อยู่, ที่อยู่บรรทัดที่ 1, ห้อง/อพาร์ตเมนต์, รหัสไปรษณีย์, เมือง, ประเทศ, รัฐ/จังหวัด, บริษัท และเบอร์โทรศัพท์
4. เมื่อเสร็จแล้ว ให้คลิกปุ่ม Save

![Add address form](https://res.cloudinary.com/dza7lstvk/image/upload/v1744363680/User%20Guide/Screenshot_2025-04-11_at_12.27.45_PM_h0fkqm.png)

### ลบที่อยู่ลูกค้า

<Note type="warning">

การลบที่อยู่ไม่สามารถย้อนกลับได้

</Note>

ขั้นตอนการลบที่อยู่ลูกค้า:

1. ไปที่หน้ารายละเอียดของลูกค้า
2. ค้นหาที่อยู่ที่ต้องการลบในส่วน "Addresses"
3. คลิกไอคอน <InlineIcon Icon={EllipsisHorizontal} alt="สามจุด" /> ในแถวของที่อยู่นั้น
4. เลือก Delete จากเมนูแบบดรอปดาวน์
5. ในป๊อปอัป ให้ป้อนชื่อที่อยู่แล้วคลิกปุ่ม "Delete"

## ดูบัญชีเครดิตร้านค้าของลูกค้า

<Prerequisites

หากคุณติดตั้งปลั๊กอิน Loyalty ลูกค้าสามารถมี[บัญชีเครดิตร้านค้า](../../loyalty/store-credits/page.mdx) ได้ บัญชีเหล่านี้ช่วยให้คุณสามารถเพิ่มเครดิตให้กับลูกค้าได้ด้วยตนเอง หรือเมื่อคุณทำการคืนเงินสำหรับการสั่งซื้อ ลูกค้าจะสามารถใช้ยอดคงเหลือของเครดิตร้านค้าดังกล่าวในการชำระเงินได้

ขั้นตอนการดูบัญชีเครดิตร้านค้าของลูกค้า:

1. ไปที่หน้ารายละเอียดของลูกค้า
2. ในส่วน "Store Credits" คุณจะเห็นบัญชีเครดิตร้านค้าทั้งหมดที่เชื่อมโยงกับลูกค้า พร้อมทั้งยอดคงเหลือในปัจจุบันและสกุลเงิน

เมื่อคลิกที่บัญชี คุณจะสามารถดูรายละเอียด ประวัติการทำรายการ และเพิ่มเครดิตให้กับบัญชีได้ ดูข้อมูลเพิ่มเติมได้ที่คู่มือ[จัดการเครดิตร้านค้า](../../loyalty/store-credits/manage/page.mdx)
