# {metadata.title}

Medusa Admin มาพร้อมกับการรองรับหลากหลายภาษา การรองรับหลายภาษานี้มีไว้สำหรับส่วนติดต่อผู้ใช้งาน (Interface) ของระบบผู้ดูแลระบบเท่านั้น ไม่รวมถึงเนื้อหาในร้านค้า เช่น คำอธิบายสินค้า

เอกสารนี้จะแสดงรายการภาษาทั้งหมดที่สามารถใช้งานได้ ทั้งภาษาอย่างเป็นทางการและภาษาที่ได้รับการสนับสนุนโดยชุมชน

## วิธีการเปลี่ยนภาษา

หากต้องการเรียนรู้วิธีการเปลี่ยนภาษาของระบบผู้ดูแลระบบ โปรดดูที่คู่มือ [การจัดการโปรไฟล์](../../../settings/profile/page.mdx)

---

## การรองรับการเขียนจากขวาไปซ้าย (RTL)

<Note>

การรองรับภาษาแบบขวาไปซ้าย (RTL) สามารถใช้งานได้ตั้งแต่ [Medusa Admin v2.11.0](https://github.com/medusajs/medusa/releases/tag/v2.11.0) ขึ้นไป หากหน้าแดชบอร์ดของคุณไม่ปรับตามภาษาที่เป็น RTL โปรดติดต่อทีมงานฝ่ายเทคนิคเพื่อ [อัปเกรดแอปพลิเคชัน Medusa ของคุณ](!docs!/learn/update)

</Note>

เมื่อคุณเปลี่ยนภาษาเป็นภาษาที่เขียนจากขวาไปซ้าย (RTL) เช่น ภาษาอาหรับหรือภาษาฮีบรู ส่วนติดต่อผู้ใช้งานของ Medusa Admin จะปรับทิศทางของข้อความและองค์ประกอบการแสดงผลต่างๆ โดยอัตโนมัติ เพื่อให้สอดคล้องกับทิศทางการอ่านเขียนและมอบประสบการณ์การใช้งานที่ดียิ่งขึ้น

---
