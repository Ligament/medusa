# {metadata.title}

ในคู่มือนี้ คุณจะได้เรียนรู้วิธีการใช้รายการตารางใน Medusa Admin อย่างมีประสิทธิภาพเพื่อเรียกดูข้อมูลต่างๆ ในร้านค้าของคุณ

ทุกๆ ส่วนงานใน Medusa Admin เช่น สินค้าหรือคำสั่งซื้อ จะมีมุมมองแบบรายการตารางสำหรับแสดงผลข้อมูลต่างๆ คุณสามารถใช้การกรองขั้นสูง ค้นหาข้อมูล และจัดเรียงข้อมูลในตารางได้

![ภาพรวมรายการตาราง](https://res.cloudinary.com/dza7lstvk/image/upload/v1739538757/User%20Guide/Screenshot_2025-02-14_at_3.07.21_PM_p3vkey.png)

## การกรองข้อมูล

ใช้การกรองเพื่อดึงข้อมูลรายการในตารางที่ตรงกับเกณฑ์เฉพาะที่คุณต้องการ

หากต้องการกรองข้อมูล:

1. คลิกปุ่ม **Add filter** (เพิ่มตัวกรอง) ที่ด้านบนของตาราง
2. จากเมนูแบบดึงลง ให้เลือกเกณฑ์ที่คุณต้องการใช้กรองข้อมูล เช่น Tag (แท็ก)
3. ระบบจะแสดงชุดค่าข้อมูลใหม่สำหรับให้คุณเลือกกรองรายการ ให้เลือกค่าที่คุณต้องการใช้กรอง

หลังจากเลือกค่าแล้ว ตารางจะแสดงเฉพาะรายการข้อมูลที่ตรงกับตัวกรองของคุณเท่านั้น คุณสามารถใช้ตัวกรองหลายตัวร่วมกันได้เช่นกัน

![การเพิ่มตัวกรอง](https://res.cloudinary.com/dza7lstvk/image/upload/v1739538873/User%20Guide/Screenshot_2025-02-14_at_3.13.51_PM_jq7o7f.png)

### การล้างตัวกรอง

หากต้องการล้างตัวกรองทั้งหมดที่ใช้งานอยู่ ให้คลิกที่ลิงก์ **Clear all** (ล้างทั้งหมด) ที่ส่วนท้ายของรายการตัวกรอง

---

## การค้นหาข้อมูล

หากต้องการค้นหารายการในตาราง:

1. คลิกที่ช่องค้นหา (Search) ในส่วนหัวของตาราง
2. ป้อนคำค้นหาของคุณ ข้อมูลในตารางจะอัปเดตแบบเรียลไทม์เพื่อแสดงรายการที่ตรงกับคำค้นหานั้นๆ

![ค้นหาข้อมูล](https://res.cloudinary.com/dza7lstvk/image/upload/v1739540581/User%20Guide/Screenshot_2025-02-14_at_3.42.41_PM_ijhthi.png)

---

## การจัดเรียงข้อมูล

หากต้องการกำหนดค่าการจัดเรียงข้อมูลในตาราง:

1. คลิกปุ่ม <InlineIcon Icon={BarsArrowDown} alt="sort" />
2. เลือกฟิลด์ข้อมูลที่ต้องการใช้จัดเรียง (ตัวอย่างเช่น Created date - วันที่สร้าง) และทิศทางการจัดเรียง (ascending - น้อยไปมาก หรือ descending - มากไปน้อย)

เมื่อคุณคลิกเลือกการตั้งค่าจัดเรียงแบบใหม่ ตารางจะอัปเดตการแสดงผลตามรูปแบบการจัดเรียงที่ระบุทันที

![จัดเรียงข้อมูล](https://res.cloudinary.com/dza7lstvk/image/upload/v1739540693/User%20Guide/Screenshot_2025-02-14_at_3.44.37_PM_roprfq.png)

## การแบ่งหน้าตาราง

รายการตารางใน Medusa Admin จะถูกแบ่งออกเป็นหลายหน้า หากจำนวนรายการทั้งหมดในตารางนั้นมีมากกว่า 20 รายการ

คุณสามารถเปลี่ยนหน้าตารางได้โดยคลิกปุ่ม **Prev** (ก่อนหน้า) และ **Next** (ถัดไป) ที่ด้านล่างสุดของตาราง
