# {metadata.title}

ในคู่มือนี้ คุณจะได้เรียนรู้วิธีการปรับแต่งตารางข้อมูลในแดชบอร์ด Medusa Admin และบันทึกการปรับแต่งของคุณไว้เป็นมุมมองที่นำกลับมาใช้ซ้ำได้

<Note>

มุมมองตารางที่ปรับแต่งได้เป็นฟีเจอร์ทดลอง ซึ่งทีมเทคนิคของคุณต้องเปิดใช้งานในแอปพลิเคชัน Medusa ก่อนที่คุณจะใช้งานได้ หากคุณไม่พบตัวเลือกของมุมมองตามที่อธิบายไว้ในคู่มือนี้ ให้แจ้งทีมเทคนิคของคุณเพื่อ [เปิดใช้งานฟีเจอร์นี้](!resources!/commerce-modules/settings/view-configurations)

</Note>

## มุมมองตารางคืออะไร?

หน้าต่าง ๆ ใน Medusa Admin แสดงข้อมูลของคุณในรูปแบบตาราง เช่น รายการสินค้าหรือรายการคำสั่งซื้อ มุมมองตาราง (table view) คือการปรับแต่งตารางที่ถูกบันทึกไว้ ซึ่งครอบคลุมทั้งคอลัมน์ที่แสดง ลำดับของคอลัมน์ ตัวกรองที่ใช้ การจัดเรียง และคำค้นหา

คุณสามารถสร้างมุมมองส่วนตัวที่มีเพียงคุณเท่านั้นที่มองเห็น และกำหนดมุมมองเริ่มต้นที่มีผลกับทุกคนในทีมของคุณได้

มุมมองมีสองประเภท:

- **มุมมองส่วนตัว (Personal views)**: มุมมองที่คุณสร้างขึ้นและมีเพียงคุณเท่านั้นที่มองเห็น
- **มุมมองเริ่มต้น (Default view)**: มุมมองที่มีผลกับทุกคนในทีมของคุณที่ยังไม่มีมุมมองส่วนตัวของตนเอง

---

## สลับระหว่างมุมมอง

ที่ด้านบนของตารางที่รองรับฟีเจอร์นี้ คุณจะพบแถวของป้ายมุมมอง โดยป้าย **Default** จะมีอยู่เสมอ ตามด้วยป้ายของมุมมองส่วนตัวแต่ละรายการที่คุณมี (ถ้ามี)

หากต้องการสลับไปยังมุมมองอื่น ให้คลิกที่ป้ายของมุมมองนั้น ตารางจะอัปเดตเพื่อแสดงคอลัมน์ ตัวกรอง และการจัดเรียงของมุมมองที่เลือกไว้ ระบบจะบันทึกการเลือกของคุณไว้ ดังนั้นเมื่อคุณเปิดหน้านี้ในครั้งถัดไป ตารางจะแสดงมุมมองเดิม แม้จะเปิดจากอุปกรณ์อื่นก็ตาม

---

## ปรับแต่งตาราง

หากต้องการปรับแต่งตาราง ให้ใช้ตัวควบคุมต่อไปนี้ที่ด้านบนของตาราง:

- <InlineIcon Icon={Adjustments} alt="Columns" />: แสดงหรือซ่อนคอลัมน์ และเปลี่ยนลำดับของคอลัมน์
- <InlineIcon Icon={Funnel} alt="Filters" />: เพิ่มตัวกรองเพื่อจำกัดข้อมูลที่แสดงในตาราง
- <InlineIcon Icon={DescendingSorting} alt="Sorting" />: เปลี่ยนคอลัมน์และทิศทางที่ใช้จัดเรียงตาราง
- **Search**: พิมพ์ในช่องค้นหาเพื่อค้นหาข้อมูลที่ต้องการ

นอกจากนี้ คุณยังปรับขนาดคอลัมน์ได้ด้วยการลากขอบของหัวคอลัมน์นั้น

หลังจากปรับแต่งตารางแล้ว ให้คลิกปุ่ม **Save** เพื่อบันทึกการเปลี่ยนแปลง ปุ่ม **Save** จะแสดงเมนูที่มีตัวเลือกต่อไปนี้ ขึ้นอยู่กับมุมมองที่ใช้งานอยู่:

- **Save as new view**: สร้างมุมมองส่วนตัวใหม่ ระบบจะให้คุณตั้งชื่อมุมมอง หลังจากบันทึกแล้ว มุมมองใหม่จะถูกใช้งานทันทีและปรากฏเป็นป้ายมุมมอง
- **Update view**: อัปเดตมุมมองส่วนตัวที่ใช้งานอยู่ด้วยการเปลี่ยนแปลงของคุณ ตัวเลือกนี้จะปรากฏเมื่อคุณกำลังแก้ไขมุมมองส่วนตัวที่มีอยู่แล้วเท่านั้น
- **Update default for everyone**: บันทึกการเปลี่ยนแปลงของคุณลงในมุมมองเริ่มต้น ซึ่งจะกลายเป็นมุมมองเริ่มต้นใหม่สำหรับทุกคนในทีมของคุณ

---

## รีเซ็ตมุมมองเริ่มต้น

หากคุณอัปเดตมุมมองเริ่มต้นไปแล้วและต้องการย้อนกลับไปใช้คอลัมน์และการตั้งค่าเดิม คุณสามารถรีเซ็ตได้ดังนี้:

1. คลิกขวาที่ป้าย **Default** ที่ด้านบนของตาราง
2. เลือก **Reset to code defaults** จากเมนู
3. ยืนยันการรีเซ็ตในหน้าต่างที่ปรากฏขึ้น

การดำเนินการนี้จะรีเซ็ตมุมมองเริ่มต้นกลับไปใช้คอลัมน์และการตั้งค่าเดิม และมีผลกับทุกคนในทีมของคุณ

---

## จัดการมุมมองส่วนตัว

### เปลี่ยนชื่อมุมมองส่วนตัว

ขั้นตอนการเปลี่ยนชื่อมุมมองส่วนตัว:

1. คลิกขวาที่ป้ายของมุมมองนั้นที่ด้านบนของตาราง
2. เลือก **Edit name** จากเมนู
3. ในเมนูด้านข้างที่เปิดขึ้นมา ให้กรอกชื่อใหม่ของมุมมอง
4. คลิก **Update** เพื่อบันทึกชื่อใหม่

### ลบมุมมองส่วนตัว

<Note type="warning">

การลบมุมมองส่วนตัวไม่สามารถย้อนกลับได้ เมื่อคุณลบมุมมองไปแล้ว จะไม่สามารถกู้คืนได้อีก

</Note>

ขั้นตอนการลบมุมมองส่วนตัว:

1. คลิกขวาที่ป้ายของมุมมองนั้นที่ด้านบนของตาราง
2. เลือก **Delete** จากเมนู
3. ยืนยันการลบในหน้าต่างที่ปรากฏขึ้น
