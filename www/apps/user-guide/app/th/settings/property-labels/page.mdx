# {metadata.title}

ในคู่มือนี้ คุณจะได้เรียนรู้วิธีการจัดการป้ายกำกับคุณสมบัติ (property labels) ใน Medusa Admin

## ป้ายกำกับคุณสมบัติคืออะไร?

ป้ายกำกับคุณสมบัติช่วยให้คุณกำหนดชื่อคอลัมน์ที่แสดงใน [มุมมองตารางที่ปรับแต่งได้](../../tips/table-views/page.mdx) ของ Medusa Admin ได้เอง เมื่อระบบผู้ดูแลระบบสร้างตารางข้อมูลขึ้นมา ระบบจะใช้ป้ายกำกับคุณสมบัติของคุณเป็นชื่อคอลัมน์ ทำให้คุณสามารถใช้คำศัพท์ที่เหมาะกับร้านค้าของคุณได้

ตัวอย่างเช่น คุณสามารถกำหนดป้ายกำกับให้คุณสมบัติ `display_id` ของคำสั่งซื้อเป็น "หมายเลขคำสั่งซื้อ" เพื่อเปลี่ยนชื่อคอลัมน์นั้นในตารางคำสั่งซื้อได้

ป้ายกำกับคุณสมบัติเป็นการตั้งค่าระดับระบบ จึงมีผลกับผู้ใช้งานระบบผู้ดูแลระบบทุกคน และคุณสมบัติแต่ละรายการจะมีป้ายกำกับได้เพียงหนึ่งป้ายเท่านั้น

---

## ดูป้ายกำกับคุณสมบัติ

หากต้องการดูป้ายกำกับคุณสมบัติ ให้ไปที่ Settings → Property Labels ที่หน้านี้ คุณจะเห็นตารางของโมเดลข้อมูลในร้านค้าของคุณ เช่น คำสั่งซื้อและสินค้า

ตารางนี้ประกอบด้วยคอลัมน์ต่อไปนี้:

- Module: ชื่อของโมดูลที่โมเดลข้อมูลนั้นสังกัดอยู่
- Model: ชื่อของโมเดลข้อมูล
- Property Count: จำนวนคุณสมบัติที่โมเดลข้อมูลนั้นมี
- Has Overrides: ระบุว่าคุณได้กำหนดป้ายกำกับเองให้กับคุณสมบัติใดของโมเดลข้อมูลนั้นแล้วหรือไม่

คุณสามารถจัดเรียงรายการตามโมดูลหรือโมเดล เพื่อค้นหาโมเดลข้อมูลที่ต้องการได้

---

## กำหนดป้ายกำกับคุณสมบัติ

ขั้นตอนการกำหนดป้ายกำกับเองให้กับคุณสมบัติของโมเดลข้อมูล:

1. ไปที่ Settings → Property Labels
2. ค้นหาโมเดลข้อมูลที่คุณต้องการกำหนดป้ายกำกับให้กับคุณสมบัติ
3. คลิกไอคอน <InlineIcon Icon={EllipsisHorizontal} alt="three-dots" /> ที่ท้ายแถวของโมเดลข้อมูลนั้น แล้วเลือก Edit
4. ในหน้าต่างที่เปิดขึ้นมา คุณจะเห็นตารางของคุณสมบัติต่าง ๆ ในโมเดลข้อมูลนั้น โดยแต่ละแถวจะมีช่องข้อมูลดังนี้:
    - Field: ชื่อของคุณสมบัติ ช่องนี้เป็นแบบอ่านอย่างเดียว
    - Custom Label: ชื่อที่ต้องการให้แสดงแทนคุณสมบัตินั้นในคอลัมน์ของตารางข้อมูล
    - Description: คำอธิบายของคุณสมบัติ ซึ่งจะกรอกหรือไม่ก็ได้
5. สำหรับคุณสมบัติแต่ละรายการที่คุณต้องการเปลี่ยนชื่อ ให้กรอกค่าในช่อง Custom Label และจะกรอก Description เพิ่มเติมด้วยก็ได้
6. เมื่อเรียบร้อยแล้ว ให้คลิกปุ่ม Save

<Note>

การกรอกคำอธิบายจำเป็นต้องมีป้ายกำกับที่กำหนดเองด้วย หากคุณกรอกคำอธิบายโดยไม่ได้กรอกป้ายกำกับ คุณจะไม่สามารถบันทึกการเปลี่ยนแปลงได้

</Note>

หลังจากบันทึกแล้ว ป้ายกำกับที่คุณกำหนดเองจะแสดงเป็นชื่อคอลัมน์ของตารางข้อมูลของโมเดลข้อมูลนั้นทั่วทั้งระบบผู้ดูแลระบบ

---

## ลบป้ายกำกับคุณสมบัติ

ขั้นตอนการลบป้ายกำกับที่กำหนดเอง:

1. ไปที่ Settings → Property Labels
2. คลิกไอคอน <InlineIcon Icon={EllipsisHorizontal} alt="three-dots" /> ที่ท้ายแถวของโมเดลข้อมูลนั้น แล้วเลือก Edit
3. ดับเบิลคลิกที่ช่อง Custom Label ของคุณสมบัติที่คุณต้องการลบ แล้วลบค่าที่อยู่ในช่องออก และจะลบค่าในช่อง Description ด้วยก็ได้
4. เมื่อเรียบร้อยแล้ว ให้คลิกปุ่ม Save

คอลัมน์ของคุณสมบัตินั้นจะกลับไปใช้ชื่อเริ่มต้นในตารางข้อมูล
