# {metadata.title}

ในคู่มือนี้ คุณจะได้เรียนรู้ว่าภูมิภาค (Regions) คืออะไรและจะจัดการภูมิภาคอย่างไร

## ภูมิภาคคืออะไร?

ภูมิภาค (Region) แสดงถึงประเทศหรือพื้นที่ต่าง ๆ ที่ร้านค้าอีคอมเมิร์ซของคุณให้บริการลูกค้า โดยภูมิภาคหนึ่ง ๆ สามารถครอบคลุมได้หลายประเทศที่ใช้การตั้งค่าเดียวกัน หรืออาจกำหนดให้เจาะจงเฉพาะประเทศเดียวที่มีการตั้งค่าของตนเองก็ได้

แต่ละภูมิภาคจะมีการตั้งค่าของตนเอง เช่น สกุลเงิน ผู้ให้บริการชำระเงิน (payment providers) และผู้ให้บริการจัดส่งสินค้า (fulfillment providers) คุณสามารถตั้งค่าภูมิภาคเพื่อจัดการแง่มุมต่าง ๆ ของร้านค้าตามตำแหน่งที่ตั้งของลูกค้าของคุณได้

### ราคารวมภาษีสำหรับภูมิภาค

ภูมิภาคจะมีการตั้งค่าราคารวมภาษี (tax-inclusive pricing) ซึ่งจะกำหนดวิธีเพิ่มภาษีเข้าไปในราคาสำหรับภูมิภาคดังกล่าว ในระหว่างการชำระเงิน หลังจากที่ Medusa คำนวณภาษีของสินค้าหรือการจัดส่งแล้ว ระบบจะดำเนินการอย่างใดอย่างหนึ่งดังนี้:

- บวกภาษีเพิ่มเข้าไปในราคาสินค้า (ราคาไม่รวมภาษี - tax-exclusive pricing)
- รวมภาษีไว้ในราคาสินค้าแล้ว (ราคารวมภาษี - tax-inclusive pricing)

คุณสามารถจัดการการตั้งค่านี้ได้ในขั้นตอนการสร้างหรืออัปเดตภูมิภาค

## ดูภูมิภาค

หากต้องการดูภูมิภาคต่าง ๆ ในร้านค้าของคุณ ให้ไปที่ Settings → Regions ที่นี่ คุณจะเห็นรายการของภูมิภาคทั้งหมดที่คุณตั้งค่าไว้ในร้านค้าของคุณ นอกจากนี้ยังสามารถค้นหา กรอง และจัดเรียงภูมิภาคเพื่อค้นหาภูมิภาคที่คุณต้องการได้

## สร้างภูมิภาค

ขั้นตอนการสร้างภูมิภาค:

1. ไปที่ Settings → Regions
2. คลิกปุ่ม Create ในหัวข้อของส่วนหลัก
3. ในฟอร์มที่เปิดขึ้น:
    - ในฟิลด์ Name ให้ป้อนชื่อสำหรับภูมิภาค เช่น "Europe"
    - ในฟิลด์ Currency ให้เลือกสกุลเงินของภูมิภาค โดยภูมิภาคหนึ่ง ๆ สามารถมีได้เพียงสกุลเงินเดียวเท่านั้น
    - หากคุณไม่ต้องการให้คำนวณภาษีโดยอัตโนมัติในระหว่างการชำระเงิน คุณสามารถปิดสวิตช์ "Automatic Taxes" ได้ ข้อมูลนี้มีประโยชน์สำหรับนักพัฒนาเป็นหลักและควรได้รับการดูแลโดยทีมเทคนิคของคุณ
    - หากคุณต้องการเปิดใช้งาน [ราคารวมภาษี](#ราคารวมภาษีสำหรับภูมิภาค) ให้เปิดสวิตช์ตั้งค่า "Tax inclusive pricing"
    - ภายใต้ส่วน Countries คุณสามารถเพิ่มประเทศที่เป็นส่วนหนึ่งของภูมิภาคนี้ได้ วิธีเพิ่มประเทศ:
        - คลิกปุ่ม "Add countries"
        - ทำเครื่องหมายเลือกประเทศที่ต้องการเพิ่มเข้ากับภูมิภาค
        - คลิกปุ่ม Save
    - ในฟิลด์ Payment Providers ให้เลือกผู้ให้บริการชำระเงินที่ลูกค้าในภูมิภาคนี้สามารถใช้ชำระเงินสำหรับรายการสั่งซื้อของตนได้
4. เมื่อเสร็จแล้ว ให้คลิกปุ่ม Save

## ดูรายละเอียดภูมิภาค

ขั้นตอนการดูรายละเอียดของภูมิภาค:

1. ไปที่ Settings → Regions
2. คลิกภูมิภาคที่คุณต้องการดู

หน้าจอนี้จะเปิดหน้ารายละเอียดของภูมิภาค ซึ่งคุณสามารถจัดการภูมิภาคดังกล่าวได้ด้วย

![Region details](https://res.cloudinary.com/dza7lstvk/image/upload/v1739968596/User%20Guide/Screenshot_2025-02-19_at_2.36.23_PM_ny7bip.png)

---

## แก้ไขรายละเอียดภูมิภาค

ขั้นตอนการแก้ไขรายละเอียดภูมิภาค:

1. ไปที่หน้ารายละเอียดของภูมิภาค
2. คลิกไอคอน <InlineIcon Icon={EllipsisHorizontal} alt="สามจุด" /> ในหัวข้อของส่วนแรก
3. เลือก Edit จากเมนูแบบดรอปดาวน์
4. ในหน้าต่างด้านข้างที่เปิดขึ้น คุณสามารถแก้ไขชื่อภูมิภาค, สกุลเงิน, ผู้ให้บริการชำระเงิน และการตั้งค่าสำหรับคำนวณภาษีอัตโนมัติรวมถึง [ราคารวมภาษี](#ราคารวมภาษีสำหรับภูมิภาค) ได้
5. เมื่อเสร็จแล้ว ให้คลิกปุ่ม Save

![Edit region details form](https://res.cloudinary.com/dza7lstvk/image/upload/v1739968747/User%20Guide/Screenshot_2025-02-19_at_2.38.54_PM_cqali9.png)

## จัดการประเทศในภูมิภาค

คุณสามารถจัดการประเทศในภูมิภาคเพื่อเพิ่มหรือลบประเทศเหล่านั้นออกจากภูมิภาคได้

### เพิ่มประเทศเข้ากับภูมิภาค

ขั้นตอนการเพิ่มประเทศเข้ากับภูมิภาค:

1. ไปที่หน้ารายละเอียดของภูมิภาค
2. คลิกไอคอน <InlineIcon Icon={EllipsisHorizontal} alt="สามจุด" /> ในหัวข้อของส่วน "Countries"
3. เลือก "Add countries" จากเมนูแบบดรอปดาวน์
4. ในรายการที่เปิดขึ้น ให้ทำเครื่องหมายเลือกประเทศที่คุณต้องการเพิ่มเข้าไปในภูมิภาค
5. เมื่อเสร็จแล้ว ให้คลิกปุ่ม Add

### ลบประเทศออกจากภูมิภาค

ขั้นตอนการลบประเทศออกจากภูมิภาค:

1. ไปที่หน้ารายละเอียดของภูมิภาค
2. ภายใต้ส่วน "Countries" ให้ทำเครื่องหมายเลือกประเทศที่คุณต้องการลบออกจากภูมิภาค
3. กดปุ่ม <Kbd>R</Kbd> หรือคลิกปุ่ม Remove ที่กึ่งกลางด้านล่างของหน้าจอ
4. ยืนยันการลบประเทศโดยพิมพ์คำว่า "Remove" ในป๊อปอัปแล้วคลิกปุ่ม Remove

![Remove countries from region](https://res.cloudinary.com/dza7lstvk/image/upload/v1739968984/User%20Guide/Screenshot_2025-02-19_at_2.42.51_PM_ol6mvj.png)

## จัดการเมทาดาตาของภูมิภาค

เมทาดาตา (Metadata) คือข้อมูลที่กำหนดเองซึ่งสามารถเชื่อมโยงกับภูมิภาคในรูปแบบคู่คีย์-ค่า (key-value pairs) โดยปกติแล้วนักพัฒนาจะใช้วิธีนี้สำหรับการรวมระบบที่กำหนดเองหรือเพื่อจัดเก็บข้อมูลเพิ่มเติมเกี่ยวกับภูมิภาค

ขั้นตอนการแก้ไขเมทาดาตาของภูมิภาค:

1. คลิกไอคอน <InlineIcon Icon={ArrowUpRightOnBox} alt="ลูกศร" /> ในส่วน "Metadata"
2. ในหน้าต่างด้านข้างที่เปิดขึ้น:
    - จัดการคู่คีย์-ค่าในตาราง
    - หากต้องการเพิ่มแถวใหม่ของคู่คีย์-ค่า ก่อนหรือหลังแถวใดแถวหนึ่ง:
        - เลื่อนเมาส์ไปวางเหนือแถวดังกล่าวแล้วคลิกไอคอน <InlineIcon Icon={EllipsisVertical} alt="สามจุด" /> ที่ส่วนท้ายของแถว
        - เลือก "Insert row above" หรือ "Insert row below" จากเมนูแบบดรอปดาวน์
    - หากต้องการลบแถวของคู่คีย์-ค่า:
        - เลื่อนเมาส์ไปวางเหนือแถวดังกล่าวแล้วคลิกไอคอน <InlineIcon Icon={EllipsisVertical} alt="สามจุด" /> ที่ส่วนท้ายของแถว
        - เลือก "Delete row" จากเมนูแบบดรอปดาวน์
3. เมื่อเสร็จแล้ว ให้คลิกปุ่ม Save

## ลบภูมิภาค

<Note type="warning">

การลบภูมิภาคไม่สามารถย้อนกลับได้

</Note>

ขั้นตอนการลบภูมิภาคออกจากร้านค้าของคุณ:

1. ไปที่หน้ารายละเอียดของภูมิภาค
2. คลิกไอคอน <InlineIcon Icon={EllipsisHorizontal} alt="สามจุด" /> ในหัวข้อของส่วนแรก
3. Choose Delete จากเมนูแบบดรอปดาวน์
4. ยืนยันการลบภูมิภาคโดยพิมพ์ชื่อของภูมิภาคในป๊อปอัปแล้วคลิกปุ่ม Delete
