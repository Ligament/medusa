# {metadata.title}

ในคู่มือนี้ คุณจะได้เรียนรู้วิธีจัดการผู้ใช้ในร้านค้าของคุณ

<Note title="เคล็ดลับ">

คุณไม่สามารถสร้างผู้ใช้ได้โดยตรง แต่คุณจำเป็นต้อง[เชิญพวกเขา](./invites/page.mdx)เข้าร่วมร้านค้าของคุณ

</Note>

## ดูผู้ใช้

คุณสามารถดูผู้ใช้งานที่เป็นผู้ดูแลระบบ (admin users) ได้โดยไปที่ Settings → Users ในรายการนี้ คุณจะเห็นรายละเอียดของผู้ใช้ เช่น ชื่อและอีเมล นอกจากนี้คุณยังสามารถค้นหา กรอง และจัดเรียงผู้ใช้เพื่อค้นหาผู้ใช้ที่ต้องการได้

![Users List](https://res.cloudinary.com/dza7lstvk/image/upload/v1739964455/User%20Guide/Screenshot_2025-02-19_at_1.27.23_PM_qliac9.png)

## ดูรายละเอียดผู้ใช้

ขั้นตอนการดูรายละเอียดของผู้ใช้:

1. ไปที่ Settings → Users
2. คลิกที่ชื่อผู้ใช้ในรายการ

หน้าจอนี้จะเปิดหน้ารายละเอียดของผู้ใช้ ซึ่งคุณสามารถจัดการผู้ใช้ดังกล่าวได้ด้วย

![User details page](https://res.cloudinary.com/dza7lstvk/image/upload/v1739964575/User%20Guide/Screenshot_2025-02-19_at_1.29.20_PM_lffysp.png)

---

## แก้ไขรายละเอียดของผู้ใช้

ขั้นตอนการแก้ไขรายละเอียดของผู้ใช้ที่เป็นผู้ดูแลระบบ:

1. ไปที่หน้ารายละเอียดของผู้ใช้
2. คลิกไอคอน <InlineIcon Icon={EllipsisHorizontal} alt="สามจุด" /> ในหัวข้อของส่วนแรก
3. เลือก Edit จากเมนูแบบดรอปดาวน์
4. ในหน้าต่างด้านข้างที่เปิดขึ้น คุณสามารถแก้ไขชื่อและนามสกุลของผู้ใช้ได้
5. เมื่อเสร็จแล้ว ให้คลิกปุ่ม Save

![Edit user details form](https://res.cloudinary.com/dza7lstvk/image/upload/v1739964727/User%20Guide/Screenshot_2025-02-19_at_1.31.57_PM_nevurs.png)

## จัดการเมทาดาตาของผู้ใช้

เมทาดาตา (Metadata) คือข้อมูลที่กำหนดเองซึ่งสามารถเชื่อมโยงกับผู้ใช้ในรูปแบบคู่คีย์-ค่า (key-value pairs) โดยปกติแล้วนักพัฒนาจะใช้วิธีนี้สำหรับการรวมระบบที่กำหนดเองหรือเพื่อจัดเก็บข้อมูลเพิ่มเติมเกี่ยวกับผู้ใช้

ขั้นตอนการแก้ไขเมทาดาตาของผู้ใช้:

1. คลิกไอคอน <InlineIcon Icon={ArrowUpRightOnBox} alt="ลูกศร" /> ในส่วน "Metadata"
2. ในหน้าต่างด้านข้างที่เปิดขึ้น:
    - จัดการคู่คีย์-ค่าในตาราง
    - หากต้องการเพิ่มแถวใหม่ของคู่คีย์-ค่า ก่อนหรือหลังแถวใดแถวหนึ่ง:
        - เลื่อนเมาส์ไปวางเหนือแถวดังกล่าวแล้วคลิกไอคอน <InlineIcon Icon={EllipsisVertical} alt="สามจุด" /> ที่ส่วนท้ายของแถว
        - เลือก "Insert row above" หรือ "Insert row below" จากเมนูแบบดรอปดาวน์
    - หากต้องการลบแถวของคู่คีย์-ค่า:
        - เลื่อนเมาส์ไปวางเหนือแถวดังกล่าวแล้วคลิกไอคอน <InlineIcon Icon={EllipsisVertical} alt="สามจุด" /> ที่ส่วนท้ายของแถว
        - เลือก "Delete row" จากเมนูแบบดรอปดาวน์
3. เมื่อเสร็จแล้ว ให้คลิกปุ่ม Save

## ลบผู้ใช้

<Note>

ฟีเจอร์นี้พร้อมใช้งานตั้งแต่ [Medusa v2.12.0](https://github.com/medusajs/medusa/releases/tag/v2.12.0) เป็นต้นไป หากคุณไม่พบตัวเลือกในการลบผู้ใช้ หรือการลบผู้ใช้ไม่ทำงาน โปรดตรวจสอบว่าได้ทำการ[อัปเกรดแอปพลิเคชัน Medusa ของคุณ](!docs!/learn/update) แล้ว

</Note>

<Note type="warning">

การลบผู้ใช้ไม่สามารถย้อนกลับได้

</Note>

ขั้นตอนการลบผู้ใช้ออกจากร้านค้าของคุณ:

1. ไปที่ Settings → Users
2. ค้นหาผู้ใช้ในรายการแล้วคลิกที่ชื่อผู้ใช้นั้น
3. คลิกไอคอน <InlineIcon Icon={EllipsisHorizontal} alt="สามจุด" /> ในหัวข้อของส่วนแรก
4. เลือก Delete จากเมนูแบบดรอปดาวน์
5. ยืนยันการลบผู้ใช้โดยกรอกชื่อของผู้ใช้คนดังกล่าวแล้วคลิกปุ่ม "Delete" ในป๊อปอัป
