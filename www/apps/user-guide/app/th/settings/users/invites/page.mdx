# {metadata.title}

ในคู่มือนี้ คุณจะได้เรียนรู้วิธีจัดการคำเชิญเข้าร่วมร้านค้าของคุณ

## เพิ่มผู้ใช้งานระบบผ่านคำเชิญ

ในการเพิ่มผู้ใช้ใหม่เข้าทีม คุณต้องส่งคำเชิญให้พวกเขา โดยผู้ใช้จะได้รับข้อความแจ้งเตือนคำเชิญสำหรับสมัครใช้งาน หรือคุณสามารถส่งลิงก์คำเชิญให้พวกเขาสมัครใช้งานด้วยตนเองได้เช่นกัน

<Note title="ผู้ใช้งานระบบ Cloud?">

ตรวจสอบให้แน่ใจว่าคุณได้ตั้งค่า [Medusa Emails](!cloud!/emails) ในโปรเจกต์ Cloud ของคุณแล้วเพื่อส่งอีเมลคำเชิญผู้ใช้งานระบบดูแลระบบ Medusa Emails เป็นบริการจัดการอีเมลแบบสำเร็จรูปที่ช่วยให้คุณส่งอีเมลธุรกรรม (transactional emails) ได้โดยไม่ต้องตั้งค่าคอนฟิกเพิ่มเติม

</Note>

---

## เชิญผู้ใช้

ขั้นตอนการเชิญผู้ใช้:

1. ไปที่ Settings → Users
2. คลิกปุ่ม Invite
3. กรอกอีเมลของผู้ใช้
4. เมื่อเสร็จแล้ว ให้คลิกปุ่ม "Send invite"

![Invite user form](https://res.cloudinary.com/dza7lstvk/image/upload/v1739964961/User%20Guide/Screenshot_2025-02-19_at_1.35.52_PM_rewdrm.png)

## ดูคำเชิญที่รอดำเนินการ

ขั้นตอนการดูคำเชิญที่รอดำเนินการ:

1. ไปที่ Settings → Users
2. คลิกปุ่ม Invite
3. ภายใต้ฟอร์มดังกล่าว คุณจะพบตาราง Pending Invites แสดงคำเชิญทั้งหมดที่ยังไม่ได้รับการยอมรับ

![Pending invites table](https://res.cloudinary.com/dza7lstvk/image/upload/v1739964999/User%20Guide/Screenshot_2025-02-19_at_1.36.30_PM_jvkqcw.png)

## ส่งคำเชิญซ้ำ

คุณสามารถส่งคำเชิญซ้ำได้หากผู้ใช้ไม่ได้รับคำเชิญ ทำลิงก์สูญหาย หรือคำเชิญหมดอายุ

ขั้นตอนการส่งคำเชิญซ้ำให้ผู้ใช้:

1. ไปที่ Settings → Users
2. คลิกปุ่ม Invite
3. ในตาราง Pending Invites ค้นหาผู้ใช้ที่ต้องการส่งคำเชิญซ้ำแล้วคลิกไอคอน <InlineIcon Icon={EllipsisHorizontal} alt="สามจุด" />
4. เลือก "Resend invite" จากเมนูแบบดรอปดาวน์

ระบบจะส่งการแจ้งเตือนไปยังผู้ใช้[ตามที่ทีมเทคนิคของคุณตั้งค่าไว้](!resources!/infrastructure-modules/notification)

---

## รับลิงก์คำเชิญ

นอกเหนือจากการส่งคำเชิญไปยังผู้ใช้แล้ว คุณสามารถคัดลอกลิงก์คำเชิญและส่งให้ผู้ใช้ด้วยตนเองได้ด้วย

ขั้นตอนการคัดลอกลิงก์คำเชิญ:

1. ไปที่ Settings → Users
2. คลิกปุ่ม Invite
3. ในตาราง Pending Invites ค้นหาผู้ใช้ที่ต้องการส่งคำเชิญซ้ำแล้วคลิกไอคอน <InlineIcon Icon={EllipsisHorizontal} alt="สามจุด" />
4. เลือก “Copy invite link” จากเมนูแบบดรอปดาวน์

จากนั้นคุณสามารถส่งลิงก์นี้ให้กับผู้ใช้เพื่อสมัครใช้งานได้

---

## ลบคำเชิญ

<Note type="warning">

การลบคำเชิญจะเป็นการเพิกถอนสิทธิ์คำเชิญ และผู้ใช้จะไม่สามารถสมัครใช้งานผ่านลิงก์คำเชิญนั้นได้อีกต่อไป

</Note>

ขั้นตอนการลบคำเชิญ:

1. ไปที่ Settings → Users
2. คลิกปุ่ม Invite
3. ในตาราง Pending Invites ค้นหาผู้ใช้ที่ต้องการส่งคำเชิญซ้ำแล้วคลิกไอคอน <InlineIcon Icon={EllipsisHorizontal} alt="สามจุด" />
4. เลือก Delete จากเมนูแบบดรอปดาวน์
5. ยืนยันการลบคำเชิญโดยคลิกปุ่ม Delete ในป๊อปอัป
