# {metadata.title}

ในคู่มือนี้ คุณจะได้เรียนรู้วิธีจัดการแท็กสินค้า (Product Tags) ใน Medusa Admin

## ดูแท็กสินค้า

แท็กสินค้าช่วยให้คุณสามารถจัดกลุ่มสินค้าในร้านค้าของคุณด้วยแท็กที่ใช้ร่วมกัน ตัวอย่างเช่น คุณสามารถสร้างแท็กสำหรับ "electronics" (เครื่องใช้ไฟฟ้า) หรือ "clothing" (เสื้อผ้า) และเชื่อมโยงแท็กเหล่านั้นกับสินค้าได้

หากต้องการดูแท็กสินค้าในร้านค้าของคุณ ให้ไปที่ Settings → Product Tags ที่นี่คุณสามารถดูรายการแท็กสินค้าทั้งหมดที่คุณตั้งค่าไว้ในร้านค้าของคุณ นอกจากนี้คุณยังสามารถค้นหา กรอง และจัดเรียงแท็กสินค้าเพื่อค้นหารายการที่คุณต้องการได้

![รายการแท็กสินค้า](https://res.cloudinary.com/dza7lstvk/image/upload/v1739979638/User%20Guide/Screenshot_2025-02-19_at_5.40.18_PM_ymwpfe.png)

## สร้างแท็กสินค้า

วิธีการสร้างแท็กสินค้า:

1. ไปที่ Settings → Product Tags
2. คลิกปุ่ม Create ในส่วนหัวของส่วนหลัก
3. ในฟอร์มที่เปิดขึ้น ให้ป้อนค่าสำหรับแท็กสินค้าในฟิลด์ Value เช่น "Digital"
4. เมื่อเสร็จแล้ว ให้คลิกปุ่ม Create

![ฟอร์มสร้างแท็กสินค้า](https://res.cloudinary.com/dza7lstvk/image/upload/v1739979718/User%20Guide/Screenshot_2025-02-19_at_5.41.39_PM_g3dabk.png)

## ดูรายละเอียดแท็กสินค้า

วิธีการดูรายละเอียดของแท็กสินค้า:

1. ไปที่ Settings → Product Tags
2. คลิกที่แท็กสินค้าจากรายการ

การดำเนินการนี้จะเปิดหน้ารายละเอียดของแท็กสินค้า ซึ่งคุณสามารถจัดการแท็กสินค้าและข้อมูลเมทาดาตาของแท็กได้เช่นกัน

![รายละเอียดแท็กสินค้า](https://res.cloudinary.com/dza7lstvk/image/upload/v1756372959/User%20Guide/CleanShot_2025-08-28_at_12.21.57_2x_op9es5.png)

## แก้ไขรายละเอียดแท็กสินค้า

วิธีการแก้ไขรายละเอียดของแท็กสินค้า:

1. ไปที่หน้ารายละเอียดของแท็กสินค้า
2. คลิกไอคอน <InlineIcon Icon={EllipsisHorizontal} alt="three-dots" /> ในส่วนหัวของส่วนแรก
3. เลือก Edit จากเมนูดรอปดาวน์
4. ในหน้าต่างด้านข้างที่เปิดขึ้น คุณสามารถแก้ไขค่าของแท็กสินค้าได้
5. เมื่อเสร็จแล้ว ให้คลิกปุ่ม Save

![ฟอร์มแก้ไขแท็กสินค้า](https://res.cloudinary.com/dza7lstvk/image/upload/v1739979916/User%20Guide/Screenshot_2025-02-19_at_5.45.04_PM_cso1mj.png)

## จัดการการแปลของแท็กสินค้า

<Note>

ภาษาของระบบ (Locales) มีให้ใช้งานตั้งแต่ [Medusa v2.12.3](https://github.com/medusajs/medusa/releases/tag/v2.12.3) หากคุณไม่เห็นส่วนจัดการการแปลใน Medusa Admin ของคุณ โปรดขอให้ทีมงานฝ่ายเทคนิคของคุณ [อัปเกรดแอปพลิเคชัน Medusa ของคุณ](!docs!/learn/update)

</Note>

แท็กสินค้าสามารถแปลเป็นภาษาต่าง ๆ (Locales) ที่ [ร้านค้าของคุณรองรับ](../store/page.mdx#manage-store-locales) คุณสามารถจัดการการแปล [แบบเป็นกลุ่ม](../translations/page.mdx) หรือจัดการการแปลสำหรับแต่ละแท็กสินค้าจากหน้ารายละเอียดของแท็กสินค้านั้น ๆ ได้

วิธีการจัดการการแปลสำหรับแท็กสินค้า:

1. คลิกที่ไอคอน <InlineIcon Icon={EllipsisHorizontal} alt="three-dots" /> ในส่วนหัวของส่วนแรก
2. เลือก "Manage translations" จากเมนูดรอปดาวน์
3. ใน [เครื่องมือแก้ไขแบบกลุ่ม](../../tips/bulk-editor/page.mdx) ที่เปิดขึ้น คุณสามารถดูและแก้ไขคำแปลสำหรับค่าแท็กสินค้าในแต่ละภาษาที่ร้านค้าของคุณรองรับ
    - หากต้องการแก้ไขข้อความที่มีการรองรับการขึ้นบรรทัดใหม่ ให้ดับเบิ้ลคลิกที่เซลล์นั้น ๆ เพื่อเปิดพื้นที่ป้อนข้อความขนาดใหญ่ขึ้น
4. เมื่อแก้ไขเสร็จแล้ว ให้คลิกปุ่ม Save เพื่อบันทึกการเปลี่ยนแปลง

## จัดการข้อมูลเมทาดาตาของแท็กสินค้า

<Note>

การจัดการข้อมูลเมทาดาตาของแท็กสินค้าถูกเพิ่มเข้ามาใน [Medusa v2.10.0](https://github.com/medusajs/medusa/releases/tag/v2.10.0)

</Note>

ข้อมูลเมทาดาตา (Metadata) คือข้อมูลที่กำหนดเองซึ่งสามารถเชื่อมโยงกับแท็กสินค้าในรูปแบบของคู่คีย์-ค่า (Key-Value) ซึ่งปกติแล้วนักพัฒนาจะใช้สำหรับการผสานระบบแบบกำหนดเองหรือเพื่อจัดเก็บข้อมูลเพิ่มเติมเกี่ยวกับแท็กสินค้า

วิธีการแก้ไขข้อมูลเมทาดาตาของแท็กสินค้า:

1. คลิกไอคอน <InlineIcon Icon={ArrowUpRightOnBox} alt="arrow" /> ในส่วน "Metadata"
2. ในหน้าต่างด้านข้างที่เปิดขึ้น:
    - จัดการคู่คีย์-ค่าในตาราง
    - วิธีการเพิ่มแถวคู่คีย์-ค่าใหม่ก่อนหน้าหรือหลังแถวที่มีอยู่:
        - วางเมาส์เหนือแถวแล้วคลิกไอคอน <InlineIcon Icon={EllipsisVertical} alt="three-dots" /> ที่ส่วนท้ายของแถว
        - เลือก "Insert row above" (แทรกแถวด้านบน) หรือ "Insert row below" (แทรกแถวด้านล่าง) จากเมนูดรอปดาวน์
    - วิธีการลบแถวคู่คีย์-ค่า:
        - วางเมาส์เหนือแถวแล้วคลิกไอคอน <InlineIcon Icon={EllipsisVertical} alt="three-dots" /> ที่ส่วนท้ายของแถว
        - เลือก "Delete row" จากเมนูดรอปดาวน์
3. เมื่อเสร็จแล้ว ให้คลิกปุ่ม Save

## ลบแท็กสินค้า

<Note type="warning">

การลบแท็กสินค้าจะไม่สามารถย้อนกลับคืนได้

</Note>

วิธีการลบแท็กสินค้า:

1. ไปที่หน้ารายละเอียดของแท็กสินค้า
2. คลิกไอคอน <InlineIcon Icon={EllipsisHorizontal} alt="three-dots" /> ในส่วนหัวของส่วนแรก
3. เลือก Delete จากเมนูดรอปดาวน์
4. ยืนยันการลบโดยคลิกปุ่ม Delete ในป๊อปอัป
