# {metadata.title}

ในคู่มือนี้ คุณจะได้เรียนรู้ว่าช่องทางการขาย (Sales Channels) คืออะไรและจะจัดการช่องทางการขายเหล่านั้นใน Medusa Admin อย่างไร

## ช่องทางการขายคืออะไร?

ช่องทางการขาย (Sales Channel) คือช่องทางที่คุณใช้ในการจำหน่ายสินค้าของคุณ ตัวอย่างเช่น คุณสามารถมีช่องทางการขายสำหรับหน้าร้านเว็บ (web storefront), ช่องทางการขายสำหรับแอปมือถือ (mobile app) และอีกช่องทางสำหรับการจำหน่ายสินค้าบนแพลตฟอร์มโซเชียลมีเดีย

คุณสามารถกำหนดช่องทางการขายเริ่มต้นได้ในการ[ตั้งค่าร้านค้า](../store/page.mdx) เพื่อให้ระบบนำไปใช้เมื่อไม่มีการระบุช่องทางการขาย ซึ่งจะมีประโยชน์ในกรณีที่คุณไม่ได้จำหน่ายผ่านช่องทางหลากหลายช่องทาง

### การทำงานของช่องทางการขาย

ช่องทางการขายมีความเชื่อมโยงกับข้อมูลและการตั้งค่าอื่น ๆ ในร้านค้าอีคอมเมิร์ซของคุณ ดังนี้:

- คุณสามารถเลือกสินค้าที่จะแสดงในช่องทางการขายแต่ละช่องทางได้ ซึ่งมีประโยชน์เมื่อคุณจัดหาสินค้าที่แตกต่างกันสำหรับประเภทช่องทางที่ต่างกัน ตัวอย่างเช่น คุณสามารถมีช่องทางการขายแบบ B2B และให้แสดงเฉพาะสินค้า B2B ในช่องทางนั้นเท่านั้น
- เมื่อลูกค้าสั่งซื้อสินค้าจากช่องทางการขายใด ๆ รายการสั่งซื้อนั้นจะเชื่อมโยงเข้ากับช่องทางนั้น ๆ ซึ่งมีประโยชน์หากคุณมีกระบวนการจัดการรายการสั่งซื้อที่แตกต่างกันสำหรับแต่ละช่องทาง เช่น รายการสั่งซื้อที่ทำผ่านหน้าร้านแบบออฟไลน์จะมีกระบวนการจัดการต่างจากหน้าร้านแบบออนไลน์
- สถานที่จัดเก็บสต็อกสินค้า (Stock locations) และตัวเลือกการจัดส่ง (shipping options) ก็เชื่อมโยงอยู่กับช่องทางการขายด้วยเช่นกัน ดังนั้น เมื่อลูกค้าทำรายการสั่งซื้อ สินค้าจะถูกจัดส่งจากสถานที่จัดเก็บสต็อกที่เชื่อมโยงกับช่องทางการขายของรายการสั่งซื้อนั้น

<Note title="เคล็ดลับทางเทคนิค">

นักพัฒนาสามารถใช้ [Publishable API Keys](../developer/secret-api-keys/page.mdx) เพื่อเชื่อมโยงหน้าร้าน (storefront) หรือไคลเอนต์กับช่องทางการขายได้อย่างง่ายดาย

</Note>

## ดูช่องทางการขาย

หากต้องการดูช่องทางการขายในร้านค้าของคุณ ให้ไปที่ Settings → Sales Channels ที่นี่ คุณจะเห็นรายการของช่องทางการขายทั้งหมดที่คุณตั้งค่าไว้ในร้านค้าของคุณ นอกจากนี้ยังสามารถค้นหา กรอง และจัดเรียงช่องทางการขายเพื่อค้นหาช่องทางที่คุณต้องการได้

![Sales channels list](https://res.cloudinary.com/dza7lstvk/image/upload/v1739977340/User%20Guide/Screenshot_2025-02-19_at_5.02.07_PM_pmw1v0.png)

## สร้างช่องทางการขาย

ขั้นตอนการสร้างช่องทางการขาย:

1. ไปที่ Settings → Sales Channels
2. คลิกปุ่ม Create ในหัวข้อของส่วนหลัก
3. ในฟอร์มที่เปิดขึ้น:
    - ในฟิลด์ Name ให้ป้อนชื่อสำหรับช่องทางการขาย เช่น "Web Storefront"
    - ในฟิลด์ Description ให้ป้อนคำอธิบายของช่องทางการขาย
    - หากคุณไม่ต้องการเปิดใช้งานช่องทางการขายในทันที ให้ปิดสวิตช์ตั้งค่า "Enabled"
4. เมื่อเสร็จแล้ว ให้คลิกปุ่ม Save

![Create sales channel form](https://res.cloudinary.com/dza7lstvk/image/upload/v1739977547/User%20Guide/Screenshot_2025-02-19_at_5.05.33_PM_tv88rz.png)

## ดูรายละเอียดช่องทางการขาย

ขั้นตอนการดูรายละเอียดของช่องทางการขาย:

1. ไปที่ Settings → Sales Channels
2. คลิกช่องทางการขายที่ต้องการในรายการ

หน้าจอนี้จะเปิดหน้ารายละเอียดของช่องทางการขาย ซึ่งคุณสามารถจัดการช่องทางการขายดังกล่าวได้ด้วย

![Sales channel details](https://res.cloudinary.com/dza7lstvk/image/upload/v1739977621/User%20Guide/Screenshot_2025-02-19_at_5.06.47_PM_ma6abe.png)

### สถานะของช่องทางการขาย

สถานะของช่องทางการขายจะแสดงในหัวข้อของส่วนแรกในหน้ารายละเอียด โดยสถานะสามารถเป็น "Enabled" (เปิดใช้งาน) หรือ "Disabled" (ปิดใช้งาน) คุณสามารถเปลี่ยนสถานะได้โดย[แก้ไขรายละเอียดช่องทางการขาย](#แก้ไขรายละเอียดช่องทางการขาย)

## แก้ไขรายละเอียดช่องทางการขาย

ขั้นตอนการแก้ไขรายละเอียดช่องทางการขาย:

1. ไปที่หน้ารายละเอียดของช่องทางการขาย
2. คลิกไอคอน <InlineIcon Icon={EllipsisHorizontal} alt="สามจุด" /> ในหัวข้อของส่วนแรก
3. เลือก Edit จากเมนูแบบดรอปดาวน์
4. ในหน้าต่างด้านข้างที่เปิดขึ้น คุณสามารถแก้ไขชื่อช่องทางการขาย, คำอธิบาย และเปลี่ยนสถานะเปิดหรือปิดการใช้งานได้
5. เมื่อเสร็จแล้ว ให้คลิกปุ่ม Save

![Edit sales channel form](https://res.cloudinary.com/dza7lstvk/image/upload/v1739977718/User%20Guide/Screenshot_2025-02-19_at_5.08.25_PM_akoryr.png)

## จัดการสินค้าในช่องทางการขาย

คุณสามารถจัดการสินค้าที่มีอยู่ในช่องทางการขายได้จากหน้ารายละเอียดของช่องทางการขายนั้น ๆ

### เพิ่มสินค้าเข้าสู่ช่องทางการขาย

ขั้นตอนการเพิ่มสินค้าเข้าสู่ช่องทางการขาย:

1. ไปที่หน้ารายละเอียดของช่องทางการขาย
2. คลิกปุ่ม "Add" ในส่วน "Products"
3. ในรายการที่เปิดขึ้น ให้ทำเครื่องหมายเลือกสินค้าที่ต้องการเพิ่มเข้ากับช่องทางการขาย
4. คลิกปุ่ม Save

![Add products to sales channel](https://res.cloudinary.com/dza7lstvk/image/upload/v1739978037/User%20Guide/Screenshot_2025-02-19_at_5.13.37_PM_maqev3.png)

### ลบสินค้าออกจากช่องทางการขาย

ขั้นตอนการลบสินค้าออกจากช่องทางการขาย:

1. ไปที่หน้ารายละเอียดของช่องทางการขาย
2. ภายใต้ส่วน "Products" ให้ทำเครื่องหมายเลือกสินค้าที่คุณต้องการลบออกจากช่องทางการขาย
3. กดปุ่ม <Kbd>R</Kbd> หรือคลิกปุ่ม Remove ที่กึ่งกลางด้านล่างของหน้าจอ
4. ยืนยันการลบสินค้าโดยคลิกปุ่ม Delete ในป๊อปอัป

![Remove products from sales channel](https://res.cloudinary.com/dza7lstvk/image/upload/v1739978128/User%20Guide/Screenshot_2025-02-19_at_5.15.14_PM_vgpur9.png)

## ลบช่องทางการขาย

<Note type="warning">

การลบช่องทางการขายไม่สามารถย้อนกลับได้

</Note>

ขั้นตอนการลบช่องทางการขาย:

1. ไปที่หน้ารายละเอียดของช่องทางการขาย
2. คลิกไอคอน <InlineIcon Icon={EllipsisHorizontal} alt="สามจุด" /> ในหัวข้อของส่วนแรก
3. เลือก Delete จากเมนูแบบดรอปดาวน์
4. ยืนยันการลบช่องทางการขายโดยกรอกชื่อของช่องทางการขายดังกล่าวแล้วคลิกปุ่ม "Delete" ในป๊อปอัป
