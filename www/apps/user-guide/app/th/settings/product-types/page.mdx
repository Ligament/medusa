# {metadata.title}

ในคู่มือนี้ คุณจะได้เรียนรู้วิธีจัดการประเภทสินค้า (Product Types) ใน Medusa Admin

## ดูประเภทสินค้า

ประเภทสินค้ามีประโยชน์ในการจัดกลุ่มสินค้าตามประเภททั่วไป เช่น ประเภทสินค้า "Physical" (สินค้าทั่วไป) และ "Digital" (สินค้าดิจิทัล)

หากต้องการดูประเภทสินค้าในร้านค้าของคุณ ให้ไปที่ Settings → Product Types ที่นี่คุณสามารถดูรายการประเภทสินค้าทั้งหมดที่คุณตั้งค่าไว้ในร้านค้าของคุณ นอกจากนี้คุณยังสามารถค้นหา กรอง และจัดเรียงประเภทสินค้าเพื่อค้นหารายการที่คุณต้องการได้

![รายการประเภทสินค้า](https://res.cloudinary.com/dza7lstvk/image/upload/v1739978497/User%20Guide/Screenshot_2025-02-19_at_5.21.04_PM_dcux4c.png)

---

## สร้างประเภทสินค้า

วิธีการสร้างประเภทสินค้า:

1. ไปที่ Settings → Product Types
2. คลิกปุ่ม Create ในส่วนหัวของส่วนหลัก
3. ในฟอร์มที่เปิดขึ้น ให้ป้อนค่าสำหรับประเภทสินค้าในฟิลด์ Value เช่น "Digital"
4. เมื่อเสร็จแล้ว ให้คลิกปุ่ม Create

![ฟอร์มสร้างประเภทสินค้า](https://res.cloudinary.com/dza7lstvk/image/upload/v1739978980/User%20Guide/Screenshot_2025-02-19_at_5.29.25_PM_k96euy.png)

---

## ดูรายละเอียดประเภทสินค้า

วิธีการดูรายละเอียดของประเภทสินค้า:

1. ไปที่ Settings → Product Types
2. คลิกที่ประเภทสินค้าจากรายการ

การดำเนินการนี้จะเปิดหน้ารายละเอียดของประเภทสินค้า ซึ่งคุณสามารถจัดการประเภทสินค้าได้เช่นกัน

![รายละเอียดประเภทสินค้า](https://res.cloudinary.com/dza7lstvk/image/upload/v1739979095/User%20Guide/Screenshot_2025-02-19_at_5.30.49_PM_wr7mro.png)

## แก้ไขรายละเอียดประเภทสินค้า

วิธีการแก้ไขรายละเอียดของประเภทสินค้า:

1. ไปที่หน้ารายละเอียดของประเภทสินค้า
2. คลิกไอคอน <InlineIcon Icon={EllipsisHorizontal} alt="three-dots" /> ในส่วนหัวของส่วนแรก
3. เลือก Edit จากเมนูดรอปดาวน์
4. ในหน้าต่างด้านข้างที่เปิดขึ้น คุณสามารถแก้ไขค่าของประเภทสินค้าได้
5. เมื่อเสร็จแล้ว ให้คลิกปุ่ม Save

![ฟอร์มแก้ไขประเภทสินค้า](https://res.cloudinary.com/dza7lstvk/image/upload/v1739979188/User%20Guide/Screenshot_2025-02-19_at_5.32.46_PM_hsdluu.png)

## จัดการการแปลของประเภทสินค้า

<Note>

ภาษาของระบบ (Locales) มีให้ใช้งานตั้งแต่ [Medusa v2.12.3](https://github.com/medusajs/medusa/releases/tag/v2.12.3) หากคุณไม่เห็นส่วนจัดการการแปลใน Medusa Admin ของคุณ โปรดขอให้ทีมงานฝ่ายเทคนิคของคุณ [อัปเกรดแอปพลิเคชัน Medusa ของคุณ](!docs!/learn/update)

</Note>

ประเภทสินค้าสามารถแปลเป็นภาษาต่าง ๆ (Locales) ที่ [ร้านค้าของคุณรองรับ](../store/page.mdx#manage-store-locales) คุณสามารถจัดการการแปล [แบบเป็นกลุ่ม](../translations/page.mdx) หรือจัดการการแปลสำหรับแต่ละประเภทสินค้าจากหน้ารายละเอียดของประเภทสินค้านั้น ๆ ได้

วิธีการจัดการการแปลสำหรับประเภทสินค้า:

1. คลิกที่ไอคอน <InlineIcon Icon={EllipsisHorizontal} alt="three-dots" /> ในส่วนหัวของส่วนแรก
2. เลือก "Manage translations" จากเมนูดรอปดาวน์
3. ใน [เครื่องมือแก้ไขแบบกลุ่ม](../../tips/bulk-editor/page.mdx) ที่เปิดขึ้น คุณสามารถดูและแก้ไขคำแปลสำหรับค่าประเภทสินค้าในแต่ละภาษาที่ร้านค้าของคุณรองรับ
    - หากต้องการแก้ไขข้อความที่มีการรองรับการขึ้นบรรทัดใหม่ ให้ดับเบิ้ลคลิกที่เซลล์นั้น ๆ เพื่อเปิดพื้นที่ป้อนข้อความขนาดใหญ่ขึ้น
4. เมื่อแก้ไขเสร็จแล้ว ให้คลิกปุ่ม Save เพื่อบันทึกการเปลี่ยนแปลง

คุณสามารถจัดการประเภทของสินค้าได้ใน [หน้ารายละเอียดของสินค้า](../../products/edit/page.mdx#manage-product-organization)

## จัดการข้อมูลเมทาดาตาของประเภทสินค้า

ข้อมูลเมทาดาตา (Metadata) คือข้อมูลที่กำหนดเองซึ่งสามารถเชื่อมโยงกับประเภทสินค้าในรูปแบบของคู่คีย์-ค่า (Key-Value) ซึ่งปกติแล้วนักพัฒนาจะใช้สำหรับการผสานระบบแบบกำหนดเองหรือเพื่อจัดเก็บข้อมูลเพิ่มเติมเกี่ยวกับประเภทสินค้า

วิธีการแก้ไขข้อมูลเมทาดาตาของประเภทสินค้า:

1. คลิกไอคอน <InlineIcon Icon={ArrowUpRightOnBox} alt="arrow" /> ในส่วน "Metadata"
2. ในหน้าต่างด้านข้างที่เปิดขึ้น:
    - จัดการคู่คีย์-ค่าในตาราง
    - วิธีการเพิ่มแถวคู่คีย์-ค่าใหม่ก่อนหน้าหรือหลังแถวที่มีอยู่:
        - วางเมาส์เหนือแถวแล้วคลิกไอคอน <InlineIcon Icon={EllipsisVertical} alt="three-dots" /> ที่ส่วนท้ายของแถว
        - เลือก "Insert row above" (แทรกแถวด้านบน) หรือ "Insert row below" (แทรกแถวด้านล่าง) จากเมนูดรอปดาวน์
    - วิธีการลบแถวคู่คีย์-ค่า:
        - วางเมาส์เหนือแถวแล้วคลิกไอคอน <InlineIcon Icon={EllipsisVertical} alt="three-dots" /> ที่ส่วนท้ายของแถว
        - เลือก "Delete row" จากเมนูดรอปดาวน์
3. เมื่อเสร็จแล้ว ให้คลิกปุ่ม Save

---

## ลบประเภทสินค้า

<Note type="warning">

การลบประเภทสินค้าจะไม่สามารถย้อนกลับคืนได้

</Note>

วิธีการลบประเภทสินค้า:

1. ไปที่หน้ารายละเอียดของประเภทสินค้า
2. คลิกไอคอน <InlineIcon Icon={EllipsisHorizontal} alt="three-dots" /> ในส่วนหัวของส่วนแรก
3. เลือก Delete จากเมนูดรอปดาวน์
4. ยืนยันการลบโดยคลิกปุ่ม Delete ในป๊อปอัป
