# {metadata.title}

ในคู่มือนี้ คุณจะได้เรียนรู้วิธีแก้ไขรายละเอียดร้านค้าและสกุลเงินที่พร้อมใช้งาน

## ดูรายละเอียดร้านค้า

หากต้องการดูรายละเอียดร้านค้าของคุณ ให้ไปที่ Settings → Store ที่นั่นคุณสามารถดูและจัดการรายละเอียดร้านค้าและสกุลเงินที่พร้อมใช้งานได้

![รายละเอียดร้านค้า](https://res.cloudinary.com/dza7lstvk/image/upload/v1739962494/User%20Guide/Screenshot_2025-02-19_at_12.54.00_PM_eozum8.png)

---

## แก้ไขรายละเอียดร้านค้า

วิธีการแก้ไขรายละเอียดร้านค้า:

1. ไปที่ Settings → Store
2. คลิกไอคอน <InlineIcon Icon={EllipsisHorizontal} alt="three-dots" /> ในส่วนหัวของส่วน "Store"
3. เลือก Edit จากเมนูดรอปดาวน์
4. ในหน้าต่างด้านข้างที่เปิดขึ้น คุณสามารถแก้ไขชื่อร้านค้า, สกุลเงินเริ่มต้น, ภูมิภาคเริ่มต้น, ช่องทางการขายเริ่มต้น และสถานที่จัดเก็บสินค้าเริ่มต้นได้ ค่าเริ่มต้นเหล่านี้จะถูกใช้ที่หน้าเว็บร้านค้า (Storefront) หากไม่มีการระบุค่าอื่น ๆ
5. เมื่อเสร็จแล้ว ให้คลิกปุ่ม Save

![ฟอร์มแก้ไขร้านค้า](https://res.cloudinary.com/dza7lstvk/image/upload/v1739962919/User%20Guide/Screenshot_2025-02-19_at_1.01.47_PM_l2zhnc.png)

## จัดการสกุลเงิน

ร้านค้าของคุณสามารถรองรับหลายสกุลเงิน เพื่อให้ลูกค้าสามารถดูราคาสินค้าในสกุลเงินที่ต้องการได้ คุณสามารถเพิ่มหรือลบสกุลเงินได้ในการตั้งค่าร้านค้า

### เพิ่มสกุลเงิน

วิธีการเพิ่มสกุลเงินในร้านค้าของคุณ:

1. ไปที่ Settings → Store
2. คลิกไอคอน <InlineIcon Icon={EllipsisHorizontal} alt="three-dots" /> ในส่วนหัวของส่วน "Currencies"
3. เลือก Add จากเมนูดรอปดาวน์
4. ในรายการที่เปิดขึ้น ให้ทำเครื่องหมายเลือกสกุลเงินที่ต้องการเพิ่มเข้าร้านค้า
    - หากต้องการเปิดใช้งาน [การกำหนดราคาแบบรวมภาษี](#edit-tax-inclusive-setting-for-currency) สำหรับสกุลเงินนั้น ให้เปิดปุ่มเปิดปิดข้างสกุลเงินดังกล่าว
5. เมื่อเสร็จแล้ว ให้คลิกปุ่ม Save

![เพิ่มสกุลเงินในร้านค้า](https://res.cloudinary.com/dza7lstvk/image/upload/v1739963867/User%20Guide/Screenshot_2025-02-19_at_1.17.37_PM_mjrxng.png)

### แก้ไขการกำหนดค่าราคาแบบรวมภาษีสำหรับสกุลเงิน

ในการตั้งค่าร้านค้า คุณสามารถจัดการการกำหนดราคาแบบรวมภาษีของแต่ละสกุลเงินได้ด้วย โดยในขั้นตอนการชำระเงิน หลังจากที่ Medusa คำนวณภาษีของสินค้าหรือการจัดส่งแล้ว ระบบจะดำเนินการอย่างใดอย่างหนึ่งดังนี้:

- บวกภาษีเพิ่มเข้าไปในราคาสินค้า (การกำหนดราคาแบบไม่รวมภาษี - Tax-exclusive Pricing)
- รวมภาษีเป็นส่วนหนึ่งของราคาสินค้า (การกำหนดราคาแบบรวมภาษี - Tax-inclusive Pricing)

คุณสามารถจัดการว่าสกุลเงินใดจะใช้การกำหนดราคาแบบรวมภาษีได้ขณะทำการเพิ่มหรือแก้ไขสกุลเงิน วิธีการแก้ไขการตั้งค่ารวมภาษีสำหรับสกุลเงิน:

1. ไปที่ Settings → Store
2. คลิกไอคอน <InlineIcon Icon={EllipsisHorizontal} alt="three-dots" /> ข้างสกุลเงินที่ต้องการแก้ไข
3. เลือก "Enable tax-inclusive pricing" (เปิดใช้ราคารวมภาษี) หรือ "Disable tax-inclusive pricing" (ปิดใช้ราคารวมภาษี) จากเมนูดรอปดาวน์ ทั้งนี้ขึ้นอยู่กับการตั้งค่าปัจจุบัน

### ลบสกุลเงิน

คุณสามารถลบสกุลเงินใดก็ได้ออกจากร้านค้า ยกเว้นสกุลเงินที่เป็นค่าเริ่มต้น และคุณสามารถกลับมาเพิ่มสกุลเงินนั้นใหม่ได้ในภายหลังหากต้องการ

วิธีการลบสกุลเงิน:

1. ไปที่ Settings → Store
2. ในส่วน Currencies ให้ทำเครื่องหมายเลือกหน้าสกุลเงินที่ต้องการลบ
3. กดปุ่ม <Kbd>R</Kbd> หรือคลิกปุ่ม Remove ที่ด้านล่างตรงกลางของหน้า
4. ยืนยันการลบสกุลเงินโดยคลิกปุ่ม Remove ในป๊อปอัป

![ลบสกุลเงินออกจากร้านค้า](https://res.cloudinary.com/dza7lstvk/image/upload/v1739963798/User%20Guide/Screenshot_2025-02-19_at_1.16.17_PM_hlzti3.png)

## จัดการภาษาของร้านค้า

<Note>

ภาษาของระบบ (Locales) มีให้ใช้งานตั้งแต่ [Medusa v2.12.3](https://github.com/medusajs/medusa/releases/tag/v2.12.3) หากคุณไม่เห็นการตั้งค่าภาษาใน Medusa Admin ของคุณ โปรดขอให้ทีมงานฝ่ายเทคนิคของคุณ [อัปเกรดแอปพลิเคชัน Medusa ของคุณ](!docs!/learn/update)

</Note>

ภาษาของระบบ (Locales) เป็นตัวกำหนดภาษาที่ร้านค้าของคุณรองรับเพื่อใช้แสดงเนื้อหาแก่ลูกค้า คุณสามารถจัดการภาษาต่าง ๆ ที่พร้อมใช้งานของร้านค้าได้ในการตั้งค่าร้านค้า จากนั้นคุณจะสามารถแปลเนื้อหา เช่น ชื่อและคำอธิบายสินค้า เป็นภาษาเหล่านี้ได้จากหน้าการตั้งค่า [คำแปลภาษา](../translations/page.mdx)

## เพิ่มภาษาในร้านค้า

วิธีการเพิ่มภาษาที่รองรับในร้านค้าของคุณ:

1. ไปที่ Settings → Store
2. คลิกไอคอน <InlineIcon Icon={EllipsisHorizontal} alt="three-dots" /> ในส่วนหัวของส่วน "Locales"
3. เลือก Add จากเมนูดรอปดาวน์
4. ในรายการที่เปิดขึ้น ให้ทำเครื่องหมายเลือกภาษาที่คุณต้องการเพิ่มเข้าร้านค้า
5. เมื่อเสร็จแล้ว ให้คลิกปุ่ม Save

ตอนนี้คุณสามารถไปเพิ่มคำแปลภาษาสำหรับทรัพยากรต่าง ๆ ในภาษาที่เพิ่มใหม่ได้แล้วที่หน้าการตั้งค่า [คำแปลภาษา](../translations/page.mdx)

### ลบภาษาออกจากร้านค้า

วิธีการลบภาษาออกจากร้านค้าของคุณ:

1. ไปที่ Settings → Store
2. ในส่วน Locales ให้ทำเครื่องหมายเลือกหน้าภาษาที่ต้องการลบ
3. กดปุ่ม <Kbd>R</Kbd> หรือคลิกปุ่ม Remove ที่ด้านล่างตรงกลางของหน้า
4. ยืนยันการลบภาษาโดยคลิกปุ่ม Remove ในป๊อปอัป

## จัดการข้อมูลเมทาดาตาของร้านค้า

ข้อมูลเมทาดาตา (Metadata) คือข้อมูลที่กำหนดเองซึ่งสามารถเชื่อมโยงกับร้านค้าในรูปแบบของคู่คีย์-ค่า (Key-Value) ซึ่งปกติแล้วนักพัฒนาจะใช้สำหรับการผสานระบบแบบกำหนดเองหรือเพื่อจัดเก็บข้อมูลเพิ่มเติมเกี่ยวกับร้านค้า

วิธีการแก้ไขข้อมูลเมทาดาตาของร้านค้า:

1. คลิกไอคอน <InlineIcon Icon={ArrowUpRightOnBox} alt="arrow" /> ในส่วน "Metadata"
2. ในหน้าต่างด้านข้างที่เปิดขึ้น:
    - จัดการคู่คีย์-ค่าในตาราง
    - วิธีการเพิ่มแถวคู่คีย์-ค่าใหม่ก่อนหน้าหรือหลังแถวที่มีอยู่:
        - วางเมาส์เหนือแถวแล้วคลิกไอคอน <InlineIcon Icon={EllipsisVertical} alt="three-dots" /> ที่ส่วนท้ายของแถว
        - เลือก "Insert row above" (แทรกแถวด้านบน) หรือ "Insert row below" (แทรกแถวด้านล่าง) จากเมนูดรอปดาวน์
    - วิธีการลบแถวคู่คีย์-ค่า:
        - วางเมาส์เหนือแถวแล้วคลิกไอคอน <InlineIcon Icon={EllipsisVertical} alt="three-dots" /> ที่ส่วนท้ายของแถว
        - เลือก "Delete row" จากเมนูดรอปดาวน์
3. เมื่อเสร็จแล้ว ให้คลิกปุ่ม Save
