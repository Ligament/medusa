# {metadata.title}

ในคู่มือนี้ คุณจะได้เรียนรู้ว่าเหตุผลการคืนสินค้า (Return Reasons) คืออะไรและจะจัดการเหตุผลเหล่านั้นอย่างไร

## เหตุผลการคืนสินค้าคืออะไร?

เหตุผลการคืนสินค้า (Return Reason) มีประโยชน์เมื่อต้องคืนสินค้าในรายการสั่งซื้อ ใช้เพื่อระบุสาเหตุที่สินค้าถูกส่งคืน ตัวอย่างเช่น ลูกค้าอาจคืนสินค้าเนื่องจากสินค้าชำรุด ขนาดไม่ถูกต้อง หรือเปลี่ยนใจ

ในการระบุเหตุผลการคืนสินค้าเมื่อทำการสร้างรายการคืนสินค้า แลกเปลี่ยน หรือเคลมสินค้า คุณสามารถเลือกจากรายการเหตุผลการคืนสินค้าที่คุณได้ตั้งค่าไว้ในการตั้งค่าของคุณได้

---

## ดูเหตุผลการคืนสินค้า

หากต้องการดูเหตุผลการคืนสินค้าในร้านค้าของคุณ ให้ไปที่ Settings → Return Reasons ที่นี่ คุณจะเห็นรายการของเหตุผลการคืนสินค้าทั้งหมดที่คุณตั้งค่าไว้ในร้านค้าของคุณ นอกจากนี้ยังสามารถค้นหา กรอง และจัดเรียงเหตุผลการคืนสินค้าเพื่อค้นหาเหตุผลที่คุณต้องการได้

## สร้างเหตุผลการคืนสินค้า

ขั้นตอนการสร้างเหตุผลการคืนสินค้า:

1. ไปที่ Settings → Return Reasons
2. คลิกปุ่ม Create ในหัวข้อของส่วนหลัก
3. ในฟอร์มที่เปิดขึ้น:
    - ป้อนรหัสระบุเฉพาะ (Value) ของเหตุผลนี้ที่ใช้ภายในระบบในฟิลด์ Value แนะนำให้ใช้เฉพาะตัวอักษรภาษาอังกฤษตัวพิมพ์เล็กและเครื่องหมายขีดล่าง (`_`) เท่านั้น ตัวอย่างเช่น "damaged" หรือ "wrong_size"
    - ป้อนข้อความที่ต้องการแสดงให้ลูกค้าหรือผู้ดูแลระบบเห็นในฟิลด์ Label
    - คุณสามารถเลือกกรอกคำอธิบายเพิ่มเติมเกี่ยวกับเหตุผลการคืนสินค้าในฟิลด์ Description ได้
4. เมื่อเสร็จแล้ว ให้คลิกปุ่ม Save

![Create return reason form](https://res.cloudinary.com/dza7lstvk/image/upload/v1739976122/User%20Guide/Screenshot_2025-02-19_at_4.41.51_PM_xgf4fu.png)

## แก้ไขเหตุผลการคืนสินค้า

ขั้นตอนการแก้ไขเหตุผลการคืนสินค้า:

1. ไปที่ Settings → Return Reasons
2. ค้นหาเหตุผลการคืนสินค้าที่ต้องการแก้ไข แล้วคลิกไอคอน <InlineIcon Icon={EllipsisHorizontal} alt="สามจุด" /> ในแถวของเหตุผลนั้น
3. เลือก Edit จากเมนูแบบดรอปดาวน์
4. ในหน้าต่างด้านข้างที่เปิดขึ้น คุณสามารถแก้ไขรหัสภายใน (Value) ป้ายกำกับ (Label) และคำอธิบายของเหตุผลการคืนสินค้าได้
5. เมื่อเสร็จแล้ว ให้คลิกปุ่ม Save

![Edit return reason form](https://res.cloudinary.com/dza7lstvk/image/upload/v1739976284/User%20Guide/Screenshot_2025-02-19_at_4.43.14_PM_ajcxpf.png)

## ลบเหตุผลการคืนสินค้า

<Note type="warning">

การลบเหตุผลการคืนสินค้าไม่สามารถย้อนกลับได้

</Note>

ขั้นตอนการลบเหตุผลการคืนสินค้า:

1. ไปที่ Settings → Return Reasons
2. ค้นหาเหตุผลการคืนสินค้าที่ต้องการลบ แล้วคลิกไอคอน <InlineIcon Icon={EllipsisHorizontal} alt="สามจุด" /> ในแถวของเหตุผลนั้น
3. เลือก Delete จากเมนูแบบดรอปดาวน์
4. ยืนยันการลบเหตุผลการคืนสินค้าโดยคลิกปุ่ม Delete ในป๊อปอัป
