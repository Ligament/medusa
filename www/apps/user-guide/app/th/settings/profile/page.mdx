# {metadata.title}

ในคู่มือนี้ คุณจะได้เรียนรู้วิธีดูและจัดการรายละเอียดและการตั้งค่าโปรไฟล์ของคุณ

## ดูรายละเอียดโปรไฟล์

หากต้องการดูรายละเอียดโปรไฟล์ของคุณ ให้ไปที่ Settings (การตั้งค่า) → Profile หรือคุณสามารถคลิกที่ชื่อของคุณที่ด้านล่างสุดของแถบข้าง (sidebar) แล้วเลือก "Profile settings" จากเมนูได้เช่นกัน

ในหน้ารายละเอียดโปรไฟล์ คุณสามารถดูข้อมูลโปรไฟล์ของคุณได้ เช่น ชื่อ อีเมล และการตั้งค่าภาษา นอกจากนี้คุณยังสามารถจัดการการตั้งค่าการยืนยันตัวตนแบบสองขั้นตอน (two-factor authentication) ได้อีกด้วย

---

## แก้ไขรายละเอียดโปรไฟล์

ขั้นตอนการแก้ไขรายละเอียดและการตั้งค่าโปรไฟล์ของคุณ:

1. ไปที่ Settings → Profile
2. คลิกไอคอน <InlineIcon Icon={EllipsisHorizontal} alt="สามจุด" /> ในหัวข้อของส่วนหลัก
3. เลือก "Edit" จากเมนูแบบดรอปดาวน์
4. ในหน้าต่างด้านข้างที่เปิดขึ้น คุณสามารถแก้ไขชื่อ นามสกุล และภาษาของแดชบอร์ด Medusa Admin ได้ การดำเนินการนี้จะเปลี่ยนเฉพาะภาษาของอินเทอร์เฟซผู้ดูแลระบบเท่านั้น ไม่เกี่ยวกับภาษาของร้านค้าหน้าร้าน และไม่มีผลต่อภาษาของผู้ใช้รายอื่นในระบบดูแลระบบด้วย
5. เมื่อเสร็จแล้ว ให้คลิกปุ่ม Save

<Note title="เคล็ดลับ">

ไม่พบภาษาของคุณใช่ไหม? เรียนรู้วิธีที่คุณสามารถมีส่วนร่วมโดยการแปลส่วนผู้ดูแลระบบเป็นภาษาอื่น ๆ ได้[ที่นี่](!docs!/learn/resources/contribution-guidelines/admin-translations)

</Note>

## จัดการการยืนยันตัวตนแบบสองขั้นตอน

<Note>

การยืนยันตัวตนแบบสองขั้นตอน (Two-Factor Authentication) มีให้ใช้งานตั้งแต่ [Medusa Admin v2.15.5](https://github.com/medusajs/medusa/releases/tag/v2.15.5) เป็นต้นไป หากคุณไม่เห็นตัวเลือกการยืนยันตัวตนแบบสองขั้นตอนใน Medusa Admin ของคุณ โปรดแจ้งให้ทีมเทคนิคทำการ[อัปเกรดแอปพลิเคชัน Medusa ของคุณ](!docs!/learn/update)

</Note>

คุณสามารถเปิดใช้งานการยืนยันตัวตนแบบสองขั้นตอน (2FA) สำหรับบัญชีของคุณเพื่อเพิ่มความปลอดภัยอีกขั้นหนึ่ง เมื่อเปิดใช้งาน 2FA แล้ว นอกเหนือจากการกรอกรหัสผ่านตามปกติเมื่อเข้าสู่ระบบ คุณจะต้องระบุรหัสยืนยันจากแอปพลิเคชันยืนยันตัวตน (เช่น Google Authenticator) ด้วย

### ดูสถานะการยืนยันตัวตนแบบสองขั้นตอน

ขั้นตอนการดูสถานะการยืนยันตัวตนแบบสองขั้นตอนสำหรับบัญชีของคุณ:

1. ไปที่ Settings → Profile
2. ในส่วน "Two-Factor Authentication" คุณจะเห็นสถานะข้างแถว "Status" เป็น "Enabled" (เปิดใช้งาน) หรือ "Disabled" (ปิดใช้งาน) ขึ้นอยู่กับว่าได้เปิดใช้งาน 2FA สำหรับบัญชีของคุณแล้วหรือไม่

### เปิดใช้งานการยืนยันตัวตนแบบสองขั้นตอน

ขั้นตอนการเปิดใช้งานการยืนยันตัวตนแบบสองขั้นตอน:

1. Go to Settings → Profile
2. ในส่วน "Two-Factor Authentication" ให้คลิกปุ่ม **Enable** หรือ **Disable** ที่ด้านบนขวาของส่วนนี้ ขึ้นอยู่กับสถานะปัจจุบันของ 2FA ในบัญชีของคุณ
3. ในป๊อปอัปที่เปิดขึ้น ให้สแกนคิวอาร์โค้ด (QR code) ด้วยแอปพลิเคชันยืนยันตัวตนของคุณ หรือป้อนรหัสคีย์ลับ (secret key) ที่อยู่เหนือคิวอาร์โค้ดลงในแอปพลิเคชันยืนยันตัวตนของคุณ
4. คัดลอกรหัส 6 หลักที่สร้างขึ้นโดยแอปพลิเคชันยืนยันตัวตนของคุณและป้อนลงในช่องรับข้อมูลในป๊อปอัป
5. ก่อนที่จะทำการยืนยัน คุณสามารถดาวน์โหลดหรือคัดลอกรหัสกู้คืน (recovery codes) เก็บไว้ได้ รหัสเหล่านี้สามารถใช้ในการเข้าถึงบัญชีของคุณได้หากคุณไม่สามารถใช้งานแอปพลิเคชันยืนยันตัวตนได้
6. เมื่อเสร็จแล้ว ให้คลิกปุ่ม Complete

### ปิดใช้งานการยืนยันตัวตนแบบสองขั้นตอน

หากต้องการปิดใช้งานการยืนยันตัวตนแบบสองขั้นตอน ให้คลิกปุ่ม **Disable** ที่ด้านบนขวาของส่วน "Two-Factor Authentication"

กระบวนการปิดใช้งาน 2FA อาจจำเป็นต้องป้อนรหัสยืนยันจากแอปพลิเคชันยืนยันตัวตนเพื่อยืนยัน ทั้งนี้ขึ้นอยู่กับการตั้งค่าคอนฟิกของแอปพลิเคชันของคุณ หากระบบขอให้กรอก ให้เปิดแอปพลิเคชันยืนยันตัวตน นำรหัส 6 หลักสำหรับบัญชี Medusa Admin ของคุณมาป้อนลงในช่องรับข้อมูล

### เข้าสู่ระบบด้วยการยืนยันตัวตนแบบสองขั้นตอน

ในการเข้าสู่ระบบบัญชี Medusa Admin ครั้งถัดไป หลังจากที่คุณป้อนอีเมลและรหัสผ่านแล้ว คุณจะได้รับข้อความแจ้งให้ป้อนรหัสยืนยันจากแอปพลิเคชันยืนยันตัวตน ให้คุณเปิดแอปพลิเคชัน นำรหัส 6 หลักสำหรับบัญชี Medusa Admin มากรอกในช่องรับข้อมูลเพื่อดำเนินกระบวนการเข้าสู่ระบบให้เสร็จสิ้น

#### เข้าสู่ระบบด้วยรหัสกู้คืน

หากคุณสูญเสียสิทธิ์ในการเข้าถึงแอปพลิเคชันยืนยันตัวตน คุณสามารถใช้รหัสกู้คืนบัญชีตัวใดตัวหนึ่งที่คุณได้บันทึกไว้ขณะเปิดใช้งาน 2FA เพื่อเข้าสู่ระบบได้

หลังจากกรอกอีเมลและรหัสผ่านในหน้าเข้าสู่ระบบแล้ว:

1. คลิกที่ลิงก์ "Use a recovery code"
2. ป้อนรหัสกู้คืนรหัสใดรหัสหนึ่งในช่องรับข้อมูล หากคุณใช้วิธีคัดลอกรหัสกู้คืนทั้งหมดเก็บไว้ ให้วางรหัสตัวใดตัวหนึ่งลงในช่องนี้
3. คลิกปุ่ม "Verify" เพื่อเข้าสู่ระบบ

<Note type="warning">

รหัสกู้คืนแต่ละรหัสสามารถใช้ได้เพียงครั้งเดียวเท่านั้น หากคุณใช้รหัสกู้คืนในการเข้าสู่ระบบ และคุณไม่มีรหัสกู้คืนอื่น ๆ ที่ยังไม่ได้ใช้อีกเลย รวมถึงไม่สามารถเข้าถึงแอปยืนยันตัวตนได้ ให้คุณไปที่หน้าโปรไฟล์ของคุณ ทำการ[ปิดใช้งานการยืนยันตัวตนแบบสองขั้นตอน](#ปิดใช้งานการยืนยันตัวตนแบบสองขั้นตอน) แล้วทำการ[เปิดใช้งานใหม่อีกครั้ง](#เปิดใช้งานการยืนยันตัวตนแบบสองขั้นตอน) เพื่อทำซ้ำขั้นตอนและรับรหัสกู้คืนชุดใหม่

</Note>
