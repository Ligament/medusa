# {metadata.title}

ในคู่มือนี้ คุณจะได้เรียนรู้ว่าเหตุผลการคืนเงินคืออะไรและวิธีการจัดการเหตุผลเหล่านั้น

<Note>

การจัดการเหตุผลการคืนเงินพร้อมใช้งานตั้งแต่ [Medusa Admin v2.11.0](https://github.com/medusajs/medusa/releases/tag/v2.11.0) หากคุณไม่เห็นตัวเลือก Refund Reasons ใน Medusa Admin ของคุณ โปรดขอให้ทีมงานฝ่ายเทคนิคของคุณ [อัปเกรดแอปพลิเคชัน Medusa ของคุณ](!docs!/learn/update)

</Note>

## เหตุผลการคืนเงินคืออะไร?

เหตุผลการคืนเงินคือเหตุผลที่กำหนดไว้ล่วงหน้าสำหรับการคืนเงินของคำสั่งซื้อ ซึ่งจะช่วยคุณแยกประเภทและติดตามการคืนเงินในร้านค้าของคุณ

เมื่อคุณ [ดำเนินการคืนเงิน](../../orders/payments/page.mdx#refund-payment) คุณสามารถเลือกเหตุผลการคืนเงินจากรายการเหตุผลที่คุณตั้งค่าไว้ได้

---

## ดูเหตุผลการคืนเงิน

หากต้องการดูเหตุผลการคืนเงินในร้านค้าของคุณ ให้ไปที่ Settings → Refund Reasons ที่นี่คุณสามารถดูรายการเหตุผลการคืนเงินทั้งหมดที่คุณตั้งค่าไว้ในร้านค้าของคุณ นอกจากนี้คุณยังสามารถค้นหา กรอง และจัดเรียงเหตุผลการคืนเงินเพื่อค้นหารายการที่คุณต้องการได้

Medusa จะเพิ่มเหตุผลการคืนเงินเริ่มต้นบางส่วนให้ในร้านค้าของคุณ คุณสามารถนำไปใช้หรือ [ลบออก](#delete-a-refund-reason) ก็ได้

## สร้างเหตุผลการคืนเงิน

วิธีการสร้างเหตุผลการคืนเงิน:

1. ไปที่ Settings → Refund Reasons
2. คลิกปุ่ม Create ในส่วนหัวของส่วนหลัก
3. ในฟอร์มที่เปิดขึ้น:
    - **Label**: ป้อนข้อความที่จะแสดงให้ลูกค้าหรือผู้ดูแลระบบเห็น
    - **Code**: ป้อนรหัสระบุเฉพาะ (Unique Identifier) สำหรับเหตุผลการคืนเงินที่ใช้เป็นการภายใน แนะนำให้ใช้เฉพาะตัวอักษรภาษาอังกฤษตัวเล็กและเครื่องหมายขีดล่าง (`_`) เท่านั้น เช่น `pricing_error`
    - **Description**: ป้อนคำอธิบายประกอบเพิ่มเติมสำหรับเหตุผลการคืนเงิน (ไม่บังคับ)
4. เมื่อเสร็จแล้ว ให้คลิกปุ่ม Save

![ฟอร์มสร้างเหตุผลการคืนเงิน](https://res.cloudinary.com/dza7lstvk/image/upload/v1759994670/User%20Guide/CleanShot_2025-10-09_at_10.24.22_2x_mmkr8z.png)

## แก้ไขเหตุผลการคืนเงิน

วิธีการแก้ไขเหตุผลการคืนเงิน:

1. ไปที่ Settings → Refund Reasons
2. ค้นหาเหตุผลการคืนเงินที่ต้องการแก้ไข แล้วคลิกไออน <InlineIcon Icon={EllipsisHorizontal} alt="three-dots" /> ในแถวนั้น ๆ
3. เลือก Edit จากเมนูดรอปดาวน์
4. ในหน้าต่างด้านข้างที่เปิดขึ้น คุณสามารถแก้ไข รหัส (Code), ป้ายชื่อ (Label) และคำอธิบาย (Description) ของเหตุผลการคืนเงินได้
5. เมื่อเสร็จแล้ว ให้คลิกปุ่ม Save

![ฟอร์มแก้ไขเหตุผลการคืนเงิน](https://res.cloudinary.com/dza7lstvk/image/upload/v1759994731/User%20Guide/CleanShot_2025-10-09_at_10.25.22_2x_hyo1j3.png)

## ลบเหตุผลการคืนเงิน

<Note type="warning">

การลบเหตุผลการคืนเงินจะไม่สามารถย้อนกลับคืนได้

</Note>

วิธีการลบเหตุผลการคืนเงิน:

1. ไปที่ Settings → Refund Reasons
2. ค้นหาเหตุผลการคืนเงินที่ต้องการลบ แล้วคลิกไอคอน <InlineIcon Icon={EllipsisHorizontal} alt="three-dots" /> ในแถวนั้น ๆ
3. เลือก Delete จากเมนูดรอปดาวน์
4. ยืนยันการลบเหตุผลการคืนเงินโดยคลิกปุ่ม Delete ในป๊อปอัป
