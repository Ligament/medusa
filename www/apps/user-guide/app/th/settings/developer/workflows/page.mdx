# {metadata.title}

ในคู่มือนี้ คุณจะได้เรียนรู้วิธีดูการทำงานของเวิร์กโฟลว์ (workflow executions) ใน Medusa Admin

<Note>

คู่มือนี้มีประโยชน์สำหรับนักพัฒนาและทีมเทคนิคที่กำลังพัฒนาและดีบักการปรับแต่งแอปพลิเคชัน Medusa เป็นหลัก

</Note>

## การทำงานของเวิร์กโฟลว์คืออะไร?

[เวิร์กโฟลว์ (Workflows)](!docs!/learn/fundamentals/workflows) คือชุดของขั้นตอนในการทำงานตามที่ได้รับมอบหมาย คุณสามารถสร้างเวิร์กโฟลว์ในซอร์สโค้ดของคุณเพื่อเชื่อมโยงขั้นตอนและฟีเจอร์การค้าที่กำหนดเองได้

เมื่อคุณเรียกใช้เวิร์กโฟลว์ Medusa จะทำตามขั้นตอนตามลำดับเพื่อทำงานนั้นให้เสร็จสิ้น หากคุณกำหนดค่าให้บันทึกประวัติการเรียกใช้งานเวิร์กโฟลว์ลงในฐานข้อมูลตามที่อธิบายไว้ใน [คู่มือจัดเก็บประวัติการเรียกใช้งานเวิร์กโฟลว์](!docs!/learn/fundamentals/workflows/store-executions) คุณจะสามารถดูการทำงานของเวิร์กโฟลว์และรายละเอียดต่าง ๆ ได้ใน Medusa Admin ซึ่งมีประโยชน์ในการดีบักเวิร์กโฟลว์และตรวจสอบให้แน่ใจว่าทำงานได้อย่างถูกต้อง

---

## ดูการทำงานของเวิร์กโฟลว์

หากต้องการดูประวัติการทำงานของเวิร์กโฟลว์ ให้ไปที่ Settings → Workflows ที่นั่นคุณจะพบรายการของเวิร์กโฟลว์ที่กำหนดเองและเวิร์กโฟลว์ของ Medusa ที่เคยทำงานและจัดเก็บไว้ในฐานข้อมูล คุณสามารถค้นหาในรายการเพื่อค้นหาเวิร์กโฟลว์ที่ต้องการได้

## ดูรายละเอียดการทำงานของเวิร์กโฟลว์

ขั้นตอนการดูรายละเอียดการทำงานของเวิร์กโฟลว์:

1. ไปที่ Settings → Workflows
2. คลิกที่การทำงานของเวิร์กโฟลว์ที่ต้องการดู

ในหน้าการทำงานของเวิร์กโฟลว์ คุณจะพบส่วนต่าง ๆ ที่แสดงรายละเอียดการทำงาน

![Workflow executions details](https://res.cloudinary.com/dza7lstvk/image/upload/v1740496967/User%20Guide/Screenshot_2025-02-25_at_5.22.33_PM_z6al6a.png)

### ส่วนสรุปรายละเอียด

ในส่วนแรกคุณจะพบข้อมูลสรุปของการทำงานของเวิร์กโฟลว์ ประกอบด้วย:

- ป้ายสถานะที่ด้านบนขวาซึ่งแสดง [สถานะการทำงาน](#สถานะการทำงานของเวิร์กโฟลว์)
- ID ที่ไม่ซ้ำกันของเวิร์กโฟลว์ (Workflow ID) ซึ่งกำหนดไว้ตอนสร้างเวิร์กโฟลว์
- ID รายการธุรกรรม (Transaction ID) ซึ่งเป็นรหัสเฉพาะสำหรับการทำงานรอบนั้น ๆ มีประโยชน์สำหรับใช้ดีบัก ติดตาม และเปลี่ยนสถานะขั้นตอนของ [เวิร์กโฟลว์ที่ทำงานระยะยาว](!docs!/learn/fundamentals/workflows/long-running-workflow)
- ความคืบหน้าของเวิร์กโฟลว์ (Progress) แสดงภาพรวมอย่างรวดเร็วของขั้นตอนต่าง ๆ ที่ทำงานเสร็จไปแล้ว

### เส้นเวลา (Timeline)

### JSON

ส่วน JSON ช่วยให้คุณดูรายละเอียดของการทำงานในรูปแบบออบเจกต์ JSON ดิบได้โดยคลิกที่ไอคอน <InlineIcon Icon={ArrowUpRightOnBox} alt="ขยาย" /> ซึ่งมีประโยชน์สำหรับการดีบักระดับสูงเพื่อให้เห็นรายละเอียดทั้งหมดของการทำงานเวิร์กโฟลว์

### ประวัติการทำงาน (History)

ส่วนประวัติ (History) จะแสดงรายละเอียดการทำงานของขั้นตอนต่าง ๆ ในเวิร์กโฟลว์ตามลำดับการทำงาน คุณสามารถเห็นชื่อขั้นตอนแต่ละขั้นพร้อมจุดที่แสดงสถานะของขั้นตอนนี้ตามที่อธิบายไว้ในส่วน [สถานะของขั้นตอน](#สถานะของขั้นตอน)

หากคลิกที่ขั้นตอนใด ๆ ที่เคยทำงานไปแล้ว คุณจะเห็นรายละเอียดต่าง ๆ ดังนี้:

- **คำจำกัดความ (Definition)**: การตั้งค่าคอนฟิกูเรชันของขั้นตอนที่ส่งผ่านตอนสร้างขั้นตอน เช่น ชื่อของขั้นตอน, การระบุว่ามีฟังก์ชันย้อนกลับ (compensation function) หรือไม่, หรือฟังก์ชันนี้ทำงานแบบไม่พร้อมกัน (asynchronous) หรือไม่
- **ผลลัพธ์ (Output)**: ผลลัพธ์จากการทำงานของขั้นตอนนั้น
- **อินพุตของการย้อนกลับขั้นตอน (Compensation Input)**: ในกรณีที่เวิร์กโฟลว์ล้มเหลวและขั้นตอนนี้มีฟังก์ชันย้อนกลับ คุณสามารถดูค่าอินพุตที่ฟังก์ชันย้อนกลับได้รับได้
- **ข้อผิดพลาด (Error)**: ในกรณีที่ขั้นตอนล้มเหลว คุณจะเห็นข้อความแสดงข้อผิดพลาด (error message)
