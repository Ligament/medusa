# {metadata.title}

ในคู่มือนี้ คุณจะได้เรียนรู้วิธีจัดการคำแปลภาษาของทรัพยากรต่าง ๆ เช่น สินค้า ใน Medusa Admin

<Note>

การแปลภาษามีให้ใช้งานตั้งแต่ [Medusa v2.12.3](https://github.com/medusajs/medusa/releases/tag/v2.12.3) หากคุณไม่เห็นการตั้งค่าภาษาของระบบ (Locale) ใน Medusa Admin ของคุณ โปรดขอให้ทีมงานฝ่ายเทคนิคของคุณ [อัปเกรดแอปพลิเคชัน Medusa ของคุณ](!docs!/learn/update)

</Note>

## ภาพรวมการแปลภาษา

Medusa ช่วยให้คุณสามารถแปลทรัพยากรต่าง ๆ ในร้านค้าของคุณ เช่น ชื่อสินค้าและคำอธิบายสินค้า เป็นภาษาอื่น ๆ (Locales) ที่ร้านค้าของคุณรองรับได้

<Note title="ข้อแนะนำ">

คุณสามารถกำหนดภาษาที่รองรับสำหรับร้านค้าของคุณได้ในหน้าการตั้งค่า [ร้านค้า](../store/page.mdx#manage-store-locales)

</Note>

จากนั้น ลูกค้าที่หน้าเว็บร้านค้า (Storefront) จะสามารถดูเนื้อหาในภาษาที่ต้องการตามภาษาที่ตั้งค่าไว้ได้

### ดูและจัดการคำแปลภาษา

คุณสามารถดูและจัดการคำแปลภาษาในแดชบอร์ด Medusa Admin ได้โดยไปที่ Settings → Translations หน้านี้ช่วยให้คุณสามารถจัดการคำแปลภาษาของทรัพยากรหลักและทรัพยากรที่กำหนดเองแบบเป็นกลุ่ม (Bulk) ได้

หรืออีกทางเลือกหนึ่ง คุณสามารถจัดการการแปลสำหรับแต่ละทรัพยากรได้โดยตรงจากหน้าของทรัพยากรนั้น ๆ (ตัวอย่างเช่น จากหน้ารายละเอียดของสินค้า)

![หน้าตั้งค่าการแปลภาษา](https://res.cloudinary.com/dza7lstvk/image/upload/v1768905062/User%20Guide/CleanShot_2026-01-20_at_12.30.45_2x_cp0fpt.png)

## จัดการคำแปลภาษาแบบเป็นกลุ่ม

ในหน้าการตั้งค่า Translations คุณสามารถดูและจัดการคำแปลภาษาแบบเป็นกลุ่มสำหรับทรัพยากรหลักและทรัพยากรที่กำหนดเองต่าง ๆ ในร้านค้าของคุณ รวมถึงสินค้าและสินค้าตัวเลือกย่อย (Variants)

<Note>

ศึกษาคู่มือ [โมดูลการแปลภาษา (Translation Module)](!resources!/commerce-modules/translation#supported-module-translations) สำหรับรายการทรัพยากรหลักที่รองรับการแปลภาษาโดยไม่ต้องกำหนดค่าเพิ่มเติม

</Note>

ตัวอย่างเช่น การจัดการคำแปลของสินค้าแบบเป็นกลุ่ม:

1. ไปที่ Settings → Translations
2. คลิกปุ่ม Edit ในแถว "Products"
3. การดำเนินการนี้จะเปิด [เครื่องมือแก้ไขแบบกลุ่ม](../../tips/bulk-editor/page.mdx) ซึ่งคุณสามารถดูและแก้ไขคำแปลสำหรับชื่อสินค้า, คำอธิบายสินค้า, ชื่อย่อย และอื่น ๆ ในแต่ละ [ภาษาที่ร้านค้าของคุณรองรับ](../store/page.mdx#manage-store-locales)
    - คุณสามารถสลับภาษาได้โดยใช้เมนูดรอปดาวน์ Locales ที่ด้านบนของเครื่องมือแก้ไขแบบกลุ่ม
    - คุณสามารถคลิกปุ่ม "Save Changes" ได้ตลอดเวลาเพื่อบันทึกความคืบหน้าโดยไม่ต้องปิดเครื่องมือแก้ไขแบบกลุ่ม
4. เมื่อแก้ไขเสร็จแล้ว ให้คลิกปุ่ม "Save and close" เพื่อบันทึกการเปลี่ยนแปลง

จากนั้นลูกค้าจะเห็นเนื้อหาที่แปลแล้วบนหน้าเว็บร้านค้าตามภาษาที่พวกเขาเลือก

ผู้ดูแลระบบสามารถกำหนดค่าได้ว่าทรัพยากรใดบ้างที่สามารถแปลภาษาได้ในหน้าตั้งค่า Translations นอกจากนี้ยังสามารถกำหนดค่าฟิลด์ที่จะแปลภาษาสำหรับแต่ละทรัพยากรได้อีกด้วย

วิธีการจัดการทรัพยากรที่แปลได้และฟิลด์ของทรัพยากรเหล่านั้น:

1. ไปที่ Settings → Translations
2. คลิกปุ่ม Manage ที่มุมขวาบนของส่วนแรก
3. ในหน้าต่างด้านข้างที่เปิดขึ้น คุณสามารถ:
    - เปิดใช้งานหรือปิดใช้งานการแปลภาษาสำหรับแต่ละทรัพยากร เช่น สินค้า (Products)
    - สำหรับแต่ละทรัพยากร คุณสามารถขยายรายการเพื่อกำหนดค่าว่าฟิลด์ใดบ้างที่เปิดให้แปลภาษาได้
    - หากต้องการเลือกทรัพยากรและฟิลด์ทั้งหมด ให้คลิกปุ่ม "Select All" ที่ด้านบน
    - หากต้องการดูเฉพาะทรัพยากรที่เลือก ให้คลิกปุ่ม "Selected" คุณสามารถคลิกปุ่ม "Full list" เพื่อสลับกลับไปดูทรัพยากรทั้งหมดได้
    - คุณสามารถสลับการเรียงลำดับตามตัวอักษรระหว่างจากน้อยไปมากและจากมากไปน้อยได้โดยคลิกปุ่ม <InlineIcon Icon={BarsArrowDown} alt="sort" /> ที่ด้านบน
    - คุณสามารถย่อทรัพยากรทั้งหมดที่ขยายอยู่ได้โดยคลิกปุ่ม <InlineIcon Icon={Collapse} alt="collapse" /> ที่ด้านบน
4. เมื่อเสร็จแล้ว ให้คลิกปุ่ม "Save" เพื่อบันทึกการเปลี่ยนแปลง

## ดูสถิติการแปลภาษา

แต่ละแถวทรัพยากรในหน้าตั้งค่า Translations จะแสดงจำนวนฟิลด์ที่ได้รับการแปลแล้วจากจำนวนฟิลด์ที่แปลได้ทั้งหมดของทรัพยากรนั้น ๆ

ส่วน "Translated fields" จะแสดงแถบความคืบหน้าทั่วไปของการแปลฟิลด์ข้อมูลในทุกทรัพยากรและภาษาในร้านค้าของคุณ คุณสามารถใช้ส่วนสรุปนี้เพื่อติดตามความคืบหน้าของการแปลโดยรวมได้

![สถิติการแปลภาษาในส่วน Translated fields](https://res.cloudinary.com/dza7lstvk/image/upload/v1768905110/User%20Guide/CleanShot_2026-01-20_at_12.31.18_2x_swg6zy.png)

มีแผนภูมิสองแบบในส่วนนี้:

1. แถบความคืบหน้าที่แสดงความคืบหน้าการแปลภาษาโดยรวมในทุกทรัพยากรและภาษา
2. แผนภูมิแท่งแสดงจำนวนฟิลด์ข้อมูลที่แปลแล้วแยกตามภาษา

แผนภูมิเหล่านี้ช่วยให้คุณเห็นภาพความพยายามในการแปลภาษา และระบุว่าภาษาใดที่อาจต้องได้รับการดูแลเพิ่มเติม
