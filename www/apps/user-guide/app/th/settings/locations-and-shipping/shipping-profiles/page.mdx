# {metadata.title}

ในคู่มือนี้ คุณจะได้เรียนรู้ว่าโปรไฟล์การจัดส่ง (Shipping Profiles) คืออะไร และวิธีการจัดการโปรไฟล์เหล่านี้ใน Medusa Admin

## โปรไฟล์การจัดส่งคืออะไร?

โปรไฟล์การจัดส่งจะจัดกลุ่มสินค้าที่มีข้อกำหนดการจัดส่งคล้ายคลึงกัน ซึ่งช่วยให้คุณสามารถกำหนดตัวเลือกการจัดส่งที่เหมาะสมกับสินค้าเหล่านั้นโดยเฉพาะได้

ตัวอย่างเช่น หากร้านค้าของคุณมีสินค้าที่แตกหักง่าย (Fragile) ซึ่งต้องการการจัดส่งที่แตกต่างจากสินค้าทั่วไป คุณสามารถสร้างโปรไฟล์การจัดส่ง "Fragile" และนำไปผูกกับสินค้าที่แตกหักง่ายเหล่านั้นได้ จากนั้นคุณก็สามารถ [สร้างตัวเลือกการจัดส่ง](../locations/page.mdx#create-shipping-options) สำหรับสินค้าแตกหักง่าย แยกต่างหากจากตัวเลือกจัดส่งของสินค้าปกติทั่วไปได้

---

## ดูโปรไฟล์การจัดส่ง

วิธีการดูโปรไฟล์การจัดส่งในร้านค้าของคุณ:

1. ไปที่ Settings → Location & Shipping
2. ในส่วน Shipping Configuration ให้คลิกที่ "Shipping Profiles"

ที่นี่คุณสามารถดูรายการโปรไฟล์การจัดส่งทั้งหมดที่คุณตั้งค่าไว้ในร้านค้าของคุณ นอกจากนี้คุณยังสามารถค้นหา กรอง และจัดเรียงโปรไฟล์การจัดส่งเพื่อค้นหารายการที่คุณต้องการได้

## สร้างโปรไฟล์การจัดส่ง

วิธีการสร้างโปรไฟล์การจัดส่ง:

1. ไปที่ Settings → Location & Shipping -> Shipping Profiles
2. คลิกปุ่ม Create ในส่วนหัวของส่วนหลัก
3. ในฟอร์มที่เปิดขึ้น:
    - ในฟิลด์ Name ให้ป้อนชื่อโปรไฟล์การจัดส่ง เช่น "Fragile"
    - ในฟิลด์ Type ให้ป้อนประเภทสินค้าที่อยู่ในโปรไฟล์การจัดส่งนี้ เช่น "fragile" หรือ "heavy"
4. เมื่อเสร็จแล้ว ให้คลิกปุ่ม Save

![ฟอร์มสร้างโปรไฟล์การจัดส่ง](https://res.cloudinary.com/dza7lstvk/image/upload/v1739985215/User%20Guide/Screenshot_2025-02-19_at_7.13.21_PM_wjp2tm.png)

## ดูรายละเอียดโปรไฟล์การจัดส่ง

วิธีการดูรายละเอียดของโปรไฟล์การจัดส่ง:

1. ไปที่ Settings → Location & Shipping -> Shipping Profiles
2. คลิกโปรไฟล์การจัดส่งจากรายการ

การดำเนินการนี้จะเปิดหน้ารายละเอียดของโปรไฟล์การจัดส่ง ซึ่งคุณสามารถจัดการโปรไฟล์การจัดส่งได้เช่นกัน

## จัดการสินค้าในโปรไฟล์การจัดส่ง

คุณสามารถจัดการโปรไฟล์การจัดส่งของสินค้าได้ใน [หน้ารายละเอียดของสินค้า](../../../products/edit/page.mdx#edit-products-shipping-profile)

## จัดการข้อมูลเมทาดาตาของโปรไฟล์การจัดส่ง

ข้อมูลเมทาดาตา (Metadata) คือข้อมูลที่กำหนดเองซึ่งสามารถเชื่อมโยงกับโปรไฟล์การจัดส่งในรูปแบบของคู่คีย์-ค่า (Key-Value) ซึ่งปกติแล้วนักพัฒนาจะใช้สำหรับการผสานระบบแบบกำหนดเองหรือเพื่อจัดเก็บข้อมูลเพิ่มเติมเกี่ยวกับโปรไฟล์การจัดส่ง

วิธีการแก้ไขข้อมูลเมทาดาตาของโปรไฟล์การจัดส่ง:

1. คลิกไอคอน <InlineIcon Icon={ArrowUpRightOnBox} alt="arrow" /> ในส่วน "Metadata"
2. ในหน้าต่างด้านข้างที่เปิดขึ้น:
    - จัดการคู่คีย์-ค่าในตาราง
    - วิธีการเพิ่มแถวคู่คีย์-ค่าใหม่ก่อนหน้าหรือหลังแถวที่มีอยู่:
        - วางเมาส์เหนือแถวแล้วคลิกไอคอน <InlineIcon Icon={EllipsisVertical} alt="three-dots" /> ที่ส่วนท้ายของแถว
        - เลือก "Insert row above" (แทรกแถวด้านบน) หรือ "Insert row below" (แทรกแถวด้านล่าง) จากเมนูดรอปดาวน์
    - วิธีการลบแถวคู่คีย์-ค่า:
        - วางเมาส์เหนือแถวแล้วคลิกไอคอน <InlineIcon Icon={EllipsisVertical} alt="three-dots" /> ที่ส่วนท้ายของแถว
        - เลือก "Delete row" จากเมนูดรอปดาวน์
3. เมื่อเสร็จแล้ว ให้คลิกปุ่ม Save

## ลบโปรไฟล์การจัดส่ง

<Note type="warning">

การลบโปรไฟล์การจัดส่งจะไม่สามารถย้อนกลับคืนได้

</Note>

วิธีการลบโปรไฟล์การจัดส่ง:

1. ไปที่หน้ารายละเอียดของโปรไฟล์การจัดส่ง
2. คลิกไอคอน <InlineIcon Icon={EllipsisHorizontal} alt="three-dots" /> ในส่วนหัวของส่วนแรก
3. เลือก Delete จากเมนูดรอปดาวน์
4. ยืนยันการลบโดยป้อนชื่อโปรไฟล์การจัดส่งในป๊อปอัปและคลิกปุ่ม Delete
