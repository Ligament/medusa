# {metadata.title}

ในคู่มือนี้ คุณจะได้เรียนรู้ว่าประเภทตัวเลือกการจัดส่ง (Shipping Option Types) คืออะไร และวิธีการจัดการใน Medusa Admin

<Note>

หน้ารายการตั้งค่าสำหรับ Shipping Option Types ถูกเพิ่มเข้ามาใน [Medusa v2.10.0](https://github.com/medusajs/medusa/releases/tag/v2.10.0)

</Note>

## ประเภทตัวเลือกการจัดส่งคืออะไร?

ประเภทตัวเลือกการจัดส่ง คือ การจำแนกประเภทของตัวเลือกการจัดส่งที่มีคุณลักษณะร่วมกัน ตัวอย่างเช่น คุณสามารถมีประเภทตัวเลือกการจัดส่งสำหรับ "Standard Shipping" (จัดส่งแบบมาตรฐาน) และอีกประเภทสำหรับ "Express Shipping" (จัดส่งด่วน) ได้

ประเภทตัวเลือกการจัดส่งจะช่วยคุณในการจัดระเบียบและจัดการตัวเลือกการจัดส่งของคุณ นอกจากนี้ยังช่วยให้คุณสามารถกำหนดโปรโมชันเฉพาะสำหรับประเภทตัวเลือกการจัดส่งบางประเภทได้อีกด้วย

โดยเริ่มต้น Medusa จะมีประเภทตัวเลือกการจัดส่งมาให้สองประเภท ได้แก่ "Standard" และ "Express" คุณสามารถจัดการประเภทเหล่านี้หรือสร้างประเภทใหม่ขึ้นมาเพื่อให้ตรงกับความต้องการของธุรกิจคุณได้ดีที่สุด

---

## ดูประเภทตัวเลือกการจัดส่ง

วิธีการดูประเภทตัวเลือกการจัดส่งในร้านค้าของคุณ:

1. ไปที่ Settings → Location & Shipping
2. ในส่วน Shipping Configuration ให้คลิกที่ Shipping Option Types

ที่นี่คุณสามารถดูรายการประเภทตัวเลือกการจัดส่งทั้งหมดที่คุณตั้งค่าไว้ในร้านค้าของคุณ นอกจากนี้คุณยังสามารถค้นหา กรอง และจัดเรียงประเภทตัวเลือกการจัดส่งเพื่อค้นหารายการที่คุณต้องการได้

## สร้างประเภทตัวเลือกการจัดส่ง

วิธีการสร้างประเภทตัวเลือกการจัดส่ง:

1. ไปที่ Settings → Location & Shipping
2. ในส่วน Shipping Configuration ให้คลิกที่ Shipping Option Types
3. คลิกปุ่ม Create ในส่วนหัวของส่วนหลัก
4. ในฟอร์มที่เปิดขึ้น ให้กรอกข้อมูลดังต่อไปนี้:
    - **Label**: ชื่อของประเภทตัวเลือกการจัดส่งที่ต้องการแสดงให้ลูกค้าเห็น เช่น "Same Day"
    - **Code**: รหัสระบุเฉพาะ (Unique Identifier) สำหรับประเภทตัวเลือกการจัดส่ง เช่น `same_day`
    - **Description**: คำอธิบายสั้น ๆ ของประเภทตัวเลือกการจัดส่ง ซึ่งไม่บังคับ แต่จะมีประโยชน์ในการให้บริบทเพิ่มเติมเกี่ยวกับประเภทจัดส่งนี้ เช่น "จัดส่งภายในวันเดียวกัน"
5. เมื่อเสร็จแล้ว ให้คลิกปุ่ม Create ที่ด้านล่าง

## ดูรายละเอียดประเภทตัวเลือกการจัดส่ง

วิธีการดูรายละเอียดของประเภทตัวเลือกการจัดส่ง:

1. ไปที่ Settings → Shipping Option Types
2. คลิกประเภทตัวเลือกการจัดส่งที่คุณต้องการดู

การดำเนินการนี้จะเปิดหน้ารายละเอียดของประเภทตัวเลือกการจัดส่ง ซึ่งคุณสามารถจัดการประเภทตัวเลือกการจัดส่งนั้นได้ด้วยเช่นกัน

![หน้ารายละเอียดประเภทตัวเลือกการจัดส่ง](https://res.cloudinary.com/dza7lstvk/image/upload/v1756371925/User%20Guide/CleanShot_2025-08-28_at_12.05.14_2x_se4xzx.png)

## แก้ไขรายละเอียดประเภทตัวเลือกการจัดส่ง

วิธีการแก้ไขรายละเอียดของประเภทตัวเลือกการจัดส่ง:

1. ไปที่หน้ารายละเอียดของประเภทตัวเลือกการจัดส่ง
2. คลิกปุ่ม <InlineIcon Icon={EllipsisHorizontal} alt="three-dots" /> ในส่วนหัวของส่วนแรก
3. เลือก "Edit" จากเมนูดรอปดาวน์
4. ในหน้าต่างด้านข้างที่เปิดขึ้น คุณสามารถแก้ไข ป้ายชื่อ (Label), รหัส (Code) และคำอธิบาย (Description) ของประเภทตัวเลือกการจัดส่งได้
5. เมื่อเสร็จแล้ว ให้คลิกปุ่ม Save

![ฟอร์มแก้ไขประเภทตัวเลือกการจัดส่ง](https://res.cloudinary.com/dza7lstvk/image/upload/v1756372034/User%20Guide/CleanShot_2025-08-28_at_12.07.01_2x_xqk3vk.png)

## ลบประเภทตัวเลือกการจัดส่ง

<Note type="warning">

การลบประเภทตัวเลือกการจัดส่งจะไม่สามารถย้อนกลับคืนได้

</Note>

วิธีการลบประเภทตัวเลือกการจัดส่ง:

1. ไปที่หน้ารายละเอียดของประเภทตัวเลือกการจัดส่ง
2. คลิกปุ่ม <InlineIcon Icon={EllipsisHorizontal} alt="three-dots" /> ในส่วนหัวของส่วนแรก
3. เลือก "Delete" จากเมนูดรอปดาวน์
4. ยืนยันการลบประเภทตัวเลือกการจัดส่งในป๊อปอัป
