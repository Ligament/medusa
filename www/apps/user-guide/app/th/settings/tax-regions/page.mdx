# {metadata.title}

ในคู่มือนี้ คุณจะได้เรียนรู้ว่าเขตภาษี (Tax Regions) คืออะไร และวิธีการจัดการเขตภาษีเหล่านั้น

## เขตภาษีคืออะไร?

เขตภาษี หมายถึง พื้นที่ทางภูมิศาสตร์ที่คุณต้องใช้บังคับอัตราภาษีเฉพาะ ตัวอย่างเช่น หากคุณดำเนินธุรกิจในสหรัฐอเมริกาและแคนาดา คุณอาจมีอัตราภาษีที่แตกต่างกันในแต่ละประเทศ และแม้กระทั่งในรัฐหรือรัฐย่อยที่แตกต่างกันภายในแต่ละประเทศ

ในกรณีนี้ คุณสามารถสร้างเขตภาษีสำหรับแต่ละประเทศที่คุณดำเนินธุรกิจ และตั้งค่า [เขตภาษีย่อย](#sublevel-tax-regions) สำหรับแต่ละรัฐหรือแต่ละจังหวัดภายในประเทศนั้นได้

แต่ละเขตภาษีจะมีอัตราภาษีของตนเอง และคุณสามารถกำหนดอัตราภาษีพิเศษแทนที่อัตราภาษีเริ่มต้นในเขตนั้น ๆ สำหรับสินค้าหรือประเภทสินค้าเฉพาะได้

---

## ดูเขตภาษี

หากต้องการดูเขตภาษีในร้านค้าของคุณ ให้ไปที่ Settings → Tax Regions ที่นี่คุณสามารถดูรายการเขตภาษีทั้งหมดที่คุณตั้งค่าไว้ในร้านค้าของคุณ นอกจากนี้คุณยังสามารถค้นหา กรอง และจัดเรียงเขตภาษีเพื่อค้นหารายการที่คุณต้องการได้

![รายการเขตภาษี](https://res.cloudinary.com/dza7lstvk/image/upload/v1739970754/User%20Guide/Screenshot_2025-02-19_at_3.12.16_PM_iy8kvy.png)

## สร้างเขตภาษี

วิธีการสร้างเขตภาษี:

1. ไปที่ Settings → Tax Regions
2. คลิกปุ่ม Create ในส่วนหัวของส่วนหลัก
3. ในฟอร์มที่เปิดขึ้น:
    - ในฟิลด์ Country ให้เลือกประเทศที่ต้องการใช้เขตภาษีนี้
    - ในส่วน "Default tax rate" คุณสามารถป้อนชื่อ อัตราภาษี และรหัสภาษีในฟิลด์ที่เกี่ยวข้องได้ (ไม่บังคับ)
4. เมื่อเสร็จแล้ว ให้คลิกปุ่ม Save

![ฟอร์มสร้างเขตภาษี](https://res.cloudinary.com/dza7lstvk/image/upload/v1746803850/User%20Guide/Screenshot_2025-05-09_at_6.14.41_PM_vzpyza.png)

## ดูรายละเอียดเขตภาษี

วิธีการดูรายละเอียดของเขตภาษี:

1. ไปที่ Settings → Tax Regions
2. คลิกที่เขตภาษีจากรายการ

การดำเนินการนี้จะเปิดหน้ารายละเอียดของเขตภาษี ซึ่งคุณสามารถจัดการเขตภาษีนั้นได้ด้วยเช่นกัน

![รายละเอียดเขตภาษี](https://res.cloudinary.com/dza7lstvk/image/upload/v1746796437/User%20Guide/Screenshot_2025-05-09_at_4.13.06_PM_m23ili.png)

## แก้ไขเขตภาษี

วิธีการแก้ไขเขตภาษี:

1. ไปที่หน้ารายละเอียดของเขตภาษี
2. คลิกไอคอน <InlineIcon Icon={EllipsisHorizontal} alt="three-dots" /> ที่ส่วนท้ายของแถวเขตภาษี
3. เลือก Edit จากเมนูดรอปดาวน์
4. ในหน้าต่างด้านข้างที่เปิดขึ้น คุณสามารถแก้ไขผู้ให้บริการด้านภาษีเริ่มต้น (Default Tax Provider) ของเขตภาษีได้
5. เมื่อเสร็จแล้ว ให้คลิกปุ่ม Save

![ฟอร์มแก้ไขเขตภาษี](https://res.cloudinary.com/dza7lstvk/image/upload/v1746803872/User%20Guide/Screenshot_2025-05-09_at_6.15.25_PM_ebb76k.png)

## แก้ไขอัตราภาษีเริ่มต้น

วิธีการแก้ไขอัตราภาษีเริ่มต้นของเขตภาษี:

1. ไปที่หน้ารายละเอียดของเขตภาษี
2. ในส่วนแรก คุณจะพบรายละเอียดของอัตราภาษีเริ่มต้น รวมถึงอัตราภาษีและรหัสภาษี ให้คลิกไอคอน <InlineIcon Icon={EllipsisHorizontal} alt="three-dots" /> ที่ส่วนท้ายของแถว

![ไอคอนที่จะคลิก](https://res.cloudinary.com/dza7lstvk/image/upload/v1739974452/User%20Guide/Screenshot_2025-02-19_at_4.13.51_PM_zclvnp.png)

3. เลือก Edit จากเมนูดรอปดาวน์
4. ในหน้าต่างด้านข้างที่เปิดขึ้น คุณสามารถแก้ไขชื่อ รหัส และอัตราภาษีที่จะเรียกเก็บได้
5. เมื่อเสร็จแล้ว ให้คลิกปุ่ม Save

## จัดการการกำหนดอัตราภาษีพิเศษ

คุณสามารถกำหนดอัตราภาษีพิเศษ (Tax Rate Override) แทนที่อัตราภาษีเริ่มต้นของเขตภาษีสำหรับสินค้าเฉพาะ ประเภทสินค้า หรือตัวเลือกการจัดส่งได้ ซึ่งมีประโยชน์หากคุณมีอัตราภาษีที่แตกต่างกันสำหรับสินค้าหรือการจัดส่งบางประเภทในเขตภาษีนั้น ๆ

คุณสามารถกำหนดอัตราภาษีพิเศษสำหรับเขตภาษีหลักและ [เขตภาษีย่อย](#sublevel-tax-regions) ได้

### สร้างการกำหนดอัตราภาษีพิเศษ

วิธีการสร้างการกำหนดอัตราภาษีพิเศษสำหรับสินค้าหรือประเภทสินค้าในเขตภาษี:

1. ไปที่หน้ารายละเอียดของเขตภาษี
2. ในส่วน "Overrides" ให้คลิกปุ่ม Create
3. ในฟอร์มที่เปิดขึ้น:
    - ป้อนชื่อ อัตราภาษี และรหัสของการกำหนดอัตราภาษีพิเศษในฟิลด์ที่เกี่ยวข้อง
    - หากการกำหนดอัตราภาษีพิเศษนี้ใช้สำหรับเขตภาษีย่อยและควรนำไปรวมกับอัตราภาษีของเขตภาษีหลัก (Parent Region) ให้เปิดปุ่มเปิดปิด "Combinable" ตัวเลือกนี้จะมีผลเฉพาะกับเขตภาษีย่อย (ระดับรัฐหรือจังหวัด) เท่านั้น
    - ในส่วน "Targets" คุณสามารถเลือกเป้าหมายที่จะใช้อัตราภาษีพิเศษนี้ได้ โดยคลิก "Add target" สำหรับแต่ละเป้าหมาย:
        - เลือกประเภทเป้าหมาย (Product, Product Type หรือ Shipping Option)
        - เลือกสินค้า ประเภทสินค้า หรือตัวเลือกการจัดส่งที่ต้องการใช้อัตราภาษีพิเศษนี้ ตามประเภทเป้าหมายที่คุณเลือก
4. เมื่อเสร็จแล้ว ให้คลิกปุ่ม Save

![ฟอร์มสร้างการกำหนดอัตราภาษีพิเศษ](https://res.cloudinary.com/dza7lstvk/image/upload/v1739974979/User%20Guide/Screenshot_2025-02-19_at_4.22.43_PM_jup0sn.png)

### แก้ไขการกำหนดอัตราภาษีพิเศษ

วิธีการแก้ไขการกำหนดอัตราภาษีพิเศษ:

1. ไปที่หน้ารายละเอียดของเขตภาษี
2. ในส่วน "Overrides" ให้คลิกไอคอน <InlineIcon Icon={EllipsisHorizontal} alt="three-dots" /> ข้างรายการอัตราภาษีพิเศษที่ต้องการแก้ไข
3. เลือก Edit จากเมนูดรอปดาวน์
4. ในหน้าต่างด้านข้างที่เปิดขึ้น คุณสามารถแก้ไขชื่อ อัตราภาษี รหัส และเลือกว่าจะนำไปรวมกับอัตราภาษีเริ่มต้นหรือไม่ นอกจากนี้คุณยังสามารถแก้ไขเป้าหมายของการกำหนดอัตราภาษีพิเศษนี้ได้ด้วย
5. เมื่อเสร็จแล้ว ให้คลิกปุ่ม Save

![ฟอร์มแก้ไขการกำหนดอัตราภาษีพิเศษ](https://res.cloudinary.com/dza7lstvk/image/upload/v1739975201/User%20Guide/Screenshot_2025-02-19_at_4.26.22_PM_y4deom.png)

## เขตภาษีย่อย

เขตภาษีสำหรับบางประเทศ เช่น สหรัฐอเมริกา จะมีส่วนจัดการระดับรัฐ (States), จังหวัด (Province) หรือมณฑล (Cantons) ในหน้ารายละเอียดของเขตภาษี ซึ่งคุณสามารถเพิ่มเขตภาษีย่อยสำหรับประเทศนั้น ๆ ได้

![ส่วนเขตภาษีย่อย](https://res.cloudinary.com/dza7lstvk/image/upload/v1739975474/User%20Guide/Screenshot_2025-02-19_at_4.30.57_PM_ogjlp2.png)

คุณยังสามารถเปิดใช้งานส่วนนี้สำหรับประเทศอื่น ๆ ที่ไม่ได้แสดงส่วนนี้ตามค่าเริ่มต้นได้อีกด้วย โดยสำหรับประเทศเหล่านั้น คุณจะพบข้อความแนะนำที่ด้านบนของหน้าเพื่อให้คุณสามารถกดเปิดใช้งานเขตภาษีย่อยได้

![แจ้งเตือนการเปิดใช้งานเขตภาษีย่อย](https://res.cloudinary.com/dza7lstvk/image/upload/v1739971332/User%20Guide/Screenshot_2025-02-19_at_3.21.51_PM_mbm8lr.png)

หลังจากเปิดใช้งานการตั้งค่านี้แล้ว คุณจะพบส่วน "Sublevels" ในหน้ารายละเอียดของเขตภาษี ซึ่งคุณสามารถเพิ่มเขตภาษีย่อยได้

### สร้างเขตภาษีย่อย

วิธีการสร้างเขตภาษีย่อยในเขตภาษี:

1. ไปที่หน้ารายละเอียดของเขตภาษี
2. ในส่วน "Sublevels" หรือเทียบเท่า (เช่น States, Province หรือ Cantons) ให้คลิกปุ่ม "Create"
3. ในฟอร์มที่เปิดขึ้น:
    - หากประเทศนั้นรองรับเขตย่อยตามค่าเริ่มต้น คุณจะพบส่วนสำหรับเลือก รัฐ, จังหวัด หรือมณฑล
    - หากประเทศนั้นไม่รองรับเขตย่อยตามค่าเริ่มต้น คุณจะพบช่องป้อนข้อมูลเพื่อให้คุณระบุ [รหัส ISO 3166-2](https://en.wikipedia.org/wiki/ISO_3166-2) ตัวพิมพ์เล็กของเขตย่อยนั้น
    - ในส่วน "Default tax rate" คุณสามารถระบุชื่อ อัตราภาษี และรหัสภาษีในฟิลด์ที่เกี่ยวข้องได้ (ไม่บังคับ)
    - หากต้องการนำอัตราภาษีของเขตภาษีย่อยไปรวมกับอัตราภาษีของเขตภาษีหลัก ให้เปิดปุ่มเปิดปิด "Combinable"
4. เมื่อเสร็จแล้ว ให้คลิกปุ่ม Save

![ฟอร์มสร้างเขตภาษีย่อย](https://res.cloudinary.com/dza7lstvk/image/upload/v1739971762/User%20Guide/Screenshot_2025-02-19_at_3.29.09_PM_cpwi4e.png)

### ดูรายละเอียดเขตภาษีย่อย

วิธีการดูรายละเอียดของเขตภาษีย่อย:

1. ไปที่หน้ารายละเอียดของเขตภาษีหลัก
2. ในส่วน "Sublevels" หรือเทียบเท่า ให้คลิกเลือกเขตภาษีย่อยที่ต้องการดู

การดำเนินการนี้จะเปิดหน้ารายละเอียดของเขตภาษีย่อย ซึ่งคุณสามารถจัดการเขตภาษีย่อยนั้นได้เช่นกัน

![หน้ารายละเอียดเขตภาษีย่อย](https://res.cloudinary.com/dza7lstvk/image/upload/v1739974129/User%20Guide/Screenshot_2025-02-19_at_4.08.33_PM_i2v219.png)
