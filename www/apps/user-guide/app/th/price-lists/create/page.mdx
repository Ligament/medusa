# {metadata.title}

ในคู่มือนี้ คุณจะได้เรียนรู้วิธีสร้างรายการราคา

ขั้นตอนการสร้างรายการราคา:

1. ไปที่หน้า Price Lists จากแถบเมนูด้านข้าง
2. คลิกปุ่ม Create ในส่วนหัวของส่วนหลัก

ขั้นตอนนี้จะเปิดฟอร์มสำหรับสร้างรายการราคา ซึ่งประกอบด้วย 3 ขั้นตอน ได้แก่ Details, Products และ Prices

## ขั้นตอนที่ 1: Details (รายละเอียด)

ในขั้นตอนแรกของการสร้างรายการราคา คุณจะต้องระบุข้อมูลทั่วไปของรายการราคา:

1. ในส่วนของ Type (ประเภท) ให้เลือกข้อใดข้อหนึ่งระหว่าง:
    - **Sale**: เหมาะสำหรับการจัดทำรายการราคาลดชั่วคราวสำหรับสินค้าบางชนิด
    - **Override**: เหมาะสำหรับการกำหนดราคาใหม่ทับราคาเดิมแบบถาวรสำหรับกลุ่มลูกค้าเฉพาะ
2. ในฟิลด์ Title ให้ป้อนชื่อของรายการราคา
3. ในฟิลด์ Status ให้เลือกสถานะข้อใดข้อหนึ่งดังนี้:
    - **Active**: เปิดใช้งานรายการราคาและสามารถนำไปใช้งานได้ หากกำหนดวันที่เริ่มต้นใช้งานภายหลัง รายการราคาจะมีผลบังคับใช้ตั้งแต่วันดังกล่าว
    - **Draft**: รายการราคาอยู่ในสถานะร่าง ยังไม่เปิดใช้งานและไม่สามารถนำไปใช้งานได้
4. ในฟิลด์ Description ให้กรอกคำอธิบายสำหรับรายการราคานี้
5. หากคุณต้องการให้รายการราคาเริ่มใช้งานตามวันเวลาที่กำหนด ให้ระบุวันที่ในฟิลด์ "Price list has a start date"
6. หากคุณต้องการให้รายการราคาหมดอายุโดยอัตโนมัติหลังจากวันเวลาที่กำหนด ให้ระบุวันที่ในฟิลด์ "Price list has an expiry date"
7. ในส่วน "Customer availability" (กลุ่มลูกค้าที่ใช้ได้) คุณสามารถระบุกลุ่มลูกค้าที่ราคานี้จะมีผลบังคับใช้ได้ ลูกค้าที่อยู่ในกลุ่มเหล่านั้นจะมองเห็นราคาตามที่ระบุในรายการราคานี้ ขั้นตอนการเลือกกลุ่มลูกค้า:
    - คลิกปุ่ม Browse
    - ในรายการที่เปิดขึ้น ให้เลือกกลุ่มลูกค้าที่ต้องการประย่นต์ใช้รายการราคา
    - เมื่อเรียบร้อยแล้ว ให้คลิกปุ่ม Save
8. เมื่อเสร็จเรียบร้อยแล้ว ให้คลิกปุ่ม Continue เพื่อไปยังขั้นตอนถัดไป

## ขั้นตอนที่ 2: Products (สินค้า)

ในขั้นตอนที่สอง คุณจะเลือกสินค้าที่คุณต้องการเปลี่ยนราคาในรายการราคานี้

โดยให้เลือกสินค้าที่คุณต้องการรวมเข้าในรายการราคา คุณสามารถค้นหา กรอง และจัดเรียงรายการสินค้าเพื่อค้นหาสินค้าชิ้นที่ต้องการได้อย่างสะดวก

เมื่อทำเสร็จแล้ว ให้คลิกปุ่ม Continue เพื่อไปยังขั้นตอนถัดไป

![ฟอร์มเลือกสินค้าสำหรับรายการราคา](https://res.cloudinary.com/dza7lstvk/image/upload/v1739959206/User%20Guide/Screenshot_2025-02-19_at_11.59.53_AM_hgmtl4.png)

## ขั้นตอนที่ 3: Prices (ราคา)

In the last step, you'll use the [Bulk Editor](../../tips/bulk-editor/page.mdx) to enter the new prices for the variants of each product you selected. You can set the prices for every currency and region in your store.

ในขั้นตอนสุดท้าย คุณจะใช้ [เครื่องมือแก้ไขแบบกลุ่ม (Bulk Editor)](../../tips/bulk-editor/page.mdx) เพื่อกรอกราคาใหม่สำหรับตัวเลือกย่อยของแต่ละสินค้าที่คุณเลือกไว้ คุณสามารถกำหนดราคาของทุกสกุลเงินและทุกภูมิภาคที่มีอยู่ในร้านค้าของคุณได้

เมื่อเรียบร้อยแล้ว ให้คลิกปุ่ม Save เพื่อสร้างรายการราคา

![ฟอร์มราคาสำหรับรายการราคา](https://res.cloudinary.com/dza7lstvk/image/upload/v1739959865/User%20Guide/Screenshot_2025-02-19_at_12.10.10_PM_aaxecg.png)

หลังจากเสร็จสิ้นแล้ว คุณสามารถเริ่มต้น [จัดการรายการราคา](../manage/page.mdx) ที่เพิ่งสร้างขึ้นได้ทันที
