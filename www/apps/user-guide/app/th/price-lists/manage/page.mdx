## ดูรายละเอียดรายการราคา

ขั้นตอนการดูรายละเอียดรายการราคา:

1. ไปที่หน้า Price Lists จากแถบเมนูด้านข้าง
2. คลิกที่รายการราคาที่คุณต้องการดู

## แก้ไขรายละเอียดรายการราคา

ขั้นตอนการแก้ไขรายละเอียดรายการราคา:

<Note title="ข้อแนะนำ">

หากต้องการแก้ไขวันที่เริ่มต้น วันหมดอายุ หรือกลุ่มลูกค้าที่ใช้ได้ของรายการราคา โปรดดูที่หัวข้อ [แก้ไขการตั้งค่ารายการราคา](#edit-price-list-configurations)

</Note>

1. ไปที่หน้ารายละเอียดของรายการราคา
2. คลิกไอคอน <InlineIcon Icon={EllipsisHorizontal} alt="three-dots" /> ในส่วนหัวของส่วนแรก
3. เลือก Edit จากเมนูแบบดึงลง
4. ในหน้าต่างด้านข้างที่เปิดขึ้น คุณสามารถแก้ไขประเภท ชื่อ สถานะ และคำอธิบายของรายการราคาได้
    - หากคุณเปลี่ยนสถานะของรายการราคาเป็น Active แต่รายการราคานั้นกำหนดวันที่เริ่มต้นใช้งานไว้ในอนาคต รายการราคาจะแสดงสถานะเป็น "Scheduled" และจะเริ่มใช้งานเมื่อถึงวันที่กำหนดนั้น
5. เมื่อเสร็จสิ้นแล้ว ให้คลิกปุ่ม Save

## แก้ไขการตั้งค่ารายการราคา

การตั้งค่าของรายการราคาครอบคลุมถึงวันที่เริ่มต้น วันหมดอายุ และกลุ่มลูกค้าที่สามารถใช้ราคานี้ได้

1. ไปที่หน้ารายละเอียดของรายการราคา
2. คลิกไอคอน <InlineIcon Icon={EllipsisHorizontal} alt="three-dots" /> ในส่วนหัวของส่วน "Configuration"
3. เลือก Edit จากเมนูแบบดึงลง
4. ในหน้าต่างด้านข้างที่เปิดขึ้น คุณสามารถแก้ไขวันที่เริ่มต้น วันหมดอายุ และกลุ่มลูกค้าที่สามารถใช้งานรายการราคานี้ได้
    - ในการเปลี่ยนกลุ่มลูกค้า ให้คลิกปุ่ม Browse จากนั้นเลือกกลุ่มลูกค้าที่ต้องการ แล้วคลิก Save
5. เมื่อเสร็จสิ้นแล้ว ให้คลิกปุ่ม Save

![ฟอร์มแก้ไขการตั้งค่ารายการราคา](https://res.cloudinary.com/dza7lstvk/image/upload/v1739960935/User%20Guide/Screenshot_2025-02-19_at_12.28.45_PM_jczlo1.png)

## จัดการสินค้าในรายการราคา

จากหน้ารายละเอียดของรายการราคา คุณสามารถจัดการสินค้าต่าง ๆ ที่อยู่ในรายการราคาได้

### เพิ่มสินค้าไปยังรายการราคา

ขั้นตอนการเพิ่มสินค้าไปยังรายการราคา:

1. ไปที่หน้ารายละเอียดของรายการราคา
2. ในส่วนของ Products ให้คลิกไอคอน <InlineIcon Icon={EllipsisHorizontal} alt="three-dots" />
3. เลือก "Add products" จากเมนูแบบดึงลง
4. ติ๊กเลือกสินค้าที่คุณต้องการเพิ่มเข้าไปในรายการราคาจากตารางรายการสินค้าที่ปรากฏ
5. เมื่อเรียบร้อยแล้ว ให้คลิกปุ่ม Continue
6. ในขั้นตอน "Prices" ถัดไป ให้ใช้ [เครื่องมือแก้ไขแบบกลุ่ม (Bulk Editor)](../../tips/bulk-editor/page.mdx) เพื่อกำหนดราคาสำหรับตัวเลือกย่อยของสินค้าที่คุณเพิ่งเพิ่มเข้ามา คุณสามารถระบุราคาในแต่ละสกุลเงินและแต่ละภูมิภาคที่มีอยู่ในร้านค้าของคุณได้
7. เมื่อเสร็จสิ้นแล้ว ให้คลิกปุ่ม Save

### ลบสินค้าออกจากรายการราคา

ขั้นตอนการลบสินค้าออกจากรายการราคา:

1. ไปที่หน้ารายละเอียดของรายการราคา
2. ในส่วนของ Products ให้ติ๊กเลือกสินค้าที่คุณต้องการลบออกจากรายการราคา
3. กดปุ่ม <Kbd>D</Kbd> บนคีย์บอร์ด หรือคลิกปุ่ม "Delete" ที่ปรากฏบริเวณกึ่งกลางด้านล่างของหน้า
4. ยืนยันการลบสินค้าโดยคลิกปุ่ม "Delete" ในหน้าต่างป๊อปอัป

![ลบสินค้าออกจากรายการราคา](https://res.cloudinary.com/dza7lstvk/image/upload/v1739961185/User%20Guide/Screenshot_2025-02-19_at_12.32.55_PM_sfirfu.png)

## แก้ไขราคาในรายการราคา

จากหน้ารายละเอียดของรายการราคา คุณสามารถจัดการราคาพิเศษ (price overrides) ของสินค้าต่าง ๆ ที่อยู่ในรายการราคาได้

ขั้นตอนการแก้ไขราคาสินค้าในรายการราคา:

1. ไปที่หน้ารายละเอียดของรายการราคา
2. ในส่วนของ Products ให้คลิกไอคอน <InlineIcon Icon={EllipsisHorizontal} alt="three-dots" />
3. เลือก "Edit prices" จากเมนูแบบดึงลง
4. ขั้นตอนนี้จะเปิด [เครื่องมือแก้ไขแบบกลุ่ม (Bulk Editor)](../../tips/bulk-editor/page.mdx) เพื่อให้คุณแก้ไขราคาของตัวเลือกสินค้าต่าง ๆ ได้ คุณสามารถระบุราคาในแต่ละสกุลเงินและแต่ละภูมิภาคที่มีอยู่ในร้านค้าของคุณได้
5. เมื่อเสร็จสิ้นแล้ว ให้คลิกปุ่ม Save

![แก้ไขราคาในรายการราคา](https://res.cloudinary.com/dza7lstvk/image/upload/v1739961309/User%20Guide/Screenshot_2025-02-19_at_12.35.00_PM_kvpnss.png)

### กำหนดราคาตามจำนวนสินค้า

<Note>

การกำหนดราคาตามจำนวนสินค้าใช้งานได้ตั้งแต่ [Medusa v2.17.2](https://github.com/medusajs/medusa/releases/tag/v2.17.2) เป็นต้นไป

</Note>

ในแต่ละคอลัมน์ของสกุลเงินหรือภูมิภาคใน Bulk Editor คุณสามารถกำหนดราคาที่จะมีผลเฉพาะเมื่อลูกค้าสั่งซื้อในช่วงจำนวนที่กำหนดไว้ได้ ตัวอย่างเช่น คุณสามารถให้ราคาที่ถูกลงเมื่อลูกค้าสั่งซื้อตั้งแต่ 10 ชิ้นขึ้นไป

วิธีกำหนดราคาตามจำนวนสินค้าให้กับตัวเลือกย่อย:

1. คลิกที่ช่องของสกุลเงินหรือภูมิภาคที่คุณต้องการกำหนดราคาตามจำนวนสินค้า
2. คลิกไอคอน <InlineIcon Icon={ArrowsPointingOut} alt="arrows-pointing-out" /> ที่อยู่ถัดจากช่องราคาใน Bulk Editor
3. ในฟอร์มที่เปิดขึ้นมา คุณสามารถกำหนดระดับราคา (price tier) ได้ตั้งแต่หนึ่งระดับขึ้นไป โดยคลิกปุ่ม **Add Price** เพื่อเพิ่มระดับราคา
4. ในแต่ละระดับราคา ให้กรอกข้อมูลในช่องต่อไปนี้:
    - **Product variant price**: ราคาสำหรับช่วงจำนวนนี้
    - **Minimum cart quantity**: จำนวนสั่งซื้อขั้นต่ำที่จะทำให้ราคานี้มีผล
        - หากต้องการกำหนด ให้คลิกไอคอน <InlineIcon Icon={PlusMini} alt="plus" /> แล้วกรอกจำนวนขั้นต่ำในช่องที่ปรากฏขึ้น
        - หากต้องการลบออก ให้คลิกไอคอน <InlineIcon Icon={XMarkMini} alt="x" /> ที่อยู่ถัดจากช่องจำนวนขั้นต่ำ
    - **Maximum cart quantity**: จำนวนสั่งซื้อสูงสุดที่จะทำให้ราคานี้มีผล
        - หากต้องการกำหนด ให้คลิกไอคอน <InlineIcon Icon={PlusMini} alt="plus" /> แล้วกรอกจำนวนสูงสุดในช่องที่ปรากฏขึ้น
        - หากต้องการลบออก ให้คลิกไอคอน <InlineIcon Icon={XMarkMini} alt="x" /> ที่อยู่ถัดจากช่องจำนวนสูงสุด
5. เพิ่มระดับราคาได้ตามต้องการสำหรับแต่ละช่วงจำนวนสินค้า
6. เมื่อเรียบร้อยแล้ว ให้คลิกปุ่ม **Save** เพื่อใช้งานราคาตามจำนวนสินค้าที่กำหนดไว้

## จัดการข้อมูลเมทาดาตาของรายการราคา

<Note>

ส่วน Metadata สามารถใช้งานได้ตั้งแต่ [Medusa v2.15.0](https://github.com/medusajs/medusa/releases/tag/v2.15.0) เป็นต้นไป หากคุณไม่เห็นส่วน Metadata ใน Medusa Admin ของคุณ โปรดแจ้งทีมเทคนิคให้ [อัปเกรดแอปพลิเคชัน Medusa ของคุณ](!docs!/learn/update)

</Note>

เมทาดาตา (Metadata) คือข้อมูลที่กำหนดเองซึ่งสามารถเชื่อมโยงกับรายการราคาในรูปแบบคู่คีย์-ค่า (key-value pairs) โดยส่วนใหญ่แล้วนักพัฒนาจะใช้สิ่งนี้สำหรับการรวมระบบที่กำหนดเอง หรือเพื่อจัดเก็บข้อมูลเพิ่มเติมเกี่ยวกับรายการราคา

ขั้นตอนการแก้ไขข้อมูลเมทาดาตาของรายการราคา:

1. คลิกไอคอน <InlineIcon Icon={ArrowUpRightOnBox} alt="arrow" /> ในส่วน "Metadata"
2. ในหน้าต่างด้านข้างที่เปิดขึ้น:
    - จัดการคู่คีย์-ค่าในตาราง
    - หากต้องการเพิ่มแถวของคู่คีย์-ค่าใหม่ก่อนหน้าหรือหลังแถวที่มีอยู่เดิม:
        - ชี้เมาส์ไปที่แถวดังกล่าวแล้วคลิกไอคอน <InlineIcon Icon={EllipsisVertical} alt="three-dots" /> ที่ส่วนท้ายของแถว
        - เลือก "Insert row above" (แทรกแถวด้านบน) หรือ "Insert row below" (แทรกแถวด้านล่าง) จากเมนูแบบดึงลง
    - หากต้องการลบแถวของคู่คีย์-ค่า:
        - ชี้เมาส์ไปที่แถวดังกล่าวแล้วคลิกไอคอน <InlineIcon Icon={EllipsisVertical} alt="three-dots" /> ที่ส่วนท้ายของแถว
        - เลือก "Delete row" (ลบแถว) จากเมนูแบบดึงลง
3. เมื่อคุณดำเนินการเสร็จแล้ว ให้คลิกปุ่ม Save

## ลบรายการราคา

<Note type="warning">

การลบรายการราคาไม่สามารถย้อนคืนได้

</Note>

ขั้นตอนการลบรายการราคา:

1. ไปที่หน้ารายละเอียดของรายการราคา
2. คลิกที่ไอคอน <InlineIcon Icon={EllipsisHorizontal} alt="three-dots" /> ในส่วนหัวของส่วนแรก
3. เลือก Delete จากเมนูแบบดึงลง
4. ในหน้าต่างป๊อปอัป ให้พิมพ์ชื่อ (title) ของรายการราคา แล้วคลิกปุ่ม "Delete"
