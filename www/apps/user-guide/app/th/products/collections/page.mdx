# {metadata.title}

ในคู่มือนี้ คุณจะได้เรียนรู้วิธีสร้างและจัดการคอลเลกชันสินค้า

## คอลเลกชันสินค้าสำหรับจัดกลุ่มสินค้า

คอลเลกชันสินค้าคือกลุ่มสินค้าที่มีธีมหรือวัตถุประสงค์ร่วมกัน ตัวอย่างเช่น คอลเลกชันฤดูร้อนอาจรวมสินค้าประเภทชุดว่ายน้ำ แว่นกันแดด และผ้าเช็ดตัว คอลเลกชันช่วยให้ลูกค้าค้นหาสินค้าที่เหมาะสมกับพวกเขาได้ง่ายขึ้น และช่วยเพิ่มความสะดวกในการเลือกซื้อสินค้าในร้านค้าของคุณ

สินค้าหนึ่งรายการสามารถจัดอยู่ในคอลเลกชันได้เพียงคอลเลกชันเดียวเท่านั้น คุณสามารถเรียนรู้วิธีตั้งค่าคอลเลกชันสำหรับสินค้าได้ใน[คู่มือนี้](../edit/page.mdx#manage-product-organization)

### รายการคอลเลกชันสินค้า

หากต้องการดูคอลเลกชันสินค้าทั้งหมด ให้ไปที่หน้า Products → Collections (สินค้า → คอลเลกชัน) จากหน้านี้ คุณสามารถดูรายการ กรองข้อมูล และค้นหาผ่านคอลเลกชันทั้งหมดได้

![รายการคอลเลกชันสินค้า](https://res.cloudinary.com/dza7lstvk/image/upload/v1739871944/User%20Guide/Screenshot_2025-02-18_at_11.45.27_AM_ca1kie.png)

## สร้างคอลเลกชันสินค้า

ขั้นตอนการสร้างคอลเลกชัน:

1. ไปที่หน้า Products → Collections
2. คลิกปุ่ม Create ในส่วนหัวของส่วนหลัก
3. ในฟอร์มที่เปิดขึ้น:
    1. ป้อนชื่อคอลเลกชันในฟิลด์ Title
    2. ค่าในฟิลด์ Handle จะถูกใช้เป็น URL ของคอลเลกชันบนหน้าร้าน ซึ่งช่วยให้คุณสามารถสร้าง URL คอลเลกชันที่อ่านเข้าใจง่าย โดย Handle จะต้องไม่ซ้ำกันในทุกคอลเลกชัน และต้องประกอบด้วยตัวอักษรภาษาอังกฤษตัวพิมพ์เล็ก ตัวเลข และเครื่องหมายยัติภังค์ (`-`) หากไม่ได้ระบุไว้ Medusa จะสร้าง handle จาก Title โดยอัตโนมัติ
4. เมื่อเรียบร้อยแล้ว ให้คลิกปุ่ม Create

![ฟอร์มสร้างคอลเลกชัน](https://res.cloudinary.com/dza7lstvk/image/upload/v1739872385/User%20Guide/Screenshot_2025-02-18_at_11.50.24_AM_mqznbe.png)

## ดูรายละเอียดคอลเลกชันสินค้า

ขั้นตอนการดูรายละเอียดคอลเลกชัน:

1. ไปที่หน้า Products → Collections
2. เลือกคอลเลกชันที่คุณต้องการดูจากรายการ

## แก้ไขคอลเลกชันสินค้า

ขั้นตอนการแก้ไขคอลเลกชัน:

1. ไปที่หน้ารายละเอียดของคอลเลกชัน
2. คลิกไอคอน <InlineIcon Icon={EllipsisHorizontal} alt="three dots" /> ในส่วนหัวของส่วนแรก
3. เลือก Edit จากเมนูแบบดึงลง
4. ในหน้าต่างด้านข้างที่เปิดขึ้น คุณสามารถแก้ไข Title และ Handle ของคอลเลกชันได้
5. เมื่อเรียบร้อยแล้ว ให้คลิกปุ่ม Save

![ฟอร์มแก้ไขคอลเลกชัน](https://res.cloudinary.com/dza7lstvk/image/upload/v1739873760/User%20Guide/Screenshot_2025-02-18_at_12.15.46_PM_mze7zv.png)

## จัดการคำแปลของคอลเลกชันสินค้า

<Note>

การตั้งค่าภาษา (Locales) สามารถใช้งานได้ตั้งแต่ [Medusa v2.12.3](https://github.com/medusajs/medusa/releases/tag/v2.12.3) เป็นต้นไป หากคุณไม่เห็นการจัดการคำแปลใน Medusa Admin ของคุณ โปรดประสานงานทีมเทคนิคของคุณให้ [อัปเกรดแอปพลิเคชัน Medusa ของคุณ](!docs!/learn/update)

</Note>

คอลเลกชันสินค้าสามารถแปลเป็นภาษาต่าง ๆ [ที่ร้านค้าของคุณรองรับ](../../settings/store/page.mdx#manage-store-locales) คุณสามารถจัดการคำแปล [แบบพร้อมกันทั้งหมด (in bulk)](../../settings/translations/page.mdx) หรือจัดการคำแปลสำหรับคอลเลกชันสินค้าแต่ละรายการได้จากหน้ารายละเอียดของคอลเลกชันนั้น ๆ

ขั้นตอนการจัดการคำแปลของคอลเลกชันสินค้า:

1. คลิกไอคอน <InlineIcon Icon={EllipsisHorizontal} alt="three-dots" /> ในส่วนหัวของส่วนแรก
2. เลือก "Manage translations" จากเมนูแบบดึงลง
3. ใน [เครื่องมือแก้ไขแบบกลุ่ม (bulk editor)](../../tips/bulk-editor/page.mdx) ที่เปิดขึ้น คุณสามารถดูและแก้ไขคำแปลสำหรับชื่อ (title) ของคอลเลกชันสินค้าในแต่ละภาษาที่ร้านค้าของคุณรองรับ
    - ในการแก้ไขข้อความที่มีความยาวหลายบรรทัด ให้ดับเบิลคลิกที่เซลล์นั้นเพื่อเปิดกล่องป้อนข้อความที่ใหญ่ขึ้น
4. เมื่อแก้ไขเสร็จสิ้นแล้ว ให้คลิกปุ่ม Save เพื่อบันทึกการเปลี่ยนแปลง

## แก้ไขข้อมูลเมทาดาตาของคอลเลกชันสินค้า

เมทาดาตา (Metadata) คือข้อมูลที่กำหนดเองซึ่งสามารถเชื่อมโยงกับคอลเลกชันสินค้าในรูปแบบคู่คีย์-ค่า (key-value pairs) โดยส่วนใหญ่แล้วนักพัฒนาจะใช้สิ่งนี้สำหรับการรวมระบบที่กำหนดเอง หรือเพื่อจัดเก็บข้อมูลเพิ่มเติมเกี่ยวกับคอลเลกชันสินค้า

ขั้นตอนการแก้ไขข้อมูลเมทาดาตาของคอลเลกชันสินค้า:

1. ไปที่หน้ารายละเอียดของคอลเลกชันสินค้า
2. คลิกไอคอน <InlineIcon Icon={ArrowUpRightOnBox} alt="arrow" /> ในส่วน "Metadata"
3. ในหน้าต่างด้านข้างที่เปิดขึ้น:
    - จัดการคู่คีย์-ค่าในตาราง
    - หากต้องการเพิ่มแถวของคู่คีย์-ค่าใหม่ก่อนหน้าหรือหลังแถวที่มีอยู่เดิม:
        - ชี้เมาส์ไปที่แถวดังกล่าวแล้วคลิกไอคอน <InlineIcon Icon={EllipsisVertical} alt="three-dots" /> ที่ส่วนท้ายของแถว
        - เลือก "Insert row above" (แทรกแถวด้านบน) หรือ "Insert row below" (แทรกแถวด้านล่าง) จากเมนูแบบดึงลง
    - หากต้องการลบแถวของคู่คีย์-ค่า:
        - ชี้เมาส์ไปที่แถวดังกล่าวแล้วคลิกไอคอน <InlineIcon Icon={EllipsisVertical} alt="three-dots" /> ที่ส่วนท้ายของแถว
        - เลือก "Delete row" (ลบแถว) จากเมนูแบบดึงลง
4. เมื่อคุณดำเนินการเสร็จสิ้นแล้ว ให้คลิกปุ่ม Save

## จัดการสินค้าในคอลเลกชัน

จากหน้ารายละเอียดคอลเลกชันสินค้า คุณสามารถจัดการสินค้าต่าง ๆ ที่อยู่ในคอลเลกชันนั้นได้

### เพิ่มสินค้าไปยังคอลเลกชัน

ขั้นตอนการเพิ่มสินค้าไปยังคอลเลกชัน:

1. ไปที่หน้ารายละเอียดของคอลเลกชัน
2. ในส่วนของ Products ให้คลิกที่ไอคอน <InlineIcon Icon={EllipsisHorizontal} alt="three dots" /> ในส่วนหัวของส่วนนั้น
3. เลือก Add จากเมนูแบบดึงลง
4. ติ๊กเลือกสินค้าที่คุณต้องการเพิ่มลงในคอลเลกชันจากรายการสินค้า
5. เมื่อเรียบร้อยแล้ว ให้คลิกปุ่ม Save

![ฟอร์มเพิ่มสินค้าไปยังคอลเลกชัน](https://res.cloudinary.com/dza7lstvk/image/upload/v1739873949/User%20Guide/Screenshot_2025-02-18_at_12.18.55_PM_q6lgsk.png)

### ลบสินค้าออกจากคอลเลกชัน

ขั้นตอนการลบสินค้าออกจากคอลเลกชัน:

1. ไปที่หน้ารายละเอียดของคอลเลกชัน
2. ในส่วนของ Products ค้นหาสินค้าที่คุณต้องการลบออกจากคอลเลกชัน
3. คลิกไอคอน <InlineIcon Icon={EllipsisHorizontal} alt="three dots" /> ในแถวของสินค้ารายการนั้น
4. เลือก Remove จากเมนูแบบดึงลง
5. ยืนยันการลบสินค้าโดยคลิกปุ่ม "Remove" ในหน้าต่างป๊อปอัป

## ลบคอลเลกชัน

<Note type="warning">

การลบคอลเลกชันไม่สามารถย้อนคืนได้

</Note>

ขั้นตอนการลบคอลเลกชัน:

1. ไปที่หน้ารายละเอียดของคอลเลกชัน
2. คลิกที่ไอคอน <InlineIcon Icon={EllipsisHorizontal} alt="three dots" /> ในส่วนหัวของส่วนแรก
3. เลือก Delete จากเมนูแบบดึงลง
4. ยืนยันการลบคอลเลกชันโดยคลิกปุ่ม "Confirm" ในหน้าต่างป๊อปอัป
