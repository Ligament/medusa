ในคู่มือนี้ คุณจะได้เรียนรู้วิธีนำเข้าสินค้าเข้าสู่ร้านค้า Medusa ของคุณ

## นำเข้าสินค้าจากไฟล์ CSV

หากคุณกำลังย้ายข้อมูลมาจากแพลตฟอร์มอีคอมเมิร์ซอื่น หรือจาก Medusa v1 คุณสามารถนำเข้าสินค้าไปยัง Medusa ได้โดยใช้ไฟล์ CSV

เมื่อคุณนำเข้าไฟล์ CSV ระบบ Medusa จะสร้างหรืออัปเดตสินค้าตามไฟล์ CSV ที่คุณอัปโหลด

### รูปแบบไฟล์ CSV

ในฟอร์มการนำเข้า คุณสามารถดาวน์โหลดไฟล์เทมเพลต CSV เพื่อดูรูปแบบที่จำเป็นสำหรับการนำเข้าได้

#### แถวในไฟล์ CSV

แต่ละแถวในไฟล์ CSV แสดงถึงตัวเลือกสินค้า (product variant) ที่ต้องการสร้างหรืออัปเดต ดังนั้น หากสินค้าหนึ่งรายการมีหลายตัวเลือกสินค้า แต่ละตัวเลือกจะมีแถวของตัวเองในไฟล์ CSV

ตัวอย่างเช่น สินค้าที่มีสองตัวเลือกสินค้า (สีแดงและสีน้ำเงิน) จะมีสองแถวในไฟล์ CSV โดยแถวหนึ่งเป็นของตัวเลือกสีแดง และอีกแถวหนึ่งเป็นของตัวเลือกสีน้ำเงิน

#### คอลัมน์ในไฟล์ CSV

คอลัมน์ในไฟล์ CSV จะเก็บรายละเอียดของตัวเลือกสินค้าและสินค้าที่เกี่ยวข้อง ไฟล์ CSV สามารถมีคอลัมน์ต่อไปนี้ได้:

## นำเข้าข้อมูลรายการสินค้า

<Prerequisites
  items={[

      link: "#csv-file-format",
    }
  ]}
/>

ขั้นตอนการนำเข้าสินค้า:

1. ไปที่หน้า Products
2. คลิกปุ่ม Import ในส่วนหัวของส่วนหลัก
3. ในหน้าต่างด้านข้าง:
    1. หากคุณไม่แน่ใจเกี่ยวกับรูปแบบไฟล์ CSV คุณสามารถดาวน์โหลดเทมเพลตไฟล์ CSV ได้
    2. สำหรับการอัปโหลดไฟล์ CSV ที่ต้องการนำเข้าสินค้า คุณสามารถลากและวางไฟล์ในพื้นที่อัปโหลด หรือคลิกที่บริเวณดังกล่าวเพื่อเปิดหน้าต่างเลือกไฟล์
    3. หลังจากที่คุณอัปโหลดไฟล์ CSV แล้ว:
        1. ตรวจสอบจำนวนสินค้าที่จะถูกสร้างขึ้นหรือได้รับการอัปเดต
        2. หากต้องการลบไฟล์ที่อัปโหลด ให้คลิกไอคอน <InlineIcon Icon={EllipsisHorizontal} alt="trash" /> และเลือก Delete จากเมนูแบบดึงลง
4. เมื่อเรียบร้อยแล้ว ให้คลิกปุ่ม Import

![ฟอร์มการนำเข้าสินค้า](https://res.cloudinary.com/dza7lstvk/image/upload/v1739878759/User%20Guide/Screenshot_2025-02-18_at_1.39.01_PM_ctovne.png)

กระบวนการนำเข้าจะเริ่มต้นขึ้น ซึ่งอาจใช้เวลาสักครู่

### ตรวจสอบสถานะการนำเข้า

การตรวจสอบว่าการนำเข้าอยู่ระหว่างดำเนินการ เสร็จสิ้น หรือล้มเหลว:

1. คลิกที่ไอคอนการแจ้งเตือน <InlineIcon Icon={BellAlert} alt="bell" /> ในส่วนหัวของหน้า
2. ค้นหารายการนำเข้าสินค้า ซึ่งควรจะเป็นรายการล่าสุดบนรายการแจ้งเตือน

ข้อความบนรายการนำเข้าจะแสดงสถานะปัจจุบันของการนำเข้า

### การแก้ไขปัญหาข้อผิดพลาดในการนำเข้า

หากการนำเข้าล้มเหลว ไม่ว่าจะเป็นระหว่างการวิเคราะห์ไฟล์ CSV หรือระหว่างกระบวนการนำเข้า ให้ตรวจสอบว่า:

1. มีการตั้งค่า [storage integration](!resources!/infrastructure-modules/file) ไว้อย่างถูกต้องในแอปพลิเคชัน Medusa ของคุณ
2. ไฟล์ CSV มีรูปแบบตรงตาม [รูปแบบที่จำเป็น](#csv-file-format)
3. ID ทั้งหมดที่ระบุในไฟล์ CSV (เช่น คอลเลกชัน, หมวดหมู่, แท็ก, ช่องทางการขาย, โปรไฟล์การจัดส่ง ฯลฯ) มีอยู่จริงในแอปพลิเคชัน Medusa ของคุณ

คุณยังสามารถตรวจสอบที่ server logs ของแอปพลิเคชัน Medusa ของคุณเพื่อรับข้อมูลเพิ่มเติมเกี่ยวกับข้อผิดพลาดได้
