# {metadata.title}

ในคู่มือนี้ คุณจะได้เรียนรู้วิธีสร้างสินค้าจัดชุดตามหมวดหมู่ (Category Bundle) ซึ่งเป็นสินค้าที่ลูกค้า "จัดชุดเอง" โดยเลือกสินค้าจากหมวดหมู่ที่คุณกำหนดไว้ คู่มือนี้ครอบคลุม bundle แบบซื้อครั้งเดียว (one-time) หากต้องการขายเป็นแบบสมาชิกที่มีรอบจัดส่งต่อเนื่อง โปรดอ่านคู่มือ [สร้างสินค้าจัดชุดแบบสมาชิก (Subscription Bundle)](./subscription/page.mdx) ต่อจากคู่มือนี้

<Note>

คู่มือนี้ครอบคลุมฟีเจอร์ **Category Bundles** ที่อยู่ในเมนูด้านข้าง หากต้องการสร้างสินค้าจัดชุดที่ใช้คลังสินค้าแบบชุด (inventory kits) โปรดดูคู่มือ [สร้างสินค้าจัดเซต (Bundle)](../bundle/page.mdx)

</Note>

## ภาพรวม

สินค้าจัดชุดตามหมวดหมู่ประกอบด้วยกลุ่มการเลือก (selection group) ตั้งแต่หนึ่งกลุ่มขึ้นไป แต่ละกลุ่มผูกกับหมวดหมู่สินค้า และกำหนดว่าลูกค้าเลือกสินค้าจากกลุ่มนั้นได้กี่ชิ้น ตัวอย่างเช่น กล่องผักอาจมีกลุ่ม "Premium vegetable" ให้ลูกค้าเลือก 1 ถึง 6 รายการ และกลุ่ม "Beverages" ให้เลือกอีก 1 รายการ

บนหน้าร้าน ลูกค้าจะเลือกสินค้าไปทีละกลุ่มตามลำดับจนได้ชุดของตัวเอง:

![หน้าจอการจัดชุดสินค้าบนหน้าร้าน แสดงรายการที่ลูกค้าเลือกไว้](/user-guide/images/category-bundles/storefront-selection.jpg)

เมื่อคุณสร้าง bundle ระบบจะสร้างสินค้าที่เชื่อมโยงกัน (linked product) ให้โดยอัตโนมัติ คุณจัดการราคา รูปภาพ คำอธิบาย ช่องทางการขาย และการเผยแพร่ของ bundle ที่ตัวสินค้านั้นเหมือนสินค้าทั่วไป

สินค้าจัดชุดตามหมวดหมู่มี 2 ประเภท:

- **One-time bundle**: ลูกค้าซื้อและจัดชุดครั้งเดียว ไม่มีตารางจัดส่งหรือกติกาการต่ออายุผูกอยู่ คู่มือนี้ครอบคลุมประเภทนี้
- **Subscription bundle**: การชำระเงินแต่ละครั้งให้สิทธิ์ลูกค้าได้รับ "รอบจัดส่ง" ตามจำนวนที่กำหนด และ subscription ต่ออายุตามกติกาที่คุณตั้งไว้ โปรดดูคู่มือ [สร้างสินค้าจัดชุดแบบสมาชิก](./subscription/page.mdx)

ก่อนสร้าง bundle ตรวจสอบให้แน่ใจว่าสินค้าที่จะให้ลูกค้าเลือกถูกจัดอยู่ในหมวดหมู่ที่ถูกต้องแล้ว ตามคู่มือ [จัดการหมวดหมู่](../../categories/page.mdx)

## สร้าง Category Bundle แบบซื้อครั้งเดียว

วิธีสร้างสินค้าจัดชุดแบบซื้อครั้งเดียว:

1. ไปที่เมนู **Category Bundles** จากแถบเมนูด้านข้าง

![หน้ารายการ Category Bundles ใน Medusa Admin](/user-guide/images/category-bundles/category-bundles-list.jpg)

2. คลิกปุ่ม **Create Bundle** ที่มุมขวาบน ระบบจะเปิดฟอร์ม "Create category bundle"
3. กรอก **Bundle name** ระบบจะใช้ชื่อนี้เป็นชื่อของสินค้าที่สร้างให้อัตโนมัติ ซึ่งคุณเปลี่ยนชื่อได้ภายหลัง
4. ปิดสวิตช์ **Subscription bundle** สวิตช์นี้เปิดอยู่เป็นค่าเริ่มต้น เมื่อปิดแล้ว แผงด้านข้างจะแสดงข้อความ "One-time bundle" และไม่มีกติกาการจัดส่งหรือการต่ออายุผูกอยู่

![ฟอร์ม Create category bundle เมื่อปิดสวิตช์ Subscription bundle](/user-guide/images/category-bundles/create-form-onetime.jpg)

5. ตั้งค่ากลุ่มการเลือกของ bundle ตามหัวข้อ "ตั้งค่ากลุ่มการเลือก (Bundle Groups)" ด้านล่าง
6. เมื่อเรียบร้อยแล้ว คลิกปุ่ม **Create bundle**

<Note title="คำเตือน" type="warning">

เลือกประเภทของ bundle ให้ถูกต้องก่อนกดสร้าง เพราะไม่สามารถสลับระหว่าง one-time กับ subscription ได้หลังจากสร้างแล้ว

</Note>

หลังจากสร้าง bundle แล้ว ให้ตั้งราคาและเผยแพร่ตามหัวข้อ "ตั้งราคาและเผยแพร่ Bundle" ด้านล่าง

## ตั้งค่ากลุ่มการเลือก (Bundle Groups)

แต่ละกลุ่มคือหนึ่งขั้นตอนที่ลูกค้าต้องเลือกขณะจัดชุดสินค้าบนหน้าร้าน โดยแต่ละกลุ่มตั้งค่าได้ดังนี้:

- **Category**: (จำเป็น) หมวดหมู่สินค้าที่ให้ลูกค้าเลือก คุณต้องเลือกหมวดหมู่ก่อน จึงจะค้นหาสินค้าในฟิลด์ด้านล่างได้
- **Customer-facing label**: ข้อความที่ลูกค้าเห็นขณะจัดชุด ตัวอย่างเช่น "เลือกผัก 3 อย่าง"
- **Minimum quantity** และ **Maximum quantity**: จำนวนชิ้นรวมขั้นต่ำและสูงสุดที่ลูกค้าเลือกได้ในกลุ่มนี้
- **Maximum per variant**: จำนวนครั้งที่ลูกค้าเลือกสินค้ารายการเดิมซ้ำได้
- **Allowed Products (Whitelist)**: เว้นว่างเพื่อให้เลือกได้ทุกสินค้าในหมวดหมู่ หรือเลือกสินค้าบางรายการเพื่อจำกัดการเลือกเฉพาะรายการเหล่านั้น
- **Per-variant rules**: เพิ่มตัวเลือกสินค้า (variant) ที่ต้องการกติกาต่างจากค่าของกลุ่ม ตามหัวข้อ "กติการายตัวเลือกสินค้า (Per-Variant Rules)" ด้านล่าง

คลิกปุ่ม **Add group** เพื่อเพิ่มกลุ่มถัดไป และลากกลุ่มเพื่อจัดลำดับได้ ลำดับของกลุ่มคือลำดับขั้นตอนที่ลูกค้าเห็นบนหน้าร้าน

### กติการายตัวเลือกสินค้า (Per-Variant Rules)

ใช้ per-variant rules เมื่อตัวเลือกสินค้า (variant) บางรายการต้องการเงื่อนไขการแสดงผล การจำกัดจำนวน หรือจำนวนที่บังคับ ซึ่งต่างจากค่าทั่วไปของกลุ่ม

วิธีเพิ่มกติกา: ค้นหา variant ในช่อง **Per-variant rules** แล้วเลือกจากผลการค้นหา variant ที่เพิ่มแล้วจะแสดงเป็นป้ายซึ่งลบได้ด้วยไอคอน X และจะมีส่วน "Variant rule" แสดงการตั้งค่าของ variant นั้น:

![กลุ่มการเลือกที่ตั้งค่าหมวดหมู่ พร้อม per-variant rule](/user-guide/images/category-bundles/group-per-variant.jpg)

แต่ละ variant rule ตั้งเงื่อนไขได้ดังนี้:

- **Customer selectable**: ให้ลูกค้าเลือก variant นี้เองได้หรือไม่ขณะจัดชุด เปิดอยู่เป็นค่าเริ่มต้น ปิดสวิตช์เพื่อซ่อน variant นี้จากตัวเลือกของลูกค้า ตัวอย่างเช่น สินค้าที่คุณใส่ให้อัตโนมัติผ่าน **Required quantity** แทน
- **Minimum quantity**: จำนวนขั้นต่ำของ variant นี้ที่ต้องมีในชุด ค่าเริ่มต้นคือ 0 หมายถึงไม่มีขั้นต่ำ
- **Maximum quantity**: จำนวนสูงสุดของ variant นี้ในชุด เว้นว่างเพื่อใช้ค่า **Maximum per variant** ของกลุ่ม
- **Required quantity**: จำนวนของ variant นี้ที่ทุกชุดต้องมีโดยอัตโนมัติ ค่าเริ่มต้นคือ 0 ตั้งเป็นจำนวนที่มากกว่าเพื่อบังคับให้ variant นี้อยู่ในทุกชุด ตัวอย่างเช่น เจลเก็บความเย็นที่ต้องแนบทุกกล่อง

## ตั้งราคาและเผยแพร่ Bundle

ลูกค้ายังซื้อ bundle ไม่ได้จนกว่า linked product จะมีราคาและถูกเผยแพร่ วิธีตั้งค่า:

1. ไปที่ **Category Bundles** แล้วคลิก bundle เพื่อเปิดหน้ารายละเอียด
2. ในส่วน **Linked product** คลิก **View product**
3. ที่หน้าสินค้า แก้ไขราคาในส่วน **Pricing**
4. เพิ่มรูปภาพและคำอธิบายของสินค้า
5. ตรวจสอบช่องทางการขาย (sales channels) และการตั้งค่าการจัดส่ง (shipping configuration) ของสินค้า
6. เปลี่ยนสถานะสินค้าเป็น **Published**

## จัดการ Bundle หลังสร้าง

คลิก bundle ในหน้า **Category Bundles** เพื่อเปิดหน้ารายละเอียด:

![หน้ารายละเอียด bundle แสดงแผน subscription สินค้าที่เชื่อมโยง และกลุ่มการเลือก](/user-guide/images/category-bundles/bundle-details.jpg)

จากหน้านี้คุณสามารถ:

- คลิก **Edit bundle** เพื่อแก้ไขกลุ่มการเลือก และแผน subscription สำหรับ bundle แบบสมาชิก
- คลิก **Archive** เพื่อหยุดขาย bundle โดยไม่ลบข้อมูล
- คลิก **Delete** เพื่อลบ bundle

หน้ารายละเอียดยังแสดงกลุ่มการเลือกพร้อมเงื่อนไขของแต่ละกลุ่ม สินค้าที่เชื่อมโยง และสำหรับ bundle แบบสมาชิก จะแสดงจำนวน subscription ที่ใช้งานอยู่และ configuration record ด้วย

นอกจากนี้ หน้าสินค้าแต่ละตัวมีส่วน **Bundle Usage** ที่แสดงว่าสินค้านั้นถูกใช้อยู่ใน bundle ใดบ้าง ควรตรวจสอบก่อนแก้ไขหรือหยุดขายสินค้าที่เป็นส่วนประกอบของ bundle

## ขั้นตอนถัดไป: ขาย Bundle เป็นแบบสมาชิก

หากต้องการขาย bundle ที่มีรอบจัดส่งต่อเนื่อง การต่ออายุอัตโนมัติ และการเรียกเก็บเงินซ้ำ โปรดดูคู่มือ [สร้างสินค้าจัดชุดแบบสมาชิก (Subscription Bundle)](./subscription/page.mdx)
