### แก้ไขรายละเอียดสินค้า

วิธีการแก้ไขรายละเอียดทั่วไปของสินค้า:

1. คลิกที่ไอคอน <InlineIcon Icon={EllipsisHorizontal} alt="three-dots" /> ในส่วนหัวของส่วนแรก
2. เลือก "Edit" จากเมนูดรอปดาวน์
3. ในหน้าต่างด้านข้างที่เปิดขึ้น คุณสามารถแก้ไขสถานะสินค้า, ชื่อสินค้า, คำโปรย (Subtitle), แฮนเดิล (Handle), วัสดุ, คำอธิบายสินค้า และเลือกว่าสินค้านี้ร่วมรายการส่วนลดได้หรือไม่
4. เมื่อเสร็จแล้ว ให้คลิกปุ่ม "Save"

### จัดการการแปลภาษาของสินค้า

<Note>

ภาษาของระบบ (Locales) มีให้ใช้งานตั้งแต่ [Medusa v2.12.3](https://github.com/medusajs/medusa/releases/tag/v2.12.3) หากคุณไม่เห็นส่วนจัดการคำแปลภาษาใน Medusa Admin ของคุณ โปรดขอให้ทีมงานฝ่ายเทคนิคของคุณ [อัปเกรดแอปพลิเคชัน Medusa ของคุณ](!docs!/learn/update)

</Note>

สินค้าสามารถแปลเป็นภาษาต่าง ๆ ที่ [ร้านค้าของคุณรองรับ](../../settings/store/page.mdx#manage-store-locales) คุณสามารถจัดการการแปล [แบบเป็นกลุ่ม](../../settings/translations/page.mdx) หรือจัดการการแปลสำหรับแต่ละสินค้าจากหน้ารายละเอียดของสินค้านั้น ๆ ได้

วิธีการจัดการคำแปลภาษาสำหรับสินค้า:

1. คลิกที่ไอคอน <InlineIcon Icon={EllipsisHorizontal} alt="three-dots" /> ในส่วนหัวของส่วนแรก
2. เลือก "Manage translations" จากเมนูดรอปดาวน์
3. ใน [เครื่องมือแก้ไขแบบกลุ่ม](../../tips/bulk-editor/page.mdx) ที่เปิดขึ้น คุณสามารถดูและแก้ไขคำแปลสำหรับชื่อสินค้า, คำอธิบายสินค้า, คำโปรย และอื่น ๆ ในแต่ละภาษาที่ร้านค้าของคุณรองรับ
    - หากต้องการแก้ไขข้อความที่มีการรองรับการขึ้นบรรทัดใหม่ ให้ดับเบิ้ลคลิกที่เซลล์นั้น ๆ เพื่อเปิดพื้นที่ป้อนข้อความขนาดใหญ่ขึ้น
4. เมื่อแก้ไขเสร็จแล้ว ให้คลิกปุ่ม Save เพื่อบันทึกการเปลี่ยนแปลง

### ลบสินค้า

ในส่วนนี้ คุณสามารถลบสินค้าออกได้เช่นกัน

<Note type="warning">

การลบสินค้าจะไม่สามารถย้อนกลับคืนได้

</Note>

วิธีการลบสินค้า:

1. คลิกที่ไอคอน <InlineIcon Icon={EllipsisHorizontal} alt="three-dots" /> ในส่วนหัวของส่วนแรก
2. เลือก "Delete" จากเมนูดรอปดาวน์
3. ยืนยันการลบสินค้าโดยคลิกปุ่ม "Delete" ในป๊อปอัป

## จัดการสื่อและรูปภาพสินค้า

ส่วน Media จะแสดงรูปภาพต่าง ๆ ของสินค้า ใช้ส่วนนี้เพื่อดูและแก้ไขรูปภาพของสินค้า

![ส่วนจัดการรูปภาพสื่อ](https://res.cloudinary.com/dza7lstvk/image/upload/v1739810036/User%20Guide/Screenshot_2025-02-17_at_6.33.44_PM_rq9wud.png)

### เพิ่มรูปภาพ

วิธีการเพิ่มรูปภาพในสินค้า:

1. คลิกที่ไอคอน <InlineIcon Icon={EllipsisHorizontal} alt="three-dots" /> ในส่วนหัวของส่วน "Media"
2. เลือก "Edit" จากเมนูดรอปดาวน์
3. ในฟอร์มที่เปิดขึ้น ให้อัปโหลดรูปภาพโดยการลากและวางรูปภาพ หรือคลิกที่กล่อง "Upload images" เพื่อเลือกไฟล์
4. เมื่อเสร็จแล้ว ให้คลิกปุ่ม Save

### แก้ไขลำดับรูปภาพ

คุณสามารถแก้ไขลำดับการแสดงผลของรูปภาพได้ วิธีการดำเนินการ:

1. คลิกที่ไอคอน <InlineIcon Icon={EllipsisHorizontal} alt="three-dots" /> ในส่วนหัวของส่วน "Media"
2. เลือก "Edit" จากเมนูดรอปดาวน์
3. ในฟอร์มที่เปิดขึ้น ให้ลากและวางรูปภาพเพื่อสลับลำดับตามที่ต้องการ
4. เมื่อเสร็จแล้ว ให้คลิกปุ่ม Save

### ตั้งรูปภาพย่อประจำสินค้า

รูปภาพย่อ (Thumbnail) ประจำสินค้าจะมีไอคอน <InlineIcon Icon={ThumbnailBadge} alt="thumbnail" /> แสดงอยู่ที่มุมด้านบน

วิธีการกำหนดรูปภาพให้เป็นรูปภาพย่อ:

1. คลิกที่ไอคอน <InlineIcon Icon={EllipsisHorizontal} alt="three-dots" /> ในส่วนหัวของส่วน "Media"
2. เลือก "Edit" จากเมนูดรอปดาวน์
3. วางเมาส์เหนือรูปภาพที่ต้องการตั้งเป็นรูปภาพย่อ แล้วทำเครื่องหมายที่กล่องเลือกรูปนั้น
4. กดปุ่ม <Kbd>T</Kbd> หรือคลิกปุ่ม "Make thumbnail" ที่ด้านล่างของหน้า
5. เมื่อเสร็จแล้ว ให้คลิกปุ่ม Save

### ลบรูปภาพ

คุณสามารถลบรูปภาพจากหน้าสินค้าหรือจากฟอร์มจัดการรูปภาพได้

วิธีการลบรูปภาพสินค้า:

1. วางเมาส์เหนือรูปภาพสินค้าที่ต้องการลบ แล้วทำเครื่องหมายที่กล่องเลือก
2. กดปุ่ม <Kbd>D</Kbd> หรือคลิกปุ่ม "Delete" ที่ด้านล่างของหน้า
3. ยืนยันการลบรูปภาพโดยคลิกปุ่ม "Delete" ในป๊อปอัป

### เชื่อมโยงรูปภาพกับตัวเลือกย่อย

<Note>

การจัดการสื่อสำหรับตัวเลือกย่อยสินค้าพร้อมใช้งานตั้งแต่ [Medusa Admin v2.11.2](https://github.com/medusajs/medusa/releases/tag/v2.11.2) หากคุณไม่เห็นการดำเนินการ "Manage associated variants" โปรดขอให้ทีมงานฝ่ายเทคนิคของคุณ [อัปเกรดแอปพลิเคชัน Medusa ของคุณ](!docs!/learn/update)

</Note>

เมื่อรูปภาพใด ๆ ไม่ได้เชื่อมโยงกับตัวเลือกย่อยใด ๆ รูปภาพนั้นจะแสดงผลสำหรับตัวเลือกย่อยทั้งหมดของสินค้า

คุณสามารถเชื่อมโยงรูปภาพกับตัวเลือกย่อยสินค้าเฉพาะเจาะจงได้ เพื่อให้รูปภาพแสดงเฉพาะเมื่อมีการเลือกตัวเลือกย่อยนั้น ๆ

คุณสามารถจัดการรูปภาพของตัวเลือกย่อยรายการเดียวได้จาก [หน้ารายละเอียดของตัวเลือกย่อยนั้น](../variants/page.mdx#manage-product-variant-images) หรือเชื่อมโยงรูปภาพหนึ่งภาพกับตัวเลือกย่อยหลายรายการพร้อมกันได้จากฟอร์มจัดการรูปภาพสินค้า

วิธีการเชื่อมโยงรูปภาพกับตัวเลือกย่อยสินค้าหลายรายการ:

1. ในส่วน Media ให้วางเมาส์เหนือรูปภาพที่ต้องการเชื่อมโยงกับตัวเลือกย่อย แล้วทำเครื่องหมายที่กล่องเลือก
2. กดปุ่ม <Kbd>M</Kbd> หรือคลิกปุ่ม "Manage associated variants" ที่ด้านล่างของหน้า
3. ในหน้าต่างด้านข้างที่เปิดขึ้น ให้ทำเครื่องหมายเลือกหรือยกเลิกการเลือกตัวเลือกย่อยสินค้าที่ต้องการเชื่อมโยงกับรูปภาพนี้
4. เมื่อเสร็จแล้ว ให้คลิกปุ่ม Save

## จัดการตัวเลือกของสินค้า

<Note>

ตั้งแต่ [Medusa v2.16.0](https://github.com/medusajs/medusa/releases/tag/v2.16.0) เป็นต้นไป ตัวเลือกสินค้าสามารถจัดการในระดับสากลและสามารถนำกลับมาใช้ซ้ำข้ามสินค้าต่าง ๆ ได้ หากคุณไม่เห็นหน้า Product → Options ในแถบเมนูด้านข้าง โปรดขอให้ทีมงานฝ่ายเทคนิคของคุณ [อัปเกรดแอปพลิเคชัน Medusa ของคุณ](!docs!/learn/update)

</Note>

ส่วน Options แสดง [ตัวเลือกสินค้า](../options/page.mdx) ของสินค้านี้ ใช้ส่วนนี้เพื่อดูและแก้ไขตัวเลือกสินค้า

![ส่วนจัดการตัวเลือกสินค้า](https://res.cloudinary.com/dza7lstvk/image/upload/v1739810071/User%20Guide/Screenshot_2025-02-17_at_6.34.21_PM_y5eiwe.png)

ตัวเลือกสินค้าสามารถกำหนดแบบสากลจากหน้า [Product → Options](../options/page.mdx) หรืออาจกำหนดเฉพาะสำหรับสินค้านี้โดยเฉพาะก็ได้

วิธีการจัดการตัวเลือกของสินค้า:

1. คลิกที่ไอคอน <InlineIcon Icon={EllipsisHorizontal} alt="three-dots" /> ในส่วนหัวของส่วน "Options"
2. เลือก Manage จากเมนูดรอปดาวน์
3. ในหน้าต่างด้านข้างที่เปิดขึ้น คุณสามารถ:
    - เพิ่มตัวเลือกสินค้าที่มีอยู่โดยเลือกตัวเลือกในเมนูดรอปดาวน์ "Product Options"
    - สร้างตัวเลือกเฉพาะสินค้าชิ้นนี้ได้โดยการพิมพ์ชื่อตัวเลือกลงในช่องเมนูดรอปดาวน์ "Product Options" จากนั้นคุณยังสามารถป้อนค่าของตัวเลือกคั่นด้วยเครื่องหมายจุลภาคในฟิลด์ที่แสดงขึ้นสำหรับตัวเลือกใหม่ได้อีกด้วย
    - ลบตัวเลือกโดยคลิกไอคอน <InlineIcon Icon={XMark} alt="cross" /> ข้างตัวเลือกนั้น ๆ
    - ลบและเพิ่มค่าของตัวเลือกในเมนูดรอปดาวน์ "Values" ของแต่ละตัวเลือก
4. เมื่อเสร็จแล้ว ให้คลิกปุ่ม Save

![ฟอร์มจัดการตัวเลือกสินค้าใน Medusa Admin](https://res.cloudinary.com/dza7lstvk/image/upload/v1765529614/User%20Guide/CleanShot_2025-12-12_at_10.53.03_2x_f8ftqv.png)

## จัดการข้อมูลเมทาดาตาของสินค้า

ข้อมูลเมทาดาตา (Metadata) คือข้อมูลที่กำหนดเองซึ่งสามารถเชื่อมโยงกับสินค้าในรูปแบบของคู่คีย์-ค่า (Key-Value) ซึ่งปกติแล้วนักพัฒนาจะใช้สำหรับการผสานระบบแบบกำหนดเองหรือเพื่อจัดเก็บข้อมูลเพิ่มเติมเกี่ยวกับสินค้า

วิธีการแก้ไขข้อมูลเมทาดาตาของสินค้า:

1. คลิกไอคอน <InlineIcon Icon={ArrowUpRightOnBox} alt="arrow" /> ในส่วน "Metadata"
2. ในหน้าต่างด้านข้างที่เปิดขึ้น:
    - จัดการคู่คีย์-ค่าในตาราง
    - วิธีการเพิ่มแถวคู่คีย์-ค่าใหม่ก่อนหน้าหรือหลังแถวที่มีอยู่:
        - วางเมาส์เหนือแถวแล้วคลิกไอคอน <InlineIcon Icon={EllipsisVertical} alt="three-dots" /> ที่ส่วนท้ายของแถว
        - เลือก "Insert row above" (แทรกแถวด้านบน) หรือ "Insert row below" (แทรกแถวด้านล่าง) จากเมนูดรอปดาวน์
    - วิธีการลบแถวคู่คีย์-ค่า:
        - วางเมาส์เหนือแถวแล้วคลิกไอคอน <InlineIcon Icon={EllipsisVertical} alt="three-dots" /> ที่ส่วนท้ายของแถว
        - เลือก "Delete row" จากเมนูดรอปดาวน์
3. เมื่อเสร็จแล้ว ให้คลิกปุ่ม Save
