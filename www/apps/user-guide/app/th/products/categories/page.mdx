# {metadata.title}

ในคู่มือนี้ คุณจะได้เรียนรู้วิธีสร้างและจัดการหมวดหมู่สินค้า

## หมวดหมู่สินค้าสำหรับจัดกลุ่มสินค้า

หมวดหมู่สินค้าคือกลุ่มสินค้าที่มีประเภทหรือธีมที่ใกล้เคียงกัน ตัวอย่างเช่น หมวดหมู่ "รองเท้า" (Shoes) สามารถรวมสินค้าอย่างรองเท้าผ้าใบ รองเท้าบูท และรองเท้าแตะ หมวดหมู่ช่วยให้ลูกค้าสามารถค้นหาสินค้าที่ตรงตามความต้องการได้ง่ายขึ้น และช่วยเพิ่มความสะดวกในการเลือกซื้อสินค้าในร้านค้าของคุณ

หมวดหมู่สินค้าสามารถจัดประเภทซ้อนในหมวดหมู่อื่นเพื่อสร้างโครงสร้างแบบลำดับขั้น (hierarchy) ได้ ตัวอย่างเช่น คุณสามารถจัดหมวดหมู่ "รองเท้า" (Shoes) ซ้อนอยู่ภายใต้หมวดหมู่ "ผู้หญิง" (Women's)

สินค้าหนึ่งรายการสามารถจัดอยู่ในหลายหมวดหมู่ได้ คุณสามารถศึกษาวิธีตั้งค่าหมวดหมู่ให้กับสินค้าได้ใน[คู่มือนี้](../edit/page.mdx#manage-product-organization)

### รายการหมวดหมู่สินค้า

หากต้องการดูหมวดหมู่สินค้าทั้งหมด ให้ไปที่หน้า Products → Categories (สินค้า → หมวดหมู่) จากหน้านี้ คุณสามารถดูรายการ กรองข้อมูล และค้นหาผ่านหมวดหมู่ทั้งหมดได้

## สร้างหมวดหมู่สินค้า

ขั้นตอนการสร้างหมวดหมู่สินค้า:

1. ไปที่หน้า Products → Categories
2. คลิกปุ่ม "Create" ในส่วนหัวของส่วนหลัก
3. ในฟอร์มที่เปิดขึ้น จะมี 2 ขั้นตอนดังนี้:
    1. ขั้นตอน Details (รายละเอียด):
      1. ป้อนชื่อหมวดหมู่ในฟิลด์ Title นี่คือฟิลด์เดียวที่จำเป็นต้องกรอก
      2. ค่าของฟิลด์ Handle จะถูกนำไปใช้ใน URL ของหมวดหมู่บนหน้าร้าน ช่วยให้คุณสร้าง URL หมวดหมู่ที่อ่านเข้าใจง่าย โดย Handle จะต้องไม่ซ้ำกันในทุกหมวดหมู่ และต้องประกอบด้วยตัวอักษรภาษาอังกฤษตัวพิมพ์เล็ก ตัวเลข และเครื่องหมายยัติภังค์ (`-`) หากไม่ระบุ Medusa จะสร้าง handle จาก Title โดยอัตโนมัติ
      3. ระบุคำอธิบายหมวดหมู่ในช่อง Description (ไม่บังคับ)
      4. ในฟิลด์ Status คุณสามารถเปลี่ยนสถานะเป็น "Inactive" (ไม่ใช้งาน) ได้ หากไม่ต้องการให้หมวดหมู่นี้แสดงบนหน้าร้าน
      5. ในฟิลด์ Visibility คุณสามารถเปลี่ยนระดับการมองเห็นเป็น "Private" (ส่วนตัว) ได้ หากคุณสร้างหมวดหมู่สำหรับใช้ภายในร้านค้าซึ่งไม่ต้องการให้ลูกค้าทั่วไปมองเห็น
      6. เมื่อเรียบร้อยแล้ว ให้คลิกปุ่ม "Continue"
    2. ในขั้นตอนที่สอง คุณสามารถจัดลำดับความสำคัญของหมวดหมู่นี้เปรียบเทียบกับหมวดหมู่อื่น ๆ ได้:
      - ในการปรับย้ายตำแหน่งหมวดหมู่ ให้ใช้ไอคอน <InlineIcon Icon={DotsSix} alt="drag" /> เพื่อลากและวางหมวดหมู่ไปยังตำแหน่งที่ต้องการ
      - ในการตั้งค่าหมวดหมู่ย่อย (ซ้อนกัน) ให้ลากมันไปไว้ใต้หมวดหมู่อื่นแล้วขยับไปทางด้านข้างเล็กน้อย
4. เมื่อเสร็จเรียบร้อยแล้ว ให้คลิกปุ่ม Save

![ฟอร์มสร้างหมวดหมู่สินค้า](https://res.cloudinary.com/dza7lstvk/image/upload/v1739874884/User%20Guide/Screenshot_2025-02-18_at_12.30.06_PM_z53wwi.png)

## ดูรายละเอียดหมวดหมู่สินค้า

ขั้นตอนการดูรายละเอียดหมวดหมู่:

1. ไปที่หน้า Products → Categories
2. เลือกหมวดหมู่ที่คุณต้องการดูจากรายการ

![หน้ารายละเอียดหมวดหมู่](https://res.cloudinary.com/dza7lstvk/image/upload/v1739874959/User%20Guide/Screenshot_2025-02-18_at_12.35.43_PM_wfijxl.png)

### สถานะและการมองเห็นของหมวดหมู่สินค้า

ในส่วนหัวของส่วนแรก คุณจะพบป้ายสถานะ 2 ป้าย:

- ป้ายแรกแสดงสถานะของหมวดหมู่:
  - **Active**: หมวดหมู่เปิดใช้งานอยู่และแสดงผลบนหน้าร้าน
  - **Inactive**: หมวดหมู่ปิดใช้งานอยู่และไม่แสดงผลบนหน้าร้าน
- ป้ายที่สองแสดงระดับการมองเห็นของหมวดหมู่:
  - **Public**: ลูกค้าทั่วไปสามารถมองเห็นหมวดหมู่นี้ได้บนหน้าร้าน
  - **Private**: ลูกค้าทั่วไปไม่สามารถมองเห็นหมวดหมู่นี้ได้บนหน้าร้าน ใช้สำหรับผู้ใช้งานระบบหลังบ้าน (Admin) เท่านั้น

## แก้ไขรายละเอียดหมวดหมู่สินค้า

ขั้นตอนการแก้ไขหมวดหมู่สินค้า:

1. ไปที่หน้า Products → Categories
2. คลิกหมวดหมู่ที่ต้องการแก้ไข หากหมวดหมู่นั้นถูกจัดซ้อนไว้ใต้หมวดหมู่อื่น คุณอาจจำเป็นต้องคลิกไอคอนขยาย <InlineIcon Icon={TriangleRightMini} alt="expand" /> ของหมวดหมู่หลักก่อน
3. คลิกไอคอน <InlineIcon Icon={EllipsisHorizontal} alt="three-dots" /> ในส่วนแรกของหน้ารายละเอียดหมวดหมู่
4. เลือก Edit จากเมนูแบบดึงลง
5. ในหน้าต่างด้านข้างที่เปิดขึ้น คุณสามารถแก้ไข Title, Handle, Description, Status และ Visibility ของหมวดหมู่ได้
6. เมื่อแก้ไขเสร็จแล้ว ให้คลิกปุ่ม Save

## จัดการคำแปลของหมวดหมู่สินค้า

<Note>

การตั้งค่าภาษา (Locales) สามารถใช้งานได้ตั้งแต่ [Medusa v2.12.3](https://github.com/medusajs/medusa/releases/tag/v2.12.3) เป็นต้นไป หากคุณไม่เห็นการจัดการคำแปลใน Medusa Admin ของคุณ โปรดแจ้งทีมเทคนิคของคุณให้ [อัปเกรดแอปพลิเคชัน Medusa ของคุณ](!docs!/learn/update)

</Note>

หมวดหมู่สินค้าสามารถแปลเป็นภาษาต่าง ๆ [ที่ร้านค้าของคุณรองรับ](../../settings/store/page.mdx#manage-store-locales) คุณสามารถจัดการคำแปล [แบบพร้อมกันทั้งหมด (in bulk)](../../settings/translations/page.mdx) หรือจัดการคำแปลสำหรับหมวดหมู่สินค้าแต่ละรายการได้จากหน้ารายละเอียดของหมวดหมู่นั้น ๆ

ขั้นตอนการจัดการคำแปลของหมวดหมู่สินค้า:

1. คลิกที่ไอคอน <InlineIcon Icon={EllipsisHorizontal} alt="three-dots" /> ในส่วนหัวของส่วนแรก
2. เลือก "Manage translations" จากเมนูแบบดึงลง
3. ใน [เครื่องมือแก้ไขแบบกลุ่ม (bulk editor)](../../tips/bulk-editor/page.mdx) ที่เปิดขึ้น คุณสามารถดูและแก้ไขคำแปลสำหรับชื่อ (title) และคำอธิบาย (description) ของหมวดหมู่สินค้าในแต่ละภาษาที่ร้านค้าของคุณรองรับ
    - ในการแก้ไขข้อความที่มีความยาวหลายบรรทัด ให้ดับเบิลคลิกที่เซลล์นั้นเพื่อเปิดกล่องป้อนข้อความที่ใหญ่ขึ้น
4. เมื่อคุณแก้ไขเสร็จแล้ว ให้คลิกปุ่ม Save เพื่อบันทึกการเปลี่ยนแปลง

## แก้ไขข้อมูลเมทาดาตาของหมวดหมู่สินค้า

เมทาดาตา (Metadata) คือข้อมูลที่กำหนดเองซึ่งสามารถเชื่อมโยงกับหมวดหมู่สินค้าในรูปแบบคู่คีย์-ค่า (key-value pairs) โดยส่วนใหญ่แล้วนักพัฒนาจะใช้สิ่งนี้สำหรับการรวมระบบที่กำหนดเอง หรือเพื่อจัดเก็บข้อมูลเพิ่มเติมเกี่ยวกับหมวดหมู่สินค้า

ขั้นตอนการแก้ไขข้อมูลเมทาดาตาของหมวดหมู่สินค้า:

1. ไปที่หน้ารายละเอียดของหมวดหมู่สินค้า
2. คลิกไอคอน <InlineIcon Icon={ArrowUpRightOnBox} alt="arrow" /> ในส่วน "Metadata"
3. ในหน้าต่างด้านข้างที่เปิดขึ้น:
    - จัดการคู่คีย์-ค่าในตาราง
    - หากต้องการเพิ่มแถวของคู่คีย์-ค่าใหม่ก่อนหน้าหรือหลังแถวที่มีอยู่เดิม:
        - ชี้เมาส์ไปที่แถวดังกล่าวแล้วคลิกไอคอน <InlineIcon Icon={EllipsisVertical} alt="three-dots" /> ที่ส่วนท้ายของแถว
        - เลือก "Insert row above" (แทรกแถวด้านบน) หรือ "Insert row below" (แทรกแถวด้านล่าง) จากเมนูแบบดึงลง
    - หากต้องการลบแถวของคู่คีย์-ค่า:
        - ชี้เมาส์ไปที่แถวดังกล่าวแล้วคลิกไอคอน <InlineIcon Icon={EllipsisVertical} alt="three-dots" /> ที่ส่วนท้ายของแถว
        - เลือก "Delete row" (ลบแถว) จากเมนูแบบดึงลง
4. เมื่อคุณดำเนินการเสร็จแล้ว ให้คลิกปุ่ม Save

## จัดการสินค้าในหมวดหมู่

จากหน้ารายละเอียดหมวดหมู่สินค้า คุณสามารถจัดการสินค้าต่าง ๆ ที่อยู่ในหมวดหมู่นั้นได้

### เพิ่มสินค้าไปยังหมวดหมู่

ขั้นตอนการเพิ่มสินค้าไปยังหมวดหมู่:

1. ไปที่หน้ารายละเอียดของหมวดหมู่
2. ในส่วนของ Products ให้คลิกที่ไอคอน <InlineIcon Icon={EllipsisHorizontal} alt="three-dots" />
3. เลือก "Add" จากเมนูแบบดึงลง
4. ติ๊กเลือกสินค้าที่คุณต้องการเพิ่มลงในหมวดหมู่จากรายการที่เปิดขึ้น
5. เมื่อเรียบร้อยแล้ว ให้คลิกปุ่ม Save

![ฟอร์มเพิ่มสินค้าไปยังหมวดหมู่](https://res.cloudinary.com/dza7lstvk/image/upload/v1739875239/User%20Guide/Screenshot_2025-02-18_at_12.40.28_PM_ffenap.png)

### ลบสินค้าออกจากหมวดหมู่

ขั้นตอนการลบสินค้าออกจากหมวดหมู่:

1. ไปที่หน้ารายละเอียดของหมวดหมู่
2. ในส่วนของ Products ให้เลือกสินค้าที่คุณต้องการลบออกจากหมวดหมู่
3. เมื่อเสร็จสิ้นแล้ว ให้กดปุ่ม <Kbd>R</Kbd> บนคีย์บอร์ด หรือคลิกที่คำว่า "Remove" ที่ปรากฏบริเวณกึ่งกลางด้านล่างของหน้า
4. ยืนยันการลบสินค้าโดยคลิกปุ่ม "Remove" ในหน้าต่างป๊อปอัป

![ลบสินค้าออกจากหมวดหมู่](https://res.cloudinary.com/dza7lstvk/image/upload/v1739875474/User%20Guide/Screenshot_2025-02-18_at_12.44.16_PM_vji2v1.png)

## แก้ไขการจัดลำดับและโครงสร้างหมวดหมู่

ขั้นตอนการเปลี่ยนลำดับและโครงสร้างแบบลำดับขั้นของหมวดหมู่:

1. ไปที่หน้า Products → Categories
2. คลิกที่ปุ่ม "Edit ranking"
3. ในฟอร์มที่เปิดขึ้น คุณสามารถแก้ไขการจัดลำดับและลำดับขั้นของหมวดหมู่ต่าง ๆ ได้ดังนี้:
    - การเปลี่ยนแปลงจะถูกบันทึกโดยอัตโนมัติทุกครั้งที่คุณย้ายตำแหน่งหมวดหมู่
    - ในการปรับย้ายตำแหน่งหมวดหมู่ ให้ใช้ไอคอน <InlineIcon Icon={DotsSix} alt="drag" /> เพื่อลากและวางหมวดหมู่ไปยังตำแหน่งใหม่ที่ต้องการ
    - ในการตั้งหมวดหมู่ย่อย (ซ้อนในหมวดหมู่อื่น) ให้ลากมันไปไว้ใต้หมวดหมู่อื่นแล้วขยับไปทางด้านข้างเล็กน้อย
4. เมื่อเสร็จสิ้นแล้ว คุณสามารถปิดหน้าฟอร์มลงได้ทันทีเนื่องจากการเปลี่ยนแปลงถูกบันทึกเรียบร้อยแล้ว

![ฟอร์มแก้ไขการจัดลำดับและโครงสร้างหมวดหมู่](https://res.cloudinary.com/dza7lstvk/image/upload/v1739875802/User%20Guide/Screenshot_2025-02-18_at_12.49.47_PM_s3lnpc.png)

## ลบหมวดหมู่

<Note type="warning">

การลบหมวดหมู่ไม่สามารถย้อนคืนได้

</Note>

1. ไปที่หน้า Products → Categories
2. คลิกไอคอน <InlineIcon Icon={EllipsisHorizontal} alt="three-dots" /> ในแถวของหมวดหมู่ที่ต้องการลบ
3. เลือก Delete จากเมนูแบบดึงลง
4. ยืนยันการลบหมวดหมู่โดยคลิกปุ่ม "Delete" ในหน้าต่างป๊อปอัป
