# {metadata.title}

ในคู่มือนี้ คุณจะได้เรียนรู้วิธีการรีเซ็ตรหัสผ่านของผู้ใช้งานผู้ดูแลระบบ (admin user) โดยใช้แดชบอร์ด Medusa Admin

<Note title="ผู้ใช้งาน Cloud?">

ตรวจสอบให้แน่ใจว่าคุณได้ตั้งค่า [Medusa Emails](!cloud!/emails) ในโปรเจกต์ Cloud ของคุณเรียบร้อยแล้วเพื่อส่งอีเมลรีเซ็ตรหัสผ่าน Medusa Emails เป็นบริการจัดการอีเมลที่จะช่วยให้คุณส่งอีเมลธุรกรรม (transactional email) ได้โดยไม่ต้องตั้งค่าเพิ่มเติมใดๆ

</Note>

## 1. ร้องขอการรีเซ็ตรหัสผ่าน

ก่อนที่จะรีเซ็ตรหัสผ่าน คุณต้องส่งคำร้องขอการรีเซ็ตเสียก่อน ซึ่งระบบจะส่งอีเมลที่มีขั้นตอนการรีเซ็ตรหัสผ่านไปให้คุณ

วิธีรีเซ็ตรหัสผ่านของคุณ:

1. เปิดแดชบอร์ด Medusa Admin
2. คลิกที่ "Reset" (รีเซ็ต) ด้านล่างฟอร์มเข้าสู่ระบบ
3. ในฟอร์มรีเซ็ตรหัสผ่าน (Reset Password) ให้กรอกที่อยู่อีเมลของคุณ
4. คลิกปุ่ม "Send reset instructions" (ส่งขั้นตอนการรีเซ็ต)

คุณจะได้รับอีเมลที่มีขั้นตอนการรีเซ็ตรหัสผ่าน โดยในอีเมลจะมีลิงก์ที่จะนำคุณไปยัง[ฟอร์มรีเซ็ตรหัสผ่าน](#2-reset-password)

<Note>

หากคุณไม่ได้รับอีเมล โปรดติดต่อทีมงานฝ่ายเทคนิคของคุณเพื่อให้แน่ใจว่าพวกเขาได้ติดตั้ง [Notification Module Provider](!resources!/infrastructure-modules/notification) และตั้งค่า [การแจ้งเตือนการรีเซ็ตรหัสผ่าน](!resources!/commerce-modules/auth/reset-password) เรียบร้อยแล้ว

</Note>

## 2. รีเซ็ตรหัสผ่าน

หลังจากที่คุณได้[ร้องขอการรีเซ็ตรหัสผ่าน](#1-request-to-reset-password)แล้ว คุณสามารถรีเซ็ตรหัสผ่านของคุณได้โดยใช้ลิงก์ในอีเมลที่คุณได้รับ

วิธีรีเซ็ตรหัสผ่านของคุณ:

1. เปิดลิงก์ที่คุณได้รับในอีเมล
2. ในฟอร์มรีเซ็ตรหัสผ่าน (Reset Password) ให้กรอกรหัสผ่านใหม่ของคุณและยืนยันรหัสผ่าน
3. คลิกปุ่ม "Reset password" (รีเซ็ตรหัสผ่าน)

เมื่อคุณรีเซ็ตรหัสผ่านเสร็จแล้ว ให้คลิกลิงก์ "Back to login" (กลับไปที่หน้าเข้าสู่ระบบ) เพื่อกลับไปยังฟอร์มเข้าสู่ระบบ
